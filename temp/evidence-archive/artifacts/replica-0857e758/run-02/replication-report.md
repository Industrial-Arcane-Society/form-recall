## 几何核复现

用同一套本地 `Document.build()` 对三项特征做了隔离检查：轴杆 → 法兰 → 回转头时，最后一步虽然在构建日志中显示“合并”，包围盒却从预期 Z=0–60 收缩到只剩回转头 Z=25–60。改变添加顺序，让回转体成为第一特征、再添加轴杆和法兰后，包围盒恢复为 Z=0–60。用圆柱头替代最后的回转特征也能保留 Z=0–60。由此确认，问题落在当前 `revolve` 加料的顺序敏感布尔合并，而不只是视觉识别或尺寸提示。

下一轮将避免“先建轴杆和法兰、最后加回转头”的顺序：Agent 先用一条完整、闭合的半径—轴向轮廓创建回转主体，再逐步添加确有需要的非回转细节，并用独立 front 与 iso 视图复核。
