# 元增量学习 · 核心模块契约

> 本文件是「元增量核心算法」与「界面 / 主程序集成」之间的唯一契约。
> 定位：这是程序的核心学习机制，不是外挂功能。

## 0. 为什么这样选型（先看这段，别改方向）

程序的现状是「LLM 每次从零理解提示词」，没有任何积累。要补的是
**「同一族零件反复出现时不必重新理解」+「新族来了能快速适配」+「学新的忘不掉旧的」**。

三个硬约束决定了实现方式：

1. **不能让程序依赖 torch**。用户双击启动的是系统 Python（3.14，没有 torch），
   README 里写死了「核心纯标准库」。元学习模块一旦引入 torch，程序就装不动了。
2. **1828 条数据训不出深度网络**。微调不现实，few-shot 才是正解。
3. **工业场景要可审计**。原型网络可以解释成「这条提示词离哪个族的原型最近，差多少」，
   比黑盒分类器好验收。

所以：**字符 n-gram 嵌入 + 原型网络（Prototype Network, Snell 2017）+ 增量 EMA + exemplar 回放**，
全部用 numpy 实现（numpy 是程序已有依赖）。

## 3. 特征（features.py）

```python
def numeric_tokens(text: str) -> list[float]
```
从提示词里抽型号数字：`M5x8` → `[5, 8]`；`SW80x088` → `[80, 88]`；
`EGT001` → `[1]`（尾数带前导零的按整数读）；`直径 12 的孔` → `[12]`。
最多取 6 个，不足补 0。

```python
def family_cues() -> dict[str, list[str]]
```
类别线索词表，至少覆盖 13 个族，每族 ≥4 个线索词
（例：`内六角螺钉`: ['内六角','螺钉','螺栓','圆头','M']；`EGT型材`: ['EGT','型材','SW']；
`定位销`: ['定位销','销','台阶销','P0'] …）。

```python
def embed(prompt: str, vocab: dict | None = None) -> np.ndarray
```
- 字符 n-gram（n=2,3,4），中文不依赖分词
- 子线性 TF 加权（`1 + log(tf)`），再按维度做 L2 归一化
- 拼接 `numeric_tokens`（除以 100 归一化）和 `family_cues` 命中位（0/1）
- 输出固定维度向量，**维度必须由 vocab 决定并随 memory 一起持久化**，不能每次重算
- `vocab=None` 时按内置词表建（用于冷启动）；`MetaMemory` 持有自己的 vocab

## 4. 记忆（memory.py）

```python
DEFAULT_STORE = <项目根>/kb/meta_memory.json

class MetaMemory:
    def __init__(self, store_path=None, embed_dim=None)
    # ---- 推理 ----
    def suggest(self, prompt: str, k: int = 5) -> dict:
        """返回：
        {'family': str|None,            # 预测族名
         'confidence': float,           # 0..1，原型距离换算，不是概率
         'family_scores': {族: 分数},    # 全部族的相似度，降序
         'envelope_hint': [x,y,z]|None, # 该族经验包络中位数
         'similar': [{'prompt','category','model','envelope','score'}]  # top-k
        }
        空库时返回 family=None 且不抛异常——冷启动必须能跑。
        """
    # ---- 学习 ----
    def observe(self, prompt: str, category: str, model: str,
                envelope=None, verified: bool = True) -> dict:
        """写入一条经验。
        verified=False：只进候选池，**不改原型、不涨样本计数**（写入门禁）。
        verified=True：更新该族原型（EMA）、样本计数 +1、进 exemplar 池。
        返回 {'family','accepted':bool,'reason':str,'n_samples':int}
        """
    def observe_batch(self, rows, verified=True) -> dict   # 批量，返回汇总
    # ---- 查询 ----
    def families(self) -> list[dict]   # [{'name','n_samples','n_verified','n_candidates'}]
    def stats(self) -> dict            # {'families','samples','candidates','updated_at','dim'}
    def save(self) / def load(cls, path) / def reset(self)
```

**增量规则（必须严格实现，评测会验）**：

- 原型 EMA：`p_new = (1-α)·p_old + α·x`，其中 `α = max(0.05, 1/(n+1))`，n 是该族已验证样本数。
  样本越多更新越稳，避免新样本把旧知识冲掉。
- 新族门槛：**同一族累计 ≥3 条 verified 才建立原型**，之前只进候选池。
  少于 3 条就建原型，噪声会把后来的正确样本拉偏。
- exemplar 池：每族最多 32 条 verified，超出时**按与当前原型距离做多样性保留**（远的优先，别全留最像的）。
- `suggest` 的 confidence：`1 - d/ (d + d2)` 形式，其中 d 是到最近原型的欧氏距离，
  d2 是到次近原型的距离。**族间区分度**比绝对距离更有意义，必须在 docstring 里写清。

## 5. 评测（evaluate.py）

```python
def load_dataset(path=None, exclude_null_category=True) -> list[dict]
def evaluate_holdout(rows, train_ratio=0.8, seed=0) -> dict
def evaluate_incremental(rows, family_order=None, shots_per_family=5, seed=0) -> dict
```

`evaluate_holdout` 返回：
```python
{'n_train','n_test','accuracy','macro_f1',
 'per_family': {族: {'precision','recall','f1','support'}},
 'baseline_nearest': accuracy,      # 最近邻（1-NN）基线，必须给
 'confusion': [[...]]}              # 族 × 族混淆矩阵
```
**必须同时给出原型法和 1-NN 基线**，只报一个数没有说服力。

`evaluate_incremental` 返回：
```python
{'steps': [{'step','family','seen_families','acc_on_seen','acc_on_all'}],
 'forgetting': float,        # 见过的族里，学完后准确率相对刚学完时的平均下降
 'final_accuracy': float,
 'order': [...]}
```
**遗忘率定义**：每步学完立刻测一遍「已见过的族」；最后一步再测一遍；两者之差按族平均。这是标准的
forgetting 口径（Chaudhry et al. 2018），别自己发明。
