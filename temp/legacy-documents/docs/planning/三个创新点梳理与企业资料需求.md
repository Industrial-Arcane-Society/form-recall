## 一、三个创新点怎么立

### 创新点 ①：元学习与增量学习的融合

**命题**：让系统从历史建模任务里攒经验，新零件族来了用少量样例就能适配，学了新的不丢旧的。

**技术实质**（答辩时这么说，比「用了元学习」有分量）：
不是把大模型微调一遍，而是把「经验」做成一个可增量、可回滚、可审计的记忆层——
- 每个零件族一个**原型**（该族的经验中心）
- 新样本按 **EMA** 并进原型，样本越多更新越稳
- 判决走**原型 + 最近邻混合**：纯原型会把 M5x8～M5x50 平均成一个点，纯最近邻又不会随学习收敛
- **写入门禁**：只有生成的方案通过校验才准进记忆，候选和失败只进候选池

**现有证据**（可复现，`pytest tests/test_meta_memory.py`）：
- 纯裸型号口径（去掉提示词里的族名线索）：**1.0000**，1-NN 基线 0.9891
- 困难版增量（原型冻结后按序灌 10/50/200 条/族的真实流）：**max_drop = 0.0000**，没有一族掉分

**缺口**：现在记忆里的 1816 条是我们自己造的提示词。要证明在企业里管用，得灌企业的真实任务记录。

---

### 创新点 ②：AI 接入 CATIA 与「企业专属」MCP Server

**命题**：不把 CATIA 当黑盒，而是通过 MCP 协议把 CATIA 的建模能力开放给 AI Agent 调用。

**技术实质**：
- MCP（Model Context Protocol）是 AI 与外部工具之间的标准接口。业界做法多是接通用软件（浏览器、数据库），
  **接工业 CAD 的很少**，因为 CAD 的 API 是 COM 对象模型、线程敏感、失败模式复杂。
- 我们做的是把 CATIA 的能力拆成**受限工具**：每个工具明确输入字段、单位、成功条件，
  AI 只能在这些工具里选，不能凭空生成脚本。

**现有证据**（`ai_modeler/catia_mcp/tools/`，共 **83 个工具函数**）：

| 模块 | 工具数 | 能力 |
|---|---|---|
| `sketcher` | 11 | 建草图、线、矩形、圆、约束 |
| `part_design` | 15 | 凸台、凹槽、旋转、沟槽、倒角、圆角、孔、阵列 |
| `gsd` | 24 | 点、线、面、偏移面、几何集管理 |
| `assembly` | 9 | 加零件、加约束（固定/重合/偏移/角度） |
| `measurement` | 6 | 测距、惯量、包围盒、参数读写、更新 |
| `export` | 4 | 导出、截图、设视图、适应窗口 |
| `document` | 9 | 连接/断开、新建 Part/Product、开/存文档 |
| `modeler` | 5 | 自然语言预览、特征表、自然语言建模、catalog 搜索、几何检查 |

**缺口**（这是「企业专属」四个字的分量所在）：
1. **版本差异**：企业实机是 CATIA **2016**，我们本机是 V5-6R2023（5.33.0.22133）。API 有差异，没在企业机上验过。
2. **部署形态**：现在 MCP server 跑在我们自己电脑上；「企业专属」要求部署进企业内网、对接企业许可与模板。
3. **企业模板**：Part / Product / Drawing 模板、命名规范、标准件 CATALOG 路径，都得按企业的来。

---

### 创新点 ③：真实工业焊接流程数据库 + 专属 AI Agent + Working Flow

**命题**：把企业焊装夹具设计的真实流程，做成可执行、可检查、可复用的工作流。

**技术实质**：
- 不是「录个宏重复点击」，而是把流程拆成**五阶段 + 门禁**：
  前置不满足不进下一步、固定基准锁死、参数一改下游结论全作废、**检查未通过不许进复核**。
- 每阶段有明确产物（点位表、结构方案、参数表、装配关系、校核记录），
  结论按 `通过 / 未通过 / 未运行 / 不适用` 四分，**不合并成一句「已完成」**。

**现有证据**：
- `ai_modeler/workflow/`：五阶段状态机 + 8 条工程规则 + 单元记录导出
- 默认案例 UN200 气动夹紧单元能跑通「间距不足 → 拦下复核 → 修正压臂 → 放行」全流程
- 自检 47/47 全绿

**缺口（最大）**：
「数据库」现在是空的。我们只有一个演示案例、一段企业全流程视频、一批基础工件三维模型。
**流程数据、设计规则、失败案例都没有结构化**——这是第 3 个创新点目前最薄的地方。

## 二、向企业索取的资料清单

> 原则：**只要「结构」，不要「配方」**。工位号可以脱敏，坐标可以整体平移，
> 我们只需要知道『这一步的输入、操作、判据、输出分别是什么』。
> 优先级：P0 = 没有就做不下去；P1 = 有就明显变好；P2 = 锦上添花。

### A 组 · 支撑创新点 ③（最缺，优先提）

| # | 资料 | 用来做什么 | 期望格式 | 优先级 |
|---|---|---|---|---|
| A1 | **一个完整工位的 PRP 定位夹紧点数据** | 五步流程第 1 步的真实输入；现在只有演示点 P01/P02 | Excel/CSV：点位号、X/Y/Z、夹紧方向、固定/可调、可调范围 | **P0** |
| A2 | **该工位的焊装工艺文件** | 判「这个夹具为什么这么设计」；焊枪避让、开合角度都从这来 | 焊点表（焊点坐标+焊枪型号）、工序顺序、节拍要求 | **P0** |
| A3 | **该夹紧单元的 BOM / 装配树** | 第 2、4 步的结构分解与零件分类（自制件/外购件/标准件） | CATProduct 结构树导出，或 Excel 层级表 | **P0** |
| A4 | **夹具设计规则手册**（企业内规） | 把视频里的「5 mm 间距、3 mm 余量、15°」这类示例值换成真实企业标准 | 文档即可；哪怕只有几条常用的 | **P1** |
| A5 | **1–2 个返工/出错案例** | 最有价值的数据：训练「什么时候该停下来问人」 | 口头讲解 + 截图/模型，我们整理成结构化记录 | **P1** |
| A6 | **标准件/外购件选型表** | 第 2、4 步的选型依据；现在用的是公开手册数据 | Excel：型号、规格、接口孔系、使用限制 | **P1** |
| A7 | **企业现有的命名规范** | 文件、特征树、参数名的规定；决定输出能不能直接进企业流程 | 一页纸即可 | P2 |

### B 组 · 支撑创新点 ②（CATIA / MCP）

| # | 资料 | 用来做什么 | 期望格式 | 优先级 |
|---|---|---|---|---|
| B1 | **企业 CATIA 的确切版本号 + 补丁号** | 我们本机是 V5-6R2023，企业是 2016，要确认 API 差异范围 | 关于界面截图 | **P0** |
| B2 | **Part / Product / Drawing 模板文件** | 生成的模型要能直接进企业流程，就必须套企业模板 | .CATPart / .CATProduct / .CATDrawing 空模板 | **P0** |
| B3 | **一次远程/现场联调机会** | 在真实企业环境跑一次连接+建一个简单零件，是「专属」二字的唯一证明 | 约定时间 + 一台测试机 | **P0** |
| B4 | **企业 IT 策略** | 能否装外部程序、能否开 COM 自动化、安全软件白名单 | 口头/邮件确认 | **P1** |
| B5 | **企业标准件 CATALOG 库路径** | 让 MCP 的 catalog 搜索直接对接企业库 | 路径 + 库文件 | **P1** |

### C 组 · 支撑创新点 ①（元增量学习）

| # | 资料 | 用来做什么 | 期望格式 | 优先级 |
|---|---|---|---|---|
| C1 | **历史建模任务记录** | 元记忆的真实「经验」；现在只有我们自己造的提示词 | 哪怕是 Excel：任务描述、零件类型、用时、返工次数 | **P1** |
| C2 | **企业常用零件族清单** | 校准记忆的族划分；我们现在的 19 族是从公开手册推的 | 一页清单，标注哪些是高频 | **P1** |
| C3 | **设计人员的口语化描述习惯** | 决定提示词特征怎么设计；工程师不会说标准术语 | 几条真实对话/聊天记录（脱敏） | P2 |

## 三、怎么跟企业开口（话术要点）

1. **别一次全要**。先要 A1 + A2 + B1 + B2 这四项，半天就能给，也够我们推进一个月。
2. **强调「结构不要配方」**：我们要的是「这一步输入什么、判什么、输出什么」，不是企业的工艺参数值本身。
   涉密的地方，工位号可以改成 W01，坐标整体平移，我们只验证方法。
3. **说清用途边界**：数据只在我们本地训练与验证，不上云、不外传；交付物是**规则和流程模板**，不复制企业模型。
4. **给对方一个交换**：我们把这个工位的流程做成可执行的工作流原型，回给企业试用——
   这是备忘录里「共同打造桌面 AI 辅助建模软件」的兑现。
