# 高难度 / 极高难度 建模测试清单

> 这张清单专门测**中等以上**的零件：齿轮传动、曲柄连杆、配气机构、叶轮、
> 涡旋盘、转子发动机转子这些。基础件请用 `建模测试清单.md`，
> 中等件请用 `复杂零件建模测试清单.md`。

**怎么用**：把「中文描述」那一列原样复制进程序的输入框，按回车。
「实测尺寸」是程序自己建出来量到的（已跑过一遍），你输进去应该得到同样的数字。

**图例**：✅ 正常 ｜ ⚠️ 能建出来但和预期不符 ｜ ❌ 没建出来

建好的模型可以在 `零件截图/` 里对照着看形状对不对。

## 重点看什么

1. **齿形**：斜齿轮的齿要从侧面能看出是斜的，锥齿轮的齿高要沿轴向收小。
2. **偏心**：曲轴的连杆颈必须明显偏离主轴中心线，相邻两拐方向相反。
3. **相位**：凸轮轴上每个凸轮的凸起方向要错开，不是全部朝一个方向。
4. **扭曲**：叶轮叶片是扭的；涡旋盘是一条绕好几圈的螺旋墙。
5. **小数**：带小数的尺寸必须原样保留（旧版会把 `94.33` 截成 94）。
