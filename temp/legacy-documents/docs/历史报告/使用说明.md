**升级后需要知道的三个行为变化：**

1. **不会再卡死** —— 任何输入最多算 30 秒，超时自动中止并告诉你为什么；右上角有「■ 停止」随时可中断。
2. **不认识的描述不再乱建** —— 以前 `M8 内六角螺栓` 会被默默建成一个 8×8×8 方块；现在先去联网搜索，查到参数后**你确认才建**。
3. **大模型不再是主角** —— 内置规则引擎瞬时且确定，能认出来就用它；只有它不认识的说法才交给 AI（本地或云端），所以常规输入快了一个数量级。

**一、精度：这次修的是硬伤**

以前只要尺寸带小数就会**悄悄出错**。`垫圈 内径18.37 外径82.38 厚度10.47` 建出来是 82×82×10 ——
小数点被断句逻辑当成了句号，数字被切成两半。现在这类输入全部按原值建模。

**二、零件库：29 类汽车 / 机械标准零件，带真实参数**

| 分类 | 零件 |
|---|---|
| 支承 | 深沟球轴承、圆锥滚子轴承、调心球轴承、推力球轴承、圆柱滚子轴承、轴承座、轴套、胀紧套 |
| 传动 | 直齿圆柱齿轮、同步带轮、链轮、多槽带轮、蜗杆、花键轴、平键 |
| 弹性 | 螺旋弹簧、锥形弹簧、碟形弹簧、O形圈、油封 |

| 连接 | 法兰、垫圈、联轴器、螺栓、螺母、挡圈、离合器摩擦片 |

参数来自《嘉立创FA机械设计手册》（453 条真实规格记录）。**右侧「零件库」页签**可以搜、可以双击直接生成。

**三、界面：新增深色模式**

菜单 **视图 → 深色模式**，重启界面后生效（配色会写进 `config.json`，下次打开还是深色）。

**四、速度：三个零件重写了算法**

| 零件 | 改法 | 效果 |
|---|---|---|
| 蜗杆 | 螺旋管走布尔并集 → 轴身和齿**合成一个网格**输出 | 12 秒 → 0.04 秒 |
| 辐条手轮 | 逐根辐条布尔并集 → **网格组合**，外圈轮毂改单次回转 | 7661 面 → 352 面 |
| 多槽带轮 | 圆柱逐个切 V 槽 → **把轴向剖面一次性画出来再整体回转** | 十几秒 → 0.006 秒，且完全精确 |

**五、实测命中率**

258 条评测用例（覆盖 20 个零件类别，尺寸比对容差 2%）：

| 轮次 | 说明 | 命中率 |
|---|---|---|
| R1 | 只用通用中文规则，不认识标准零件 | 10.85% |
| R2 | 接入零件库 | **100.00%**（258/258） |

另有两份可自己跑的清单：

· `建模测试清单.md` —— 43 条基础功能（全通过）
· `复杂零件建模测试清单.md` —— 33 条中等难度（**33/33 全通过**）

同一批用例换 5 组随机种子（参数值与措辞模板全换）重跑，**全部 258/258**，不是只对某一组数据调出来的。

这一轮还顺带修掉了两处**真实几何缺陷**（是改模型，不是改期望值去凑分数）：

1. **花键轴**：齿顶原先是一根**弦**而不是圆弧，跨齿测量会比大径小一圈；而且 6 齿这类齿数
   不能被 4 整除时，齿顶不可能同时对准 X / Y 两轴，包围盒比大径小 4% 以上。
   现在齿顶改成以 D/2 为半径的**真圆弧**，整体相位再转 step/4 —— 齿数 4/6/8/10/12
   量出来都是大径的 99.8% 以上。
2. **锥形弹簧**：锥形螺旋的“最大外径”原先只在某一个方位出现，转 90° 已经收缩了。
   现在**第一圈保持圆柱**（真实锥簧本来就有圆柱起始圈），X / Y 两个方向都能量到标称外径。

界面的实拍图在 `reports/ui_dark.png` 和 `reports/ui_light.png`。

**五、这一轮修掉的真 bug**

1. **斜齿轮算不出来**：扭转齿廓上全是近似共面的面，拿它做 BSP 布尔差集实测 **45 秒不返回**。
   改成把中心孔**直接画进几何**（自己做法向正确的内外壁 + 圆环端面三角化），同一件事 0.03 秒完成。

### 数据来源说明（如实交代）

知识库来自开源站点 **嘉立创FA机械设计手册**（`https://www.jlc-jdgf.com/mcbook/`），
已经全量抓取 **6893 页**、逐表展开合并单元格，再按类别筛出**真实规格记录 453 条**。

抓完之后发现一件事，值得说清楚：**手册对不同类别公开的数据形态完全不一样。**

| 零件类别 | 手册里的形态 | 能否直接当规格用 |
|---|---|---|
| 深沟球轴承 / 角接触球轴承 / 圆柱滚子轴承 / 调心球轴承 / 胀紧套 / 轴套 … | 现成的尺寸表（内径·外径·宽度） | ✅ 直接建成规格记录 |
| 花键 | **公差与偏差表**（上下偏差、公差等级） | ❌ 只有公差，没有名义尺寸 |
| 齿轮 / 蜗杆 / 锥齿轮 | **几何计算公式表**、术语代号表 | ❌ 是公式不是数表 |
| 弹簧 | 材料强度表 + **参数标准系列** | ⚠️ 系列可用，单件规格要自己组合 |
| 曲轴 / 活塞 / 连杆 / 万向节 | 手册里**没有** | ❌ 这些不是标准件，本来就没有国标尺寸表 |

所以我们做了两件事：

1. 能从表里抽的，全部抽进 `kb/auto_parts.json`（453 条，带原始页面 URL 可追溯）。
2. 抽不出来的，抽出**标准系列数值**放进 `kb/spring_series.json` —— 比如弹簧中径系列
   **94 个标准值**、压缩弹簧有效圈数 **36 个**、自由高度 **84 个**。自测用例的弹簧参数
   就是从这个真实系列里挑的，不是随手编的数字。

高难度零件的**参考外形**（曲轴、叶轮、涡旋盘这些）因此来自**参数化定义**，
和中等难度零件一直以来的做法一致 —— 这也是 `tools/evaluate.py` 里写明的口径：
参考值由零件定义直接算出，与自然语言解析器无关，所以它检验的仍然是“能不能听懂人话并建对”。

如果你手上有更全的开放数据源（比如某个标准件厂商的开放 API），告诉我，我可以再接一路。

## 一、先搞清楚：这个程序是什么

它把**一句中文**变成**一个三维模型**：

    「画一个 120×80×15 的长方体, 四角圆角 R8, 中心打一个直径 20 的通孔」
                                  ↓
              特征树 → 布尔运算 → 三维模型 → 可导出 STL

**它自带几何内核**，因此：

| 能力 | 需要 CATIA 吗 | 需要联网吗 | 需要付费吗 |
|---|---|---|---|
| 中文建模、三维预览、改尺寸 | 不需要 | 不需要 | 不需要 |
| 导出 STL / OBJ / 工程文件 / 建模报告 | 不需要 | 不需要 | 不需要 |
| 不认识的说法自动联网查参数 | 不需要 | 需要 | 不需要 |
| 本地 DeepSeek 理解口语 | 不需要 | 不需要 | 不需要 |
| 云端 DeepSeek V4.1 理解口语 | 不需要 | 需要 | 按量付费（很便宜） |
| 在 CATIA 里自动重建模型 | 需要 | 不需要 | 需要 CATIA 授权 |

> 它不是 CATIA 的替代品，也不是 CATIA 的破解。它是**独立的三维建模工具**，
> 另带一条把模型"搬运"进 CATIA 的通道。

## 三、三步上手

**第 1 步**　左上角输入框写中文：

    画一个 120×80×15 的长方体, 四角圆角 R8, 中心打一个直径 20 的通孔

**第 2 步**　点 **「⚡ 生成模型」**（或按 `Ctrl+Enter`）。中间立刻出三维预览，
右边「统计」页显示外形尺寸、体积、表面积。

**第 3 步**　特征树里点中某个特征 → 右侧「参数」页改尺寸 → 「应用参数」立即重建。
满意后在「文件」菜单导出 STL。

### 4.5 写法约定

- 单位默认毫米；`cm` / `米` / `英寸` 会自动换算。
- 数字和单位之间可以有空格；`×` `x` `*` 都表示乘。
- 多句用逗号、句号、"然后""接着""再"分开，**从上到下顺序执行**。
- 没写全的尺寸自动补默认值（长宽高默认 100/60/20）并在日志里提示。
- 圆角/倒角目前作用于**长方体、齿轮、轮廓拉伸**的竖直棱。
- 叶盘用网格组合模式（叶片之间不做布尔运算），预览和打印没问题，体积统计会略偏大。

### 8.2 已经替你做好的通道

**通道 A：CATIA 宏插件（推荐）**

- 插件已装在 `catia_plugin\AI自动建模助手.CATScript`（并按当前 Python/目录生成，UTF-16 编码）
- CATIA 里：**工具 → 宏 → 宏… → 查找范围选 `catia_plugin` 目录 → 文件类型 CATScript → 运行**
- 想让它常驻宏列表：**工具 → 选项 → 常规 → 宏 → 宏库 → 添加** 该目录
- 宏只用了 Sketch/Pad/Pocket/Shaft 四个最稳的 API，每次切除会**测体积自动纠正方向**

**通道 A+：CATIA 模型库（catalog 标准件库）**

- 助手内浏览：**工具 → CATIA 模型库（catalog 标准件）…**（支持中文检索：机器人 / 输送线 / 模具 / 标准件…）
- CATIA 内插入：**工具 → 目录浏览器 Catalog Browser → 浏览其他目录 → 选 `.catalog` → 双击插入**
- 命令行：`python -m ai_modeler --catia-lib --search 标准件`

**通道 B：导出自动化脚本**

文件 → 导出 CATIA 自动化脚本 → 拷到装有 CATIA + pywin32 的机器上运行。
阵列会被**展开成显式特征**（不依赖版本相关的阵列 API），逐条报告成败。

**通道 C：从助手直接建到 CATIA（本次新增，推荐）**

在助手里输完描述、看到三维预览后，点工具栏 **「推送 CATIA」**：助手会在 CATIA 里新建 Part 文档并
逐条重建特征，还可以顺手另存为 `.CATPart`。走 Windows 自带的 `cscript` + COM，**不需要 pywin32**。

命令行：`python -m ai_modeler --push "法兰 外径 160 厚 20 内径 60, 均布 6 个直径 12 的螺栓孔" --save 法兰.CATPart`

> **零件库零件也能直接建到 CATIA**：41 类里 **38 类**可导出（三角转子、曲轴、凸轮轴、飞轮、
> 各种齿轮/轴承/法兰…，能近似的会在提示里列明哪一部分被简化）。
> 只有 **螺旋弹簧 / 锥形弹簧** 不行 —— 它们本质是螺旋扫掠，请用 CATIA 的「螺旋 + 扫掠」或 STL 导入。
> 覆盖自检：`python tools\check_catia_coverage.py -v`

**通道 A 的两个前提（本次真机联调修复）**

1. 宏文件必须是**纯 ASCII + CRLF**：CATIA 的 CATScript 加载器不接受 UTF-16/BOM，否则整份脚本会被
   读成一个 `?` 并报 `无效字符 / ScriptingERR_1002`。所以中文输入框改由 Python 提供。
2. 中文版 CATIA 的零件几何体不叫 `PartBody`、偏移平面上的草图要先 `OpenEdition`、
   建实体特征前要把在制品切回实体 Body —— 这些坑都已在 `catia_plugin\catia_build_core.vbs.txt` 里处理好。

> 验证情况：以上两条通道已在 **CATIA V5-6R2023 (B33)** 真机上跑通
> （助手侧 8/8 个特征建模完成 + 另存 .CATPart；宏侧同一份构建核心同样 8/8）。

## 九、联网搜索模式（v1.0.2 新增）

内置词库不认识的说法（`M8 内六角螺栓`、`6204 轴承`、`4040 铝型材`），程序会自动：

1. 去 Bing 检索（不需要 API Key）
2. 用**中文二元词过滤**掉不相关内容（不会把"问界 M8 汽车"当答案）
3. 打开详情页，从正文抠出直径/长度/厚度/齿数/模数
4. 弹窗给出**建议描述**，你点「用这条描述建模」才建

它认识的型号写法：M8→公称直径 8 · 6204 轴承→内径 04×5=20 · 4040 型材→截面 40×40 ·
M12 螺母→对边约 19.2。

菜单 **工具 → 联网搜索设置** 可关掉（关掉后完全不发网络请求）；
**工具 → 手动联网搜索** 可随时对任意文字搜。

> 搜出来的都是工程估算，用来快速起形状；精确尺寸以手册为准，在参数页微调。

### 10.2 云端 DeepSeek V4.1-Flash（v1.0.3 新增）

2026-09-10 官方发布，1M 上下文、原生多模态、JSON/Tool Calls 全支持，
价格缓存命中 0.02 元/百万 tokens 起。

配置方法：工具 → AI 大模型设置 → 点 **「DeepSeek 官方 API (V4.1 Flash)」** →
去 <https://platform.deepseek.com> 拿 API Key 填上 → 保存。

#### ⚠️ 关于模型名的坑（很多人会困惑）

官方价格页原文：

> 模型名请使用 @@deepseek-flash@@。旧模型名 @@deepseek-v4-flash@@、
> @@deepseek-v4-flash-vision-exp@@ 仍可调用，但对应模型已下线，
> 请求将由 DeepSeek-V4.1-Flash 模型提供服务，并按 Flash 价格计费。

也就是说下面这些名字**拿到的是同一个模型**：

| 你看到的名字 | 实际是什么 |
|---|---|
| DeepSeek-V4.1-Flash | 官方**显示名**（模型版本号） |
| @@deepseek-flash@@ | 官方**正式 API 名** ← 推荐 |
| DeepSeek-V4-Flash / @@deepseek-v4-flash@@ | 旧名，已下线，请求被路由到 V4.1-Flash |
| DeepSeek-V4-Flash-Vision-Exp | 旧名，同上 |

**为什么不同人的客户端显示的名字不一样？** 模型列表由**后端下发**，
新客户端显示 "DeepSeek-V4.1-Flash"，旧客户端可能还显示 "DeepSeek-V4-Flash"。
**模型本身是同一个**，不用纠结名字。

同家族的 **DeepSeek-V4-Pro-0813**（API 名 @@deepseek-v4-pro@@）能力更强、
不支持图像、价格约 4.5 倍。

## 十二、常见问题

**Q1 双击快捷方式没反应？** 用 `启动 AI自动建模助手(带控制台).bat` 看报错。

**Q2 提示未找到 Python？** 装 Python 3.9+（勾选 Add Python to PATH），重跑 `安装桌面快捷方式.bat`。

**Q3 输入的内容没建出来 / 画面没变？** v1.0.2 已修复所有已知的此类问题（见版本变化表）。
现在的行为是：规则引擎 →（失败）→ 本地/云端 AI →（失败）→ 联网搜索给建议。
实在不行看「日志」页，每一步都有记录。

**Q4 模型算得慢？** 法兰类复杂件约 0.7 秒属正常。超过 30 秒会自动中止并给建议。
也可以把「圆周分段」从 48 调到 24。

**Q5 导出的 STL 能直接打印吗？** 能。唯一例外是叶盘（壳体有重叠），切片软件一般能处理。

**Q6 为什么没看到我写的圆角？** 圆角/倒角是修饰，加到上一个基本体上，不单占一行。

**Q7 本地 DeepSeek 突然没反应？** 程序会自动回退到规则引擎+联网搜索，不会卡。
重启本地服务：`python tools\install_deepseek.py --check` 查看状态。

**Q8 界面右侧面板显示不全？** 换到新版（v1.0.1 起有高 DPI 自适应）。若仍异常，把窗口拉大即可。
