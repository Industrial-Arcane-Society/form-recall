FormRecall 0.2.0 带来新的 Windows 原生建模工作台。

- 默认桌面迁移到 Go/MyGo，使用自定义窗口栏、SVG 图标和深灰配色。
- 重新设计设置页面，加入面板、设置和相机过渡动画，支持系统减少动画偏好。
- 原生三维视口显示模型、边线、网格和坐标轴，修复界面绘制层覆盖模型的问题。
- Windows x64 免安装包包含 Rust 建模引擎、OCCT、DSH 离线运行时及 CATIA 私有 Python 依赖。
- 发布流程增加版本校验、文件 SHA-256 校验、隔离启动和四孔底板建模检查。

首次使用请下载 portable ZIP，解压后运行目录内的 `FormRecall.exe`。独立 EXE 用于替换兼容便携目录中的桌面程序，使用时需要同目录的引擎和运行资源。跨版本升级建议使用完整 ZIP。

Quick 建模可使用本地运行资源。Agent 功能需要在设置中配置模型服务。CATIA 导出需要本机已注册 CATIA COM。

原生桌面已有独立测试和成品验证。Rust 核心全量测试仍有已记录的 23 项基线失败，外部模型服务和 CATIA COM 实机导出需在相应环境验收。
