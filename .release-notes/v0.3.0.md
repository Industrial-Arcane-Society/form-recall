## FormRecall v0.3.0 正式版

这是继 v0.2.0 之后的正式版，将 v0.3.0 测试阶段的应用内更新带到 Windows x64 正式渠道。同时提供完整安装包和免安装包。

### 应用内更新

- 在「设置 → 更新」可手动检查新版本，也可启用或关闭自动检查。支持 Alpha、Beta、RC 和 Release 四个渠道，所选渠道和自动检查偏好会保留。
- 在应用内下载并查看进度。确认重启后，更新器在后台切换版本，无需打开安装向导。测试渠道间切换到同一版本线的较低版本时，需单独确认「重启并降级」。
- 更新器会验证分发清单签名、下载包和组装后的文件。有适用增量时优先使用增量，增量缺失或基线校验失败时下载完整便携包。新版本在独立目录准备，建模引擎就绪后才切换活动版本。启动失败时继续使用原版本。

### Windows 交付

| 文件 | 使用方式 |
| --- | --- |
| `FormRecall-0.3.0-windows-x64-setup.exe` | 完整安装包。支持简体中文和英文安装向导、选择安装位置、开始菜单和可选桌面快捷方式，以及系统卸载入口。默认安装到当前用户目录。 |
| `FormRecall-0.3.0-windows-x64-portable.zip` | 完整免安装包。将压缩包完整解压到新目录，再运行其中的 `FormRecall.exe`。 |

两种交付均包含桌面程序、Rust 建模引擎、OCCT 运行库和配套资源。下载后可用本页的 SHA-256 校验附件。

### 如何升级到正式版

- **v0.2.0 或更早的正式版**。下载 v0.3.0 完整安装包或完整便携包升级。升级前保存打开的工程。
- **Alpha、Beta、RC 测试版**。建议这次用完整包切换到 v0.3.0，以免受旧更新清单格式或缺少直达增量的影响。启动后在「设置 → 更新」确认当前版本为 v0.3.0，并选择 **Release** 接收后续正式版。
- 应用内更新沿用现有用户数据目录。采用安装版时，「设置 → 更新」显示实际运行版本，Windows 已安装应用列表显示最近一次通过安装向导安装的版本。

主仓库的 Release 提供完整包。[OTA 分发仓库](https://github.com/Industrial-Arcane-Society/form-recall-release) 提供各渠道的签名清单和应用内更新附件。正式版增量面向符合条件的旧正式版和同版本线最近的 RC，实际可用路径以签名清单为准。
