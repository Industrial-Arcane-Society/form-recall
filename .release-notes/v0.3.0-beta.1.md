## FormRecall v0.3.0-beta.1

这是首个 Beta 测试版，重点验证从 Alpha 切换到 Beta 后的检查、下载和重启更新。

### 更新体验

- 「设置 → 更新」可选 Alpha、Beta、RC、Release。自动检测可以关闭，手动检查仍然可用。
- 检查更新优先读取 GitHub 内容 API 上的签名清单，减少频道更新后因 Raw 缓存造成的延迟。
- 新版在独立目录准备并校验，等工程保存、桌面和建模引擎退出后，由后台更新进程完成切换。应用内更新时无需经过安装向导。

### 如何测试

1. 使用 **Alpha.4 完整安装包或完整便携包**启动 FormRecall。由 Alpha.1–Alpha.3 通过 OTA 升到 Alpha.4 的安装，需要先用完整包更新根目录启动器。
2. 打开「设置 → 更新」，将更新渠道切到 **Beta**，检查是否发现 v0.3.0-beta.1。
3. 点击「下载更新」，完成后选择「重启并更新」。重启后在更新页确认版本，打开已有工程或生成一个模型。

本次是首个 Beta，Alpha → Beta 会下载约 232 MB 的完整便携 ZIP，由应用内更新器解压应用。同一渠道有匹配差分时，客户端优先下载增量。已开始使用 Beta.1 的用户也可以直接下载本页完整安装包或便携包。
