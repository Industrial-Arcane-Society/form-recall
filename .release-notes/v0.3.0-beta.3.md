## FormRecall v0.3.0-beta.3

这一版收敛了更新分发格式。每个渠道使用一个签名清单，分发 Release 只提供一份 update.json。增量附件采用「来源版本 → 目标版本」命名。多个旧版本需要相同文件时共用一个附件，适用版本在分发说明中列出。

- 测试版最多覆盖时间线上最近八个可升级的测试版本。
- 增量不可用、过大或校验失败时，更新器下载完整便携 ZIP 并在后台应用。
- 同一版本线的跨渠道降级需要在更新页主动选择「重启并降级」。

### 如何升级

本次更新清单格式有破坏性改动。请下载本页完整安装 EXE 或便携 ZIP 升级一次。启动新版后可继续使用「设置 → 更新」。

Beta.3 能读取历史签名清单作为降级目标。切换到使用旧更新格式的历史版本后，恢复新版需启动 Beta.3 完整包。
