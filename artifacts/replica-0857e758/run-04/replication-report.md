# 第四轮复刻记录：多图输入未被 Agent 正确利用

## 结论

本轮没有进入建模。DSH Agent 只调用了一次 `cad_get_state`，随后以“只看到第一张等轴图”为由要求用户补传其它三张图，并结束了会话。`CADPlan` 为空、`revision=0`、没有预览或模型输出，因此本轮未通过验收。

## 核对结果

- 调用 `run_dsh_agent` 时传入 4 个有效图片路径，返回记录 `image_parts_in_request=4`。
- DSH durable attachment store 内实际生成了 4 个对象，字节数分别与四个原始 PNG 对应（17,082、10,260、7,598、5,173）。因此不是 runner 漏传路径或文件缺失。
- Agent 回复仍称只看到 image-1 的等轴视图，并未尝试按现有图先建候选。
- 从开始到结束约 2 分 24 秒，思考流约 15,500 个字符；结束状态为 `conversation`，不是建模错误或复核失败。

## 当前判断

代码确实向 DSH SDK 传了四个 image content block，SDK 的附件层也接收了四张图，但模型最终表现为只看见第一张。现有运行结果不足以证明具体是哪一层丢弃了后续视图；可以确定的是“调用参数里有 4 张”并不保证 Agent 正确使用了 4 张。

## 已实施的修正方向

第五轮起，`dsh_agent` 会把多张原图按原比例排成带 `REFERENCE 1..N` 标记的一张拼版，并把拼版作为单个图像块发送给 Agent；CAD 多模态复核仍保留并读取原始四张图。返回值现在区分实际送出的图像块数、原始参考图数和输入方式，避免再把路径数误报成模型可见图片数。

## 验收要求

下一轮须确认 Agent 能描述拼版中多个视图并开始建立特征；若它仍把拼版当成只有一个视角，继续修正 DSH 输入链路，不进入尺寸猜测或建模评分结论。
