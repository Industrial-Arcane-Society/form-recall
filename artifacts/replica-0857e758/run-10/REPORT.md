## 观察到的问题

1. **复核描述与原图冲突时，Agent 仍采信复核文本。** 提示已经明确要求以图片证据为准，但模型仍新增六角法兰；分数因此改善，几何却偏离原图。
2. **评分不是可靠的收敛条件。** 正视 82 分仍带有可见差异；分数与逐项 evidence 不一致。应由程序用 evidence 严重度校正通过状态，并要求同一几何版本的各视图证据齐全。
3. **跨视图回归没有固定版本基线。** front、iso、top、bottom 的最新记录来自不同 revision，导致 Agent 在修一个视图后没有证明其他视图仍正确。
4. **推理输出仍然很长。** `minimal` 下约 53k 字符，79 次工具调用和多轮重复预览/复核仍耗时约 25 分钟。
5. **取消后的快照路径需要补强。** 本轮进程中断后，自动脚本没有把 CAD 状态和预览复制到 run 目录；本报告所列两个文件是从 DSH session 手工保存的。
