# 第三轮复刻记录：参考图复核提示词污染

## 结论

本轮由项目内 DSH SDK Agent 根据四张参考图建立了候选模型，但没有通过自审查，也没有调用 `cad_finish_model`。因此没有生成可交付的 AIMODEL/STL，不能视为复刻完成。

这轮的主要失败不是回转几何工具，而是多模态复核提示词仍带着上一个方块工件的固定要求。复核器要求检查“正面中间退台”和“3×3 孔位”，并把这些未在当前定位销参考图中得到支持的结构当成差异。Agent随后反复改动主体轮廓，分数长期停在 45–75/100，收到的是错误返修方向。

## 本轮运行事实

- 输入：`references/image-1.png` 至 `image-4.png`，通过 DSH SDK 作为多模态图像输入。
- DSH 模型：`moonshotai/Kimi-K2.7-Code`，推理强度 `high`；当前代码未显式提供预算时使用 2048 默认预算。
- Agent 建立的特征：一个完整 `revolve` 主体、一个六边形 `prism` 法兰、一个同轴圆锥切除，共 3 项。
- 最终快照：revision 24，尚未完成；本地预览包围盒约 `9.24 × 8.00 × 22.00 mm`。
- 前视外廓宽高比约 `9.24 / 22 = 0.42`；参考图 2 的可见外廓约 `115 / 374 = 0.31`。该比例仍未收敛。
- 运行事件记录有 14 次多模态视图审查，所有分数均低于 80；最后可见复核将参考图中的 3×3 孔阵列和中央退台列为要求。
- 本轮在 rev24 保存 CADPlan 和 iso/front/top 预览后停止。该状态只用于失败分析，不作为模型交付。

## 复核提示词错误证据

旧版 `dsh_mcp_server.py` 会在每个工件的独立视觉复核中固定要求检查：

- “正面中间退台的位置和方向”
- “孔数量/列行/孔径”
- “front 重点看正面宽高比例、3×3孔位与孔径”
- “中央有限深度退台”

rev20 的 iso 复核因此称模型缺少“正面中间退台”与“3×3孔位”；rev22 的 front 复核又把“3×3孔阵列”说成题目要求，并要求确认参考图中并不存在的孔阵列。这些内容来自复核器自己的旧任务提示，不是定位销图像证据。

## 已作修正

1. 把视觉审查规则改为先从当前图像识别对象与可见结构，不预设孔阵列、凹槽、圆头或尖头；只能将原图/用户文字支持的特征判作差异，视角看不到的内容列为不可观测。
2. 清除 Agent 系统提示中会把旧方块任务结构带入当前零件的固定方块/退台/孔阵列示例，改为通用的证据约束。
3. 增加跨 revision 的多模态审查历史，避免几何更新后只保留分数而丢失旧差异证据；当前 revision 的通过门槛仍按新几何版本单独计算。

## 下一步

以相同四张原图和修正后的复核提示词启动全新 DSH Agent 会话。要求它自行识别定位销的头部、法兰、柄部与端面特征，按正交图像比例估尺寸并标记 `image_estimate`，逐视图对照原图修正；只有几何比例合理且当前版本独立复核达到门槛，才保存为可交付结果。
