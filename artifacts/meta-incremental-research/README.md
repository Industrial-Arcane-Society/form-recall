# AI Modeler 迁移学习与增量记忆研究

2026-11-19 · 基线提交 `7e79fd8`

现有记忆模块对目录内的未见型号仍有较高的零件族识别准确率，但收益取决于是否限制样本存储、输入写法和类别出现顺序。三个结果决定下一轮研究重点：全量 1-NN 在型号隔离后总体领先混合记忆，进入新类别时个别旧族的召回会大幅下降，现有提示门槛会把部分库外型号当作历史经验推荐。本轮的小型情景式元学习对照也未提升平均成绩。主要证据来自目录提示词和独立的离线实验。

## 附件概念如何对应项目

| 概念 | 可检验的项目问题 | 原始研究 |
|---|---|---|
| 迁移学习 | 已有带族名的训练样本能否帮助识别新型号的裸编号。此处类别集合相同，变化来自输入写法。另一个更强的问题是跨企业、跨目录供应商迁移。 | [Pan 与 Yang，2010](https://doi.org/10.1109/TKDE.2009.191) |
| 持续或增量学习 | 后续加入新零件族或更新已有族时，能否兼顾新族识别和旧族保留。新增族属于类别增量，推理时不给任务身份。持续更新已有族是另一种实验阶段。 | [van de Ven 等，2022](https://doi.org/10.1038/s42256-022-00568-3) |
| 元学习 | 在一批训练任务的支持集与查询集上学习共享先验，再用少量带标签样本适应全新的类别。附件第二张图展示的是 MAML 式内外循环，元学习还可以学习用于分类的度量。 | [MAML，Finn 等，2017](https://proceedings.mlr.press/v70/finn17a.html) · [Prototypical Networks，Snell 等，2017](https://papers.neurips.cc/paper_files/paper/2017/hash/cb8da6767461f2812ae4290eac7cbc42-Abstract.html) |
| 元学习与持续学习结合 | 同时验证少样本适应与旧任务保留。SAM 先用优化式元学习获得共享先验，再通过自注意力选择表示，为各任务建立专用表示。MER 将经验重放与 Reptile 式元更新结合，鼓励有利于迁移的梯度方向一致。 | [SAM，Sokar 等，2021](https://arxiv.org/abs/2101.12136) · [MER，Riemer 等，2019](https://openreview.net/forum?id=B1gTShAct7) |

附件中 SAM 和 MER 的 Python 片段是带 `pass` 的结构示意。本次据论文核实算法含义。LwF 用旧模型输出进行蒸馏，iCaRL 将样本记忆、最近类均值和表示学习结合，PackNet 通过剪枝与参数掩码将不同任务的容量隔开。当前项目如果引入共享的可训练表示，应先与等预算的普通经验重放对照，才能估计元更新本身的贡献。[LwF](https://arxiv.org/abs/1606.09282) · [iCaRL](https://openaccess.thecvf.com/content_cvpr_2017/html/Rebuffi_iCaRL_Incremental_Classifier_CVPR_2017_paper.html) · [PackNet](https://openaccess.thecvf.com/content_cvpr_2018/html/Mallya_PackNet_Adding_Multiple_CVPR_2018_paper.html) · [普通经验重放基线](https://arxiv.org/abs/1902.10486)

## 代码审计

项目在旧版 Tkinter Agent 前面接了一个**增量原型与历史样本记忆**。编码由字符 2–4 gram、数字与手工族线索组成。字符块执行子线性 TF 和归一化，代码没有乘 IDF。已验证样本达到 3 条后创建族原型，此前已经可通过近邻参与预测。后续以 `max(0.05, 1/(n+1))` 更新并归一化原型，每族最多保留 32 条 exemplar。判决将族内近邻分数与原型分数按 0.6 和 0.4 混合。系统会更新族原型，特征映射和更新规则由代码指定，当前没有跨任务元训练，也没有对 DSH 或 LLM 权重做微调。[features.py](../../src/legacy/ai_modeler/meta/features.py#L346) · [memory.py](../../src/legacy/ai_modeler/meta/memory.py#L330)

旧 UI 在分类区分度达到 0.55 后注入预测族、经验包络和相似案例。`validation.state == "valid"` 控制样本能否更新原型，族标签由本地规则解析器给出，两项信号分别来自计划校验和规则判定。另有两个明确的边界：

- `suggest(k=3)` 的相似案例同时检索 exemplar 和未验证候选，返回字段没有验证状态。通过内存探针复现，写入同文本的未验证候选后，族和区分度保持相同，该候选以 1.0 相似度排到案例首位。离线分类实验用 `k=0`，因此分类指标覆盖不到这一条提示注入路径。[memory.py](../../src/legacy/ai_modeler/meta/memory.py#L452) · [app.py](../../src/legacy/ai_modeler/ui/app.py#L3381)
- 旧 UI 的历史数据导入显式保存记忆。Agent 一轮后的在线写入只调用 `observe`，退出处理也没有保存这份记忆。跨重启的在线知识积累缺少这条调用链上的落盘证据。新版 Tauri/DSH 的生产入口另走 Rust 会话和工具链，本轮评估的 Python 分类器位于旧版。[app.py](../../src/legacy/ai_modeler/ui/app.py#L3423) · [旧版退出处理](../../src/legacy/ai_modeler/ui/app.py#L3514) · [Tauri 工具入口](../../src/apps/desktop/src-tauri/src/lib.rs#L1552)

## 数据与评测口径

本轮实际读入 1,828 条提示词，其中 1,816 条属于 19 个族，来自 520 个型号，另有 12 条库外或模糊输入。提示词由目录及其几何记录生成，同一型号常有两到四种写法。EGT 型材有 1,156 条，占正例约 64%。旧全量留出复现为混合 99.72%、1-NN 99.72%，363 条测试提示词中有 355 条的型号也见于训练。README 的裸型号 92 条结果也可复现，其中没有同型号重叠。不过裸型号仍有明确的型号前缀，而且单独切分后模型训练用的语料不同。现有分组函数遇到训练条数下限会截断所抽到的组，在仅用裸型号的默认种子中只测试了 18 个裸型号族中的 12 个。[目录数据说明](../../src/legacy/datasets/训练提示词/说明_AI建模训练.md) · [旧评估切分](../../src/legacy/ai_modeler/meta/evaluate.py#L94)

新实验把归一化型号作为分组单位，并检查型号和归一化提示词均无交叉。先在各族留出约 20% 的型号，使用其余型号的写法拟合词表和记忆。同一次切分同时评估所有写法和裸型号子集。1-NN 使用同一套编码。全量 1-NN 有 1,444 条训练提示，限额版仅用混合分类器保留的 302 条实例或待建原型样本。各项是重复划分上的描述性均值，样本跨种子可重复出现。

## 一 未见型号识别与拒识

| 测试输入 | 每次测试数 | 混合准确率 | 混合宏 F1 | 全量 1-NN 准确率 / 宏 F1 | 限额 1-NN 准确率 / 宏 F1 |
|---|---:|---:|---:|---:|---:|
| 所有写法 | 372 | 99.38% | 94.85% | 99.70% / 97.69% | 97.82% / 97.08% |
| 裸型号 | 92 | 99.35% | 95.56% | 99.67% / 97.78% | 99.67% / 97.78% |

手动夹紧气缸只有两个型号。混合分类器在所有写法上的该族平均召回为 23.33%，裸型号为 40.00%。混合记忆提高了全量写法下的限额基线准确率，但宏 F1 低 2.23 个百分点。全量 1-NN 在两种口径的平均准确率和宏 F1 都更高，代价是保留更多样本。

旧 UI 使用的 0.55 门槛在已知正例上分别覆盖 94.44% 的全量写法和 81.52% 的裸型号。这两组被接受的已知正例均分对了族。与此同时，每次试验都有 6 个库外探针达到该门槛，包括 `EGT009 SW70x500`、`内六角螺栓 M14x88` 和 `定位销 KMS-M01-P999-A99`。可见阈值允许产生历史提示，但这些探针没有执行实际 Agent 请求。完整目录的规范化精确索引能命中 447/447 个目录裸型号并拒绝 12/12 个探针。索引使用了全部已知型号，适用于目录检索。对库外新型号，能否推断其族与能否验证其尺寸应分别判断。

## 二 输入写法迁移

在具有至少四个配对型号的 12 个族上，每次为各族抽三个支持型号候选。查询集固定为剩余 395 个裸型号，支持集取前 1、2 或 3 个型号。在匹配的两条训练分支中，支持型号和标签相同，只替换为裸型号写法或带类别词写法。分类器使用同一内置特征，10 个重复种子。

| 每族支持型号 | 裸型号作支持，宏 F1 | 带类别词作支持，宏 F1 | 同写法高出的百分点 |
|---:|---:|---:|---:|
| 1 | 85.99% | 81.78% | 4.22 |
| 2 | 91.17% | 86.47% | 4.69 |
| 3 | 96.43% | 88.24% | 8.19 |

已有带类别词的样本能提供分类线索。同等样本预算下，用裸型号作支持更适合裸型号查询。该实验比较的是把目录知识直接迁移到另一种输入写法的效果，尚未试验混合收集、输入去类名、跨企业或跨供应商的迁移增益。

## 三 类别持续进入与旧族保留

用 18 个有裸型号的族做类别流，按大族先来、小族先来和随机打乱测试 10 个种子，共 30 条序列。每族先学习最多三个不同型号，稀有族实际用 1–2 个，随后流入同族剩余训练型号。每个阶段用固定的 92 个隔离型号评测，推理不给任务 ID。表中“峰值到末尾下降”按 Chaudhry 等的思想取每个旧族已见阶段的最高召回减去引入阶段末尾召回，再按族平均。更新阶段报告引入结束到最终的差，负值表示净改善。[遗忘指标原论文](https://www.ecva.net/papers/eccv_2018/papers_ECCV/html/Arslan_Chaudhry__Riemannian_Walk_ECCV_2018_paper.php)

| 方法 | 引入阶段平均旧族下降 | 30 条序列中最坏单族下降 | 后续更新阶段平均变化 | 最终裸型号宏 F1 |
|---|---:|---:|---:|---:|
| 混合 | 0.52 pp | 72.73 pp | −1.06 pp | 100.00% |
| 同一保留池的 1-NN | 1.41 pp | 100.00 pp | −1.57 pp | 98.52% |

最差的混合序列出现在种子 1、大族先来。内六角螺钉刚引入时识别 11/11，随着其他族加入依次掉到 10/11、9/11、6/11 和 3/11，后续补充本族样本后恢复到 11/11。类原型彼此分开存储，新增其他族仍会改变分类竞争。旧版困难评估的三个默认流量设置也复现了最终 `max_drop=0`。这一数值和本次中途出现的退步可以同时成立。

## 四 未见类别的元学习对照

为检验跨类学习的额外收益，独立实现了一个小型情景式度量学习实验。编码用散列字符 n-gram 与六维数字向量，移除了项目手写的族线索。18 个裸型号族在每个种子划分成三折，每折用 12 个族构造 40 个训练情景，用剩余 6 个从未参加该折训练的族构造 20 个测试情景。每个情景为 6-way 1-shot，支持与查询型号分离。训练仅从五个候选数值权重中选择一个共享权重，测试使用同样的支持样本和最近原型规则。此实验评估跨类别少样本适应，与持续类别流分开运行。

| 表示 | 30 个折的测试平均宏召回 |
|---|---:|
| 情景式学习数值权重 | 92.86% |
| 固定数值权重 0.55 | 93.83% |
| 仅字符 n-gram | 94.93% |

学习权重相对固定权重平均低 0.97 个百分点，折内差异从 −7.08 到 +4.58 个百分点。所得权重在训练情景间变化。当前结果支持保留简单字符度量作为强基线。实验只评估共享单一权重的方案，SAM 和 MER 的迁移效果仍需各自复现。

## 对项目的判断

1. **目录型号走精确检索。** 对未命中时的族推荐单独校准拒识，在独立的同前缀近邻、超规格、拼写错误和新供应商型号上报告覆盖率及误接纳率。族预测成功后，尺寸和几何仍需证据。
2. **把可验证的案例和跨重启留存纳入实验。** 优先验证未复核案例是否会被注入，以及保存、重启和撤销后记忆是否与复核状态一致。对真实建模任务应固定模型与配置，比对关闭记忆、规则检索和有界记忆三种条件，分别记录族、型号、尺寸、特征及 B-Rep 几何结果。
3. **用独立企业或供应商样本检验元学习。** 现有目录提示词由固定模板生成，族前缀高度重复，长尾族样本很少。应先固定目录之外的盲测集、支持预算和阶段指标。只有在简单字符度量、1-NN 与等预算经验重放依然表现不足时，才有依据判断 SAM 或 MER 值不值得增加共享模型和训练复杂度。

## 复现

在仓库根目录用带 NumPy 的 Python 3.10 或更新版本运行：

```powershell
$env:OPENBLAS_NUM_THREADS = '1'
python artifacts/meta-incremental-research/benchmark.py --output artifacts/meta-incremental-research/results.json --seeds 10
```

[逐种子原始结果](results.json)记录源码提交、数据 SHA-256、已知与库外探针结果、各类召回和阶段轨迹。旧记忆单测 33/33 通过。本轮使用 Python 内存实例和仓库目录数据，评测目标为零件族推荐，未运行桌面端、LLM、CAD 生成或真实 CATIA 验收。

## 新版桌面端接入

新版 Rust Agent 将目录证据与建模经验分开。目录检索通过完整型号边界核对和已知别名返回来源，未知型号不返回近邻尺寸或视觉样例。案例库使用宿主当前验收结论，需由用户显式保存。相同描述从空白零件开始时，宿主可向 ACP 传递历史特征顺序，原始用户轮次记录仍保存原描述。案例可以关闭参考或逐条移除。[使用与数据说明](../../docs/05-operations/01-build-and-run.md#目录核对与已验收案例)

Rust 目录验收覆盖全部 447 个目录裸型号、12 个库外探针、相似前后缀及混合命中。案例验收复核了当前几何版本、文件持久化、重复保存、撤销、续话限制与开关，并通过本地 ACP 测试进程确认上下文可达。Vue 无头集成验证面板的保存、新建、关闭参考和移除。Rust 全套相较 `7e79fd8` 修复了纯文字首轮对图片缓存目录的依赖，其余 24 项失败在基线中可复现。真实模型服务、独立企业盲测和 CATIA 几何仍无本次实测结论。
