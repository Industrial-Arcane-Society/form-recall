# 手工 CADPlan 对照建模

## 建模范围

- 参考：用户提供的等轴测参考图；图中没有任何尺寸标注。
- 方法：人工读取参考图的可见结构和大致比例，直接构造 CADPlan，再调用项目现有 `validate_plan`、`_preview_internal`、`preview_plan`、`export_project` 和 `export_stl`。
- 未调用 AgentLoop、LLM/Kimi 或 CATIA；没有修改程序源文件。
- 所有毫米值都是图像比例推算出来的名义尺寸，不代表制造尺寸。

## 名义尺寸估算

以高度 340 mm 作为任意名义尺度：

| 几何量 | 名义值 | 图像依据 / 置信度 |
|---|---:|---|
| 总宽 X | 330 mm | 顶面长投影边约 258 px、竖直棱约 267 px；按同等缩短近似得 340×258/267≈329 mm，取 330 mm |
| 总深 Y | 134 mm | 顶面短投影边约 105 px；按同等缩短近似得 340×105/267≈134 mm，受透视/手工读点影响较大 |
| 总高 Z | 340 mm | 仅作为方便的归一尺度选择，无绝对尺寸依据 |
| 左 / 中 / 右段宽 | 130 / 70 / 130 mm | 由图中中段窄条约占总宽 21% 推算，并按近似左右对称假设分配 |
| 中段后退量 | 20 mm | 等轴图可见前后错层深度估算，低到中等置信度 |
| 孔列 X 中心 | -100 / 0 / 100 mm | 按三列大致处于总宽 20% / 50% / 80% 位置估算 |
| 孔行 Z 中心（自底面） | 65 / 170 / 275 mm | 约处于总高 19% / 50% / 81% 位置 |
| 大 / 小孔径 | 48 / 32 mm | 大小孔比例按约 1.5 估算；绝对值由名义尺度换算 |

## 当前 SDK 下最少的稳妥特征树

使用 **11 项特征**：

1. `box/add`：一块完整连续实体外包络，322×122×340 mm。
2. `box/cut`：从正面中央切去约 20 mm 深、68 mm 宽、贯穿全高的区域，保留实体后壁作为中段后退面。
3. 至 11. `hole/cut`：九个单独的贯穿孔，三列三行，大—小—大。

这是当前特征集合里最直接、没有语义歧义且仍是精确 CATIA 支持状态的表示。孔阵列没有减少特征数：每列的大孔对可写成一个种子孔加一个 Z 轴阵列，仍然两项；小孔仍需单独一项。跨列的 X 轴线性阵列虽然本地某些路径可能能复制网格，但当前 SDK 将非 Z 轴阵列列为 CATIA 暂不支持，因此没有拿它压缩计划。也没有把三段拆成互相接触的独立实体，以免引入多实体合并和拓扑歧义。

## 本地建模结果与自查

- CADPlan 校验有效，11 个特征均映射为当前 SDK 的 exact 支持类型。
- 本地网格包围盒：330×134×340 mm；特征数 11；三角面约 2,134。
- 九个孔都通过 SDK 本地网格射线检查，结果为 `verified_open`。
- 我实际打开并检查了 ISO、正视及七视图预览。三段宽度比例、全高中央凹入、九孔位置和大—小—大顺序都符合该图的比例估算；中央是后退的实体面，不是贯通槽。
- 不是像素级完美渲染复刻：参考图的分段颜色、孔内青/蓝/紫色和视角均未由此本地预览复现。当前 CADPlan 没有本次用到的按面着色/材质表达，预览统一为灰色；此差异不代表主体孔位几何失败。
- 自查仅针对 AI Modeler 本地网格，不是 CATIA B-Rep/几何核验证据。

## 暴露出的接口限制

1. **贯穿孔只表达全包围盒贯通。** `hole(through=true)` 无法指定开始面、结束面、单侧贯通范围；CADPlan 的三维 `point` 经 SDK 对轴 Y 映射后，本地几何实际只使用 X/Z 平面位置，Y 表面起点不参与网格切除。这个例子全部是贯穿孔，所以还能表达目标；如果需要只穿某一片板或从指定一侧盲钻，就需要新增显式方向、起点面和深度定义。
2. **盲孔只支持旧式单方向深度。** 当前内核根据包围盒沿正轴一侧生成盲孔，不能选择任意起始面、法向和终止面。这对通用多面、多层零件会造成歧义。
3. **阵列映射不够通用。** 当前精确 CATIA 阵列只承诺 Z 轴；这限制了跨面/跨列复制特征。孔阵列虽然能表示一列等间距同径孔，但不能用一个特征描述本例两种孔径和二维布局。
4. **CADPlan 是形状参数而非带命名的设计意图。** 本计划通过 id、name、note 保留“左/中/右段”和“后退面”的含义，但几何校验主要验证参数有效、包围盒和贯穿结果，尚不能独立证明前视比例、中央凹入比例或图像中的分组关系。
5. **预览没有本次需要的面级颜色语义。** 几何可编辑，但当前工具链不能按左段/中段/右段及孔内表面赋予参考图对应颜色。

## 产物

- `candidate.cadplan.json`：带数值来源的完整 CADPlan。
- `candidate.aimodel`：包含 Document 特征与 CADPlan/来源元数据的可编辑工程。
- `candidate.stl`：本地网格导出。
- `candidate-views.png`：ISO + 六个标准正交视图预览。
- `candidate-front.png`、`candidate-iso.png`：便于单独检查的视图。
- `candidate-report.json`：完整验证、孔检查、尺寸、特征树与视觉自查记录。
- `build_candidate.py`：重建产物的本地基准脚本。

检查结论：这组参考结构能由当前 CADPlan 稳定表达。它说明几何接口本身足以生成一个有比例依据的候选；但 AgentLoop 必须先识别出“一个连续主体 + 中央前凹槽 + 三列孔径关系”这些约束，并把全局孔位传给工具。当前结果是人工基准，不证明 AgentLoop 已能从仅含“复刻”的输入自动推导出同一结果。
