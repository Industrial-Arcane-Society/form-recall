# Cold run mid2 独立视觉复核

## 范围与方法

本记录仅基于指定的原始用户参考图与该 run 的 `iso.png`、`front.png` 三张图像逐张目视复核。没有读取 CADPlan、特征树、geometry report、`result.json`、Agent 自评或此前报告；没有运行 CLI、provider 或 GUI，也没有修改模型。SHA-256 对图片文件本身计算。

这是图像独立复核，不是 CATIA 验收、几何验收或制造验收。截图无法证明孔的贯通/深度、尺寸、公差、实体有效性或制造可行性。

## 配对判断与发现

### 原始参考图 ↔ 候选 `iso.png`

**判断：comparable（仅限粗略外观特征对照）。** 两图均为块状零件等轴视图，主要带孔正面、顶面和右侧面均可见，因此可以直接比较可见主体外形、正面结构、孔分布和可见侧面钻孔情况。渲染风格、颜色和视角细节不同不影响这些粗略可见特征比较。

- **主体外形：** 两图都呈块状长方体外观，候选保留了大体块状轮廓。
- **前部凹进/台阶：** 源图是窄的中央纵向凹入带，两侧正面板向前凸出；候选是占据正面大部分面积的宽矩形凹腔，四周形成连续边框。两者的可见凹进布局明显不同。
- **孔数量、列排与正面位置：** 两图都能目视数到正面九孔。源图的孔分布在三条纵向带/面上（左凸面、中间凹面、右凸面），各带大致三孔；候选的九孔全部位于同一个宽凹腔底面，呈规整三列三行。因此数量相同，但孔所在表面及相对正面位置不同。
- **侧面或背面误钻：** 两图可见的右侧面均为无孔连续面；顶面也未见孔。背面不可见，不能判断背面有无孔。
- **孔径视觉层级：** 源图中可见孔有明显大小层级（较大的青色孔与较小的蓝/紫色孔）；候选图中九孔外观近似同径，未保留可见的大小层级。颜色差异本身不用于判断孔型。

### 原始参考图 ↔ 候选 `front.png`

**判断：comparable（限正面可见布局；源图为等轴图，候选为正投影式正视图，比较精度有限）。** 源图正面特征朝向观察者，候选图正对带孔面，能比较孔数和正面区域布置；但无法从该对判断深度、侧面与顶面。

- **主体外形：** 两图均显示矩形块状正面轮廓。源图可见该轮廓由多块不同前后位置的面构成；候选显示单一矩形外框。
- **前部凹进/台阶：** 源图正面中央为窄纵向凹入区，两侧为凸出面；候选为宽矩形凹面及环绕边框，形态不同。
- **孔数量、列排与正面位置：** 两图都可见九孔。源图孔分布于三条不同前后位置的纵向面带；候选为同一凹面中的规整 3×3 阵列。孔数吻合，面带布局不吻合。
- **孔径视觉层级：** 源图孔存在可见大小层级；候选九孔看起来近似同径。
- **侧面/背面钻孔：** 此候选正视图不显示侧面或背面，无法从该配对评价。

## 未知与结论

- 源图和候选截图均不能确认孔是否贯通、孔深、背面状态、精确尺寸或实际 CAD 几何质量。
- 候选可见地保留了“块体正面九孔”这一粗粒度特征；但正面凹入/台阶布局、孔所在面及孔径视觉层级与参考图存在明显可见差异。
- 未对绝对尺寸作估计，也未从图像推断图中不可见的结构。

**结论：** 按图像可见信息，候选与参考图在块状外轮廓和正面孔总数上有粗略一致；主要正面凹槽布局及孔的分面分布不同，孔径视觉层级亦未体现。此结论只属于指定图像的独立视觉复核，不代表 CATIA 或制造验收结果。
