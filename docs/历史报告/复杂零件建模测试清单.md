# 复杂零件建模测试清单（中等难度）

> 这一份比《建模测试清单》难一档：弹性元件、传动件、凸轮、制动件、
> 组合件都用上了**螺旋扫掠、花键齿形、凸轮轮廓、辐条阵列、多槽切除**这些
> 更复杂的几何运算。每一条都**已实跑验证**。

**怎么看结果**

1. 右侧「**统计**」页看**外形尺寸**，和"应该看到"那列比
2. 三维视图里**转到侧面和俯视**看形状特征（圈数、齿数、辐条数、槽数）
3. 「**日志**」页会显示用了什么特征、多少面片

> 复杂件布尔运算较慢，**单件 1~3 秒属正常**；超过 30 秒会自动中止。

**图例**：✅ 正常 ｜ ⚠️ 能建出来但和预期不符 ｜ ❌ 没建出来

## 中等难度零件的建模原理

| 零件 | 用到的几何运算 |
|---|---|
| 螺旋弹簧 | 圆形截面沿螺旋线**放样扫掠**（每圈 14 个截面） |
| 花键轴 | 矩形花键**轮廓生成** + 拉伸 |
| 盘形凸轮 | 基圆 + 简谐升程**极坐标轮廓** + 拉伸 |
| 辐条手轮 | 外圈（布尔差）+ 轮毂 + N 根辐条**圆周阵列并集** |
| 多楔带轮 | 圆柱 − N 个**回转体 V 槽** |
| 制动鼓 | 外筒 + 中心孔 + **分度圆均布孔** |
| 蜗杆 | 圆柱 + **螺旋扫掠**螺纹 |
| 齿轮 | 渐开线近似**齿形轮廓** + 拉伸 |
