# 桌面多模态 AgentLoop

## 启动与使用

在项目根目录运行：

```powershell
python -m ai_modeler
```

在左侧建模对话中输入文字，或粘贴/选择参考图片，然后发送。图片可用作多视角证据，
文字可补充目标、单位、尺寸偏好以及是否允许按图估算。

- 在输入框按 `Ctrl+V` 可把剪贴板图片附加为参考图；剪贴板是文字时仍按普通文字粘贴。
- 也可点输入框左下角“＋”选择 PNG、JPG、WebP 或 GIF 文件。每轮最多 8 张图。
- Windows 剪贴板优先读取 PNG；常见 DIB 位图会转换为 PNG，过程不依赖 Pillow。
- 粘贴图片后可继续输入文字；附件缩略图显示在输入框上方，点击缩略图上的“×”移除。
  发送后，聊天记录中继续保留缩略图供回看。

## 大模型配置

在“工具 → AI 大模型设置”填写 OpenAI Chat Completions 兼容的接口地址、模型名称和 API Key，
并启用多模态 AgentLoop。服务端模型必须同时支持图像输入和函数/工具调用；仅支持文本
或不支持 tools 的接口不能运行完整流程，程序会显示接口错误，不会静默转交旧规则解析。

关闭 AgentLoop 后，纯文字仍可使用内置规则快速建模；图片输入需要启用支持视觉和工具调用的模型。

## 回合路由与工作流

每轮先读取近期对话与当前模型状态，由 LLM 路由器返回 `conversation`、`create`、`edit` 或
`clarify`，并按本轮需求选择是否识别图片，以及 `none`、`multiview` 或 `full` 复核。连续问答
不调用建模工具；修改优先以应用当前特征树为几何基线。当特征树与旧 CADPlan 不一致（例如手动改参数、删除、移动或停用特征，或打开旧工程）时，UI 会额外传入当前特征树快照，旧计划只作为可能过期的来源/关系参考；新建从用户需求生成计划；缺少关键结构信息时先询问。
上下文优先保留最近 16 轮、最多 48,000 个字符，并单独传入当前模型计划。更早的消息按批次合并为最多约 1,800 字的长期摘要；每积累 8 条移出近期窗口的消息再调用一次摘要，避免长对话只保留最近几轮，也避免每轮额外发起摘要请求。
最近一次右侧显示的本地预览也会作为助手侧视觉上下文带入后续回合，并明确标注为生成结果，不与用户原始参考图混淆；清空模型/新建对话/打开工程，以及手动改动几何或特征状态时会移除过期预览附件。
如果当前特征树包含 CADPlan Schema 尚不能表达的特征类型或停用特征，编辑流程会在重建前停下并要求先处理，避免静默丢失几何或特征状态。继承自本地特征树且原始来源不明的参数使用 `existing_model` 来源标记。

- `none`：CADPlan 通过校验并生成本地预览，结果标记为未做视觉复核的 `previewed` 候选。
- `multiview`：执行带五类证据检查的多视图复核和必要返修，结果标记为 `reviewed`；不宣称通过相似度审查。
- `full`：执行多视图检查和独立相似审查；两者都满足接受门禁后才标记为 `accepted`。

视觉识别（如被选中）：汇总文字、图片视角、可观察结构和尺寸证据。对平涂、分区清楚的图片，程序会补充水平扫描线和外轮廓像素比例；模型根据图片视角决定是否采用这些数据。
模型构造：生成 CADPlan，并由 SDK 校验参数、数值来源和 CATIA 支持状态。CADPlan 的 box.center 表示几何中心；缺少来源元数据时，只允许模型补 sources，几何参数必须保持不变。
多视图检查：读取正视、右视、俯视结果；有证据可修正时提交完整新计划。应用会将计划的 X/Z 外轮廓比和三段 X 宽度与识别阶段得到的正视比例作确定性核对。
完整复核还会独立检查主要比例、分段、布局和剩余差异。若模型误判接受但程序发现正视比例冲突，会发出有具体测量值的修订请求，再重新生成预览并复审。

工具总上限为 64 次；网页搜索最多 8 次，多视图工具最多生成 12 张新预览，每轮多视图检查最多调用 4 次预览工具。默认总时限 10 分钟；修订仍有轮数上限，修订没有改变冲突计划时立即停止。图片估算需保留
来源说明；必要几何参数无法可靠判断时，Agent 会请求用户补充。仅缺少来源标注时会尝试一次
不改几何的元数据修复。高严重度问题、低置信度或明确相似度不匹配不能被自动接受。模型不得生成或执行任意代码。

每次本地网格预览完成后，AgentLoop 会通过线程安全队列更新右侧「Agent」页的预览图、尺寸和阶段状态；
用户无需等待对话结束才看到第一版几何。AgentLoop 只构建 AI Modeler 的本地网格并在应用内渲染，不启动 CATIA、不保存 CATPart，也不
自动推送。即使计划需要用户确认，只要 CADPlan 已通过几何校验，应用也会标明“未通过最终复核”并
显示候选模型。预览图和 `run.json` 运行记录保存在 `artifacts/agentloop/`；记录包含输入文件名、
像素扫描证据、CADPlan、校验、逐轮预览尺寸、审查/修订决定与工具轨迹，不保存 API Key。三视图和
扩展多视图可通过工具栏或“文件”菜单从当前网格导出为 PNG；它们不是 CATIA B-Rep 检查结果。
