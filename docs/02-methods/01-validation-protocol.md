# 实验与验收协议

## 样例集与盲测

固定输入集包含纯文字、单张图片、同一零件多视角、明确尺寸图、无尺寸外观图、遮挡/视图冲突、标准件及续话修改。每条输入保存来源、原图 SHA-256、允许使用的先验知识和禁止泄漏给盲测 Agent 的信息。报告区分冷启动盲测和已知答案回归。

## 单次运行记录

一次 run 至少记录：应用版本、runtime manifest 哈希、DSH/provider/model/reasoning、操作系统、日期、用户输入与图片哈希、工具调用序列、每次调用的开始/结束/结果、取消与重试、CADPlan revision、输出文件和错误。API key 等密钥不得写入日志。

## 三条独立验收线

### Agent 行为

- DSH 是否收到文字和图片；检查原图在新会话、续话、摘要和每次自审查中的传递方式。
- 工具是否真实由 DSH 调用；从运行日志核对工具名、参数、回包和几何 revision，不能只看 prompt 或 UI 文案。
- 评估工具序列的任务相关性、重复/无变化调用、时间和错误率。
- 取消一个会话后确认其他会话不受影响；恢复 session 后核对历史关联与图像资源仍有效。

### 几何模型

- 单位、坐标系、包围盒、实体数量、开/闭壳、拓扑有效性和网格退化分别记录。
- 指定要素用参数化检查：孔中心/直径/方向/贯穿范围，外形台阶深度、圆角半径、对称关系等。
- OCP 与 Rust/OCCT FFI 迁移用同一 CADPlan fixtures 比对尺寸和拓扑，声明容差与失败阈值。

### 图像相似度

- 每个原始视角单独对照匹配方向的模型视图；不能把多个视图拼图后只给整体 match 分数。
- 每条审查意见须描述可见证据、差异位置、影响特征、建议操作和不确定性。
- 修正后仅用新 revision 的视图重新确认受影响差异；旧图/旧分数不能关闭问题。
- 记录“图像无法判断”“尺寸为估算”和“用户已提供尺寸”，不强行归类为几何失败或通过。

## 发布门禁

feature 完成前填写对应 Todo 中的验收项，保存机器运行记录和可复核路径。`git diff --check`、静态解析、单测、UI build、安装包 cold-start、真实 DSH 多模态运行和 CATIA 实测分别报告，不用低层通过冒充高层通过。
