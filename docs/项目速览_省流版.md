## 一句话

**用一句中文描述，在 CATIA 里自动建出可用的机械零件模型；同时记住企业真实的夹具设计流程，用得越久越准。**

面向汽车装备制造：焊装夹具、模具、汽车零部件。

---

## 现在有什么

### 1. 一句话建模（核心）

输入「内六角螺栓 M5x16」「法兰 外径 160 厚 20 内径 60，均布 6 个孔」这种描述，
程序解析成参数化特征，生成三维模型，可导出 STL / 推送 CATIA。

- **19 个零件族**：螺栓、型材、销、支座、压臂、托块、气缸、垫块……全是机械件
- **83 个 CATIA 工具函数**，经 MCP 暴露给 AI Agent 调用
- 支持参考图建模（给图片 + 文字）

### 2. 元增量学习（这套东西的招牌）

不是训练神经网络，是**带原型的记忆 + 增量写入**：

| 层 | 记什么 | 现在有多少 |
|---|---|---|
| 零件族记忆 | 这个零件属于哪一族 | 19 族 / 1816 条已验证样本 |
| 工序记忆 | 这类任务该走哪道工序、这道工序历史上栽在哪 | 16 道工序 / 79 条场景说法 |

工作方式：
- 新样本进来 → 并进族原型（EMA 更新），立刻生效，不用重训
- 走一遍流程 → 每步结局自动写进工序记忆（成功/失败 + 失败原因）
- 下次再问同样的事 → 带出「这道工序成功率多少、常栽在哪」

### 3. 五步协同设计工作流

夹具单元设计的五个阶段，**前置不满足不许进下一步**：

```
工程输入 → 单元规划 → 参数建模 → 关联装配 → 校核输出
```

四道门禁：前置校验、P01 锁定、失效传播、复核准入。
检查结论四分：`pass / fail / not_run / not_applicable`——**不合并成一句「通过」**。

### 4. 学习进度面板

工具栏「📊 学习进度」按一下 → 生成网页 → 浏览器打开。
看得见：多少个族、多少样本、每道工序的成功率和失败原因。

## 基于什么技术

### 语言与依赖

- **Python 3.11+**（实测 3.14.3），核心**纯标准库**
- 元增量学习只依赖 **numpy**（不装 torch，用户双击就能跑）
- 可选 `cadquery-ocp`（OpenCASCADE）做几何运算

### 界面

- **tkinter** 桌面程序：`python -m ai_modeler`
- 另一套 `AI Modeler`（Tauri + Vue + WebView2）是旧壳，前端源码不在本机

### 与 CATIA 的通道

- **V5 宏 + cscript/COM** 推送模型
- 也可导出 **STEP** 让 CATIA 导入
- 通过 **MCP（Model Context Protocol）** 把 83 个工具暴露给 AI Agent

### AI 接入

- **DeepSeek API**（OpenAI 兼容接口）
- Agent 用 **DSH（DeepSeek Harness）** 的 ACP 协议跑，MCP 服务是 `ai_modeler.agent.dsh_mcp_server`
- 系统提示词约束了建模规则与能力边界

### 算法细节（元增量学习）

| 组件 | 做法 |
|---|---|
| 特征 | n-gram 词表 + 数值量化 + 族线索词，L2 归一化 |
| 族原型 | 样本向量 EMA：`α = max(0.05, 1/(n+1))` |
| 分类 | 原型最近邻（`w=0.6`）+ 1-NN 基线（`w=0.4`） |
| 写入门禁 | 只有 `verified` 样本进原型 |
| 新族判定 | 同族累计 ≥3 条 verified 才建原型 |
| 工序检索 | 余弦相似度 + 多说法取最大 + 关键词兜底 |

## 已知限制（队友必看，别踩坑）

### 1. 口语化提问检索不准

三组实测：

| 测试组 | 命中率 |
|---|---|
| 专业长描述（含术语） | 9/9 |
| 短口语 + 术语 | 16/16 |
| **超短口语不含术语** | **6/16 = 38%** |

原因：用的是 **n-gram 字频匹配**，不是语义向量。
「能不能活动起来」和「建立转动副」没有一个字重叠，字频方法连不上。

**要解决得换真正的 embedding 模型**，但那要联网或装模型，跟现在纯 numpy 的部署方式冲突。

### 2. 只认识机械零件

19 个零件族全是机械件。说「建一个房子」它不会——本地解析器会兜底成长方体并警告，
Agent 模式会瞎编（实测编出 8000mm 和回转体当屋顶）。

提示词里加了能力边界，让它承认不会，但**承认不会不等于会**。

### 3. 汽车零部件 / 模具族库是空的

企业另外两条业务线（汽车零部件研发、模具制造）现在只到「特征原语够用、族库没建」。
评委或企业问起来，别说过头。

### 4. AI Modeler 里没有新功能

那个漂亮的 Tauri 界面是 2026-10-21 的旧版本，前端源码不在本机。
**今晚所有功能都在 tkinter 版「AI 自动建模助手」里**，看工具栏有没有「📊 学习进度」就能分辨。

### 5. 两道工序待企业确认

- **S03** 焊枪避让空间怎么定
- **S06** 标准件型号怎么选

CSV 里标着「待企业确认」，判据数值还没核准。**建议去问企业，回来改掉**。
