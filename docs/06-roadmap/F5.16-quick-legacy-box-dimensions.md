# F5.16：Quick 旧版长方体尺寸补全

## 范围

恢复旧 Python Quick 对**独立长方体描述**的尺寸补全规则。旧 `make_box()` 通过 `pick3()` 按长、宽、高顺序读取已识别尺寸、两维尺寸组或剩余数值，然后用默认值 `100×60×20 mm` 补齐缺项。本项只对没有孔/槽修饰子句的长方体启用这项规则；圆柱、圆锥、球体默认及带修饰长方体仍是待迁移范围。

## Python oracle

Oracle 为 `src/legacy/ai_modeler/core/parsing/nlparser.py` 中 `extract_dims()` → `Parser.pick3()` → `make_box()`，直接调用 `nlparser.parse(text).doc.to_dict()` 的样例保存在 [`quick_legacy_box_defaults_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_box_defaults_contract.json)：

| 输入 | Python 长×宽×高（mm） | Python warning |
|---|---:|---|
| `长方体` | 100×60×20 | 空 |
| `长方体 长40` | 40×60×20 | 空 |
| `长方体 40×30` | 40×30×20 | 空 |
| `长方体 40mm` | 40×60×20 | 空 |

`40×30` 是两维尺寸，缺少的高度按旧默认补齐；裸 `40mm` 在旧 `pick3()` 中进入 `Dims.raw`，按首个尺寸补作长度。本 fixture 记录的是解析器的真实字段结果，不把 Python 对 pair 来源的历史标注瑕疵复制成 Rust 的来源事实。

## Rust 迁移与边界

- 对没有孔/槽修饰的 box，Rust 支持明确长宽高、`L×W` 尺寸对、以及旧 parser 能读取的剩余数值；按 Python 的长→宽→高顺序填充，最后不足的字段使用 `100/60/20 mm`。
- 用户给出的尺寸来源标为 `user`；旧默认补出的值标为 `derived`，附带默认值说明，并通过 `legacy_box_dimensions_defaulted` 警告显示具体补值。未写单位仍保留 Rust 的 mm 解释警告。
- 明确的非正尺寸或冲突值仍报错，不会被默认值覆盖。
- 本轮限制默认补全只用于独立长方体，不在带孔/槽修饰的计划中补齐缺失主体尺寸；其他基本体默认尚未迁移。
