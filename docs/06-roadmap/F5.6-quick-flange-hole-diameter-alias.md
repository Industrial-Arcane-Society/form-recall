# F5.6 Quick 法兰“孔径”中心孔别名

## 范围

将旧 Python Quick 法兰模板中的“孔径”别名补到 Rust 原生 Quick 的法兰模板中心孔解析中。限定输入形态为带有法兰模板词、外径、厚度和孔径的描述。普通基础形体和套筒模板的参数词汇不在本次变更范围内。

## Python 语义基准

基准实现：`src/legacy/ai_modeler/core/parsing/nlparser.py` 的 `parse()` / `tpl_flange()` 与 `Dims` 提取。执行：

```text
PYTHONPATH=src/legacy python -c "from ai_modeler.core.parsing.nlparser import parse; r=parse('法兰外径100厚10孔径20'); print([(f.kind, f.params) for f in r.doc.features])"
```

观察到两项：盘体 `cylinder(radius=50, height=10, base=false, axis=Z, segments=64)`，中心通孔 `hole(diameter=20, through=true, pos=center, axis=Z, segments=24)`，无 warning。该结果存入 `tests/fixtures/quick_legacy_contract.json` 并由 Rust Python-golden parity 测试覆盖。

## 实现与边界

- Rust 法兰模板的中心孔别名列表增加“孔径”。
- 未增加对普通 box/cylinder 的“孔径”解释，也未修改套筒解析；Python 套筒在该词上的行为还会受到旧解析器跨片段处理影响，不作为本项兼容承诺。
- 此改动不代表完整旧 Quick 语法迁移，也不代表几何内核或 CATIA 验收。
