# F5.40：Quick 旧 Python 轴承座与轴承套

## 迁移依据

旧 Quick 入口为 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.parse`，零件库构造器为 `src/legacy/ai_modeler/parts/library/partlib.py::_bearing_seat`。实际结果是一个居中的 Z 轴圆柱和一条居中的贯穿孔；旧注释提到的凸缘并未由构造器生成。参数表要求外径 `D` 和高度 `H`；内径 `d` 缺省时旧解析器沿用 30 mm 典型值。

Python 样例、特征树、参数来源、包围盒和旧 mesh 体积记录在 [`quick_legacy_bearing_seat_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_bearing_seat_contract.json)。

## Rust Quick 行为

- 支持“轴承座”和“轴承套”名称，映射为 cylinder + center through-hole；外圆 64 段，中心孔 48 段，中心在原点，主体沿 Z 轴居中。
- 必须给出有效外径 D 和高度 H。未给内径时记录 `d=30 mm` 的 `derived` 来源和 warning；内径不小于外径、尺寸缺失、冲突或非正数时返回澄清。
- 这只是旧程序生成的圆柱套筒简化件，不含凸缘、安装孔、滚动体、滚道或密封结构。带这些附加要求的描述返回 `unsupported`。
- 旧 Parser 对显式“通孔”会在已有中心孔外再加一个 10 mm 中心孔特征，该切除是 no-op。Rust 将这类复合请求明确标为未迁移，不重复生成无效特征。

## 验收

解析合同测试 `native_quick_parser::tests::legacy_bearing_seats_match_python_oracle_and_default_provenance` 对照 3 个旧版可建输入，另检查缺失尺寸、无效尺寸、内外径顺序、附加通孔和法兰拒绝。

OCCT 集成测试 `native_quick::acceptance_tests::f5_40_legacy_bearing_seats_build_measure_reopen_and_export` 构建显式 ⌀20 内孔与旧默认 ⌀30 内孔两个 50×50×30 mm 样例。两者均为一个有效闭合实体，中心孔通过 B-Rep 和射线证据核验为贯穿。OCCT 体积分别为 `49480.084294` 和 `37699.111843 mm³`，与旧 Python mesh 体积差异分别约 `0.137%` 和 `0.0905%`。AIMODEL 重载及 GLB、STL、OBJ 生成检查均通过。
