# F6.5 原生手工联网查询

## 输入与边界

- 输入：桌面联网查询框中的查询文本；原生 `NativeWeb` 搜索结果及最多前两条结果页正文。
- 输出：兼容旧 `online.ask` 的 `ok`、`results`、`suggestion`、`reason`、`query`、`notes` 和 `params` 字段；无结果时仍省略 `params`。结果行只含 `title`、`snippet`、`url`，不泄漏内部 result id。
- 路由：Vue 调用 Rust `native_online_ask`，不再调用 Python `online.search`。Agent 的 DSH web tools 是另一条单查询接口，不由本 feature 改动。
- 不变量：查询结果只作为参考资料，不能覆盖用户输入，也不代表目录条目已支持几何建模。

## 旧契约迁移

Rust adapter 复刻 `src/legacy/ai_modeler/agent/online.py::ask` 与 `build_candidate`：

1. 依次查询 `query + " 标准 规格 尺寸表 mm"`、`query + " 规格参数 mm"`、`query + " 尺寸"`、原始 `query`，去重后按顺序执行。
2. 每次 `online.search` 先按 ASCII 词/型号筛选，`online.ask` 再按旧中文关键词/型号筛选；若某一轮不足两个二次相关结果，继续查询但保留首批非空、已通过首层筛选的结果作为回退；某轮有至少两个二次相关结果时采用该轮结果并停止。
3. `deep=true` 时只打开最终结果中的前两页，正文最多取 4000 个字符，再按旧关键词和单位抽取直径、内径、长度、宽度、高度、齿数、模数。单位换算与众数选择保留旧规则。
4. 保留 M 公称直径覆盖、轴承型号、型材截面、螺钉/螺栓/螺母/垫圈等旧 suggestion 规则。它们是启发式文本建议，不是验证过的标准件数据库或可用几何能力清单。
5. 零条结果返回 `ok:false`、空 `results`、空 suggestion、原因和 notes，且没有 `params`。有结果但没有尺寸时返回 `params:{}`，suggestion 可为 `null`。

原生额外返回 `page_read_errors`，仅列正文读取失败或 URL 安全拒绝的结果；不宣称页面已读取，也不把网页正文当作可信指令。Tauri 命令失败会由 UI 作为结构化错误显示。

## 验收

- 输入样本来自固定 JSON fixtures，覆盖查询扩展和调用顺序、前两页正文读取、4000 字符正文上限、首批结果回退、无结果字段形状、无参数结果、M 尺寸覆盖、轴承/型材/螺母/垫圈/通用 suggestion、单位换算和频次并列时保留首值。
- 12 个案例的 Python expected response、搜索序列、正文 URL 序列与 Rust 结果逐字段对拍。页面安全拒绝、搜索错误另有定向 fixture；query-relevance 使用本机 mock HTTP server 验证首层筛选会剔除无关行。
- Vue 检查手工查询直连 Rust 命令、结果面板显示旧字段、suggestion 可填入建模提示。
- 验收没有访问公网，没有启动 GUI、DSH、CATIA 或模型 provider；不证明实际联网环境可达，也不评价外部搜索结果的相关性。

## 复现命令

在仓库根目录执行：

```powershell
py -3 src/legacy/tests/test_native_online_lookup_parity.py
pwsh -NoProfile -ExecutionPolicy Bypass -File src/apps/desktop/scripts/test-native-online-lookup.ps1
npm run test:online --prefix src/apps/desktop
npm run build --prefix src/apps/desktop
git diff --check
```

Rust 脚本会临时覆盖 `TAURI_CONFIG.bundle.resources` 以跳过打包资源 staging，并给测试 exe 嵌入项目已有的 Common-Controls v6 manifest；lookup 测试使用固定 fixtures，query-relevance 测试仅绑定 loopback mock。

## 限制与后续

- 保留的是旧的简易抓取与启发式 suggestion 契约；格式变动、地区差异或网页噪声仍可能导致无结果或错误建议。桌面 UI 应把 suggestion 当作待确认文本。
- NativeWeb 页读取继续执行其现有 URL 安全与正文长度限制，读取失败通过 `page_read_errors` 说明。页面错误字段是本地诊断扩展，并非旧 Python 输出字段。
- 没有真实公网验收，因此搜索可用性、源站封锁、站点正文可读性和最慢响应时间仍未知。
- 本 feature 不会根据建议自动建模，不负责 Agent 工具，不改变 DSH web tools、知识库或模型几何能力。
