# F5.31：Quick 旧 Python 单段实心轴配方

## 迁移依据

旧 Quick 的真实入口为 `Parser.parse`，轴类模板位于 `src/legacy/ai_modeler/parts/library/partlib.py` 的 `_shaft`。初始轮以旧入口实测并固化三种无孔输入：

- `轴 直径20 长度100` 与 `实心轴 d20 L100` 都生成一个 `cylinder`：半径 10 mm、长度 100 mm、中心 `[0,0,0]`、`base=false`。
- `轴 长度100` 因旧零件库默认轴径为 30 mm，生成半径 15 mm 的同心圆柱，并给出缺失参数警告。
- 旧网格内核用 48 边近似圆柱。20×20×100 mm 示例的包围盒为 `[20,20,100] mm`、网格体积为 `31326.286133 mm³`；30×30×100 mm 示例的包围盒为 `[30,30,100] mm`、网格体积为 `70484.143799 mm³`。

F5.31 后续窄扩展固定输入 `轴 直径20 长度100 通孔6`。已保存旧 `Parser.parse`、`Document.build()` raw STL、`Document.build_brep()` BREP 与 BREP 三角化 STL 于 `artifacts/f5.31-shaft-center-through-hole/`。旧 Parser 保留有序 `cylinder/add`、`hole/cut`；孔参数为 Ø6、`through=true`、`axis=Z`、`pos=center`、`segments=24`。旧孔的 `provenance` 是空对象；Rust 的孔来源是根据用户文本与受限子集默认规则新建，不能解释为继承旧 provenance。`legacy_oracle_report.json` 中的 Rust 状态是实现前的静态快照；当前 Native Quick 运行报告和对比结果单独保存在同目录。

原始结果和迁移期望记录在 `src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_solid_shaft_contract.json`。

## Rust Quick 行为

- 新增 `轴`、`实心轴`、`光轴`、`圆柱轴` 的单段轴路由，支持 `直径/轴径/外径` 与 `长度/长`，也支持旧参数写法 `d20 L100`。
- 输出一个以全局 Z 为轴、几何中心位于原点的 `cylinder`。缺少轴径时沿用旧 Quick 的 Ø30 mm 默认并明确警告；缺少轴长则要求澄清。
- 仅接受单段圆柱轴后缀唯一、显式直径的 `通孔<直径>`，例如固定 oracle 的 `通孔6`；按本窄迁移合同解释为中心 Z 轴贯穿孔，CADPlan 中保留有序 `cylinder/add` 后接 `hole/cut`。该固定输入的 parser 来源记录直径/贯穿类型为用户指定，中心位置、Z 轴与 24 段参数为 Rust 派生；来源说明注明旧孔 provenance 为空。
- 偏心/坐标孔、侧向或非 Z 孔、盲孔、多个孔，以及键槽/其它槽、倒角、圆角、螺纹、缺少或冲突孔径等仍返回 unsupported，不会只生成轴身并吞掉附加特征。
- 复合零件名称（阶梯轴、曲轴、凸轮轴、花键轴、空心轴、轴套、轴承等）不会被单段轴路由截获，继续由各自已迁移或未迁移的解析分支处理。

## 与旧解析器的差异

这不是对旧解析器所有偶然输出的逐字复制：

- `光轴 直径20 长100` 在旧 Python 参数绑定中没有把“直径20”绑定到轴径，最后用了 Ø30 mm 默认值。Rust 使用明确写出的 Ø20 mm，并将源尺寸保留为用户输入。
- `轴 直径20` 在旧 Python Quick 中会将孤立的数值回退成长方体。Rust 识别其为不完整的轴描述并询问轴长，不会把长方体冒充为轴。

这两种旧输出作为差异保存在 oracle fixture 中；因此本卡的结论是迁移明确、可执行的单段轴契约并修正两个静默误解析，不宣称所有输入逐字段兼容。

## 验收边界

- Rust parser 定向合同测试校验无孔旧 Quick 正例及固定中心通孔输入，检查有序特征、hole 参数/来源、CADPlan schema 与本地几何 preflight；偏心、侧向、盲孔、多孔及其它修改特征继续 fail-closed。
- 忽略式 OCCT 集成验收对固定样例检查有效闭合实体、外形尺寸、体积相对旧 48 边网格误差、AIMODEL 重载及 GLB/STL/OBJ 输出。
- OCCT 使用解析圆柱，旧 Python 使用 48 边多边形；包围盒一致，体积预期差约 `0.2862%`。该差异来自圆周离散化，不作为尺寸不一致。
- 本地 Rust/OCCT 集成结果不代表 CATIA 已运行，也不代表安装版桌面 UI 已验收。

中心通孔 OCCT 验收要求一个有效闭合实体、bbox `[20,20,100] mm`、中心 Z Ø6 贯穿孔测量为 `verified_open`，并核对 Rust B-Rep 体积与旧 `Document.build_brep()` 体积。测试把 Rust STL 与几何报告写至 artifact；同坐标比较可复跑：

```powershell
python artifacts/f5.31-shaft-center-through-hole/compare_native_quick_to_legacy_brep.py
```

比较器以旧 B-Rep 三角化 STL 为表面/体积权威，容差为 0.08 mm 表面采样、1e-3 mm³ 几何报告体积差；输出 `rust_vs_legacy_brep_comparison.json`。比较使用共同世界坐标，不做平移/旋转/缩放。表面点采样是确定性近似，不是连续 Hausdorff 上界。旧 `Document.build()` raw mesh 存在开边，作为诊断单列，不作为有效实体体积依据。
