# F5.96：旧 Quick 缺 PCD 时默认值造成的边界破孔

## 范围与输入

本记录核验旧 Python Quick 对输入 `长方体100x60x20，均布四个直径8通孔` 的实际行为，执行 `Parser().parse()` 后调用 `Document.build()`，并检查生成三角网格。当前 Rust 仅做源码核对，没有运行 Cargo、没有重建 Rust 几何，也没有修改代码。

旧 Quick 实际运行结果：解析 `ok=true`，识别两个特征，无 warnings/questions。特征分别为 `100×60×20 mm` 长方体，以及 Z 轴贯穿、直径 8 mm、数量 4、位置模式 `pcd`、PCD 60 mm 的孔阵列。PCD 并非用户输入，而是旧解析器缺省补入。

## 旧 Quick 几何实测

`Document.build()` 返回 328 个多边形、532 个三角形，包围盒为 `100×60×20 mm`。旧构造器将 PCD 除以二作为阵列半径，默认相位为 0，因此四个 Z 向孔中心是：

| 孔 | XY 中心 (mm) | 与坯料边界的关系 |
|---|---:|---|
| 1 | `(30, 0)` | 位于内部 |
| 2 | `(0, 30)` | 中心落在 Y 正边界 |
| 3 | `(-30, 0)` | 位于内部 |
| 4 | `(0, -30)` | 中心落在 Y 负边界 |

坯料 XY 范围为 `[-50,50] × [-30,30]`。因此两个 ±Y 孔中心恰好在边界上；半径 4 mm 的孔超出坯料侧边，切出开放缺口，而不是完整包围在材料内的圆柱孔。

### 网格健康检查

对三角面顶点按 6 位小数坐标量化并统计无向边出现次数，得到：

- 出现 1 次的边（边界/破边）：600 条；
- 出现 2 次的边：498 条；
- 出现超过 2 次的边：0 条。

532 个三角形共计 1596 个边 incidence，统计值相加也为 `600 + 498×2 = 1596`；本次未发现退化三角形。因此该输出不是闭合水密网格。`0` 条超过 2 次的边只说明这次统计未发现该类边，不会抵消 600 条边界边，也不能据此认定为有效实体。

### 孔中心射线检查与限制

把网格三角化后，对给定 XY 点沿 `+Z` 投射竖直射线：逐三角形检查其 XY 投影内含该点时，用重心坐标插值得到交点 Z，并将相同位置的重复三角命中合并。结果如下：

| XY 点 | 射线交点 Z (mm) | 解释 |
|---|---:|---|
| 四个声明的孔中心 `(±30,0),(0,±30)` | 无 | 网格在这些中心线上没有三角面交点 |
| 控制点 `(0,0)` | `0,20` | 两个外表面交点，材料贯穿该点 |
| 控制点 `(10,10)` | `0,20` | 两个外表面交点，材料贯穿该点 |

该检查证明网格在四个中心线上留下了贯通空隙，控制点仍穿过上下表面；它与边 incidence 检查相互支持。**这不是完整孔壁验收**：中心线无命中不能证明每个孔都有完整、连续、同轴的圆柱侧壁，也不能证明拓扑上构成四个合法通孔或闭合 B-Rep。当前旧网格已因边界破边而不满足闭合要求。

旧 `K.volume_of()` 对该输出给出 `117018.4046 mm³`。它是对当前开口、破边网格应用有向四面体求和后取绝对值的 scalar；闭合且方向一致的网格条件不成立，因此该数值不能作为可信实体体积，也不能用于证明孔阵列正确。

## Rust 行为与兼容判断

当前 Rust 源码在 `native_quick_parser.rs` 中将“均布四个”识别为阵列请求；若缺少明确的 PCD，则加入 `hole_pcd_missing`，提示 `孔阵列缺少明确的 PCD/分度圆直径。` 相关分支位于 [`native_quick_parser.rs`](../../src/apps/desktop/src-tauri/src/native_quick_parser.rs#L12913) 的 pattern 判定和 [缺 PCD 处理](../../src/apps/desktop/src-tauri/src/native_quick_parser.rs#L12953)。

旧默认来源位于 [`nlparser.py`](../../src/legacy/ai_modeler/core/parsing/nlparser.py#L1602) 的 `_add_hole`：当阵列位置没有显式 PCD 或暂存 PCD 时，设置 `60.0`。旧孔位与贯穿 cutter 的构造位于 [`docmodel.py`](../../src/legacy/ai_modeler/core/model/docmodel.py#L565) 的 `_build_holes`，其中 PCD 阵列位置从 PCD 半径与相位生成。

不应把旧的 PCD=60 行为恢复为无条件默认。对本例的 60 mm 短边而言，四象限等分且孔径 Ø8 时，PCD=60 会使 ±Y 两个孔越界；理论上 PCD=52 mm 已让这两个孔的外缘恰好接触边界，没有制造余量，实际值还应根据所需边距进一步缩小。缺少 PCD 时询问用户，或采用有明确来源、检查过边界的估算值，比静默采用旧常量安全。若为旧模型兼容保留该默认，只能作为显式标记的历史策略，并在构造前做孔外缘与坯料边界检查，越界时不得声称得到有效闭合实体。

## 复验与证据边界

本次实际复验是本地旧 Python `Parser().parse → Document.build → polygons_to_triangles`。复验时还应记录 Python/网格内核版本、原始多边形及三角化结果哈希，并运行相同版本脚本，避免把不同旧运行环境的产物混用。

本记录没有证明旧模型可形成合法闭合 B-Rep，也没有测量孔壁表面连续性、孔径公差或与 Rust 的表面距离。后续若要宣称完整孔几何，应对可用的 B-Rep 检查实体/壳闭合和有效性，并对网格检查每孔周围完整侧壁、截面圆环、拓扑连通和边界边；中心线射线结果只作局部证据。当前 Rust 的澄清是有理由的安全偏差，不应为追平旧默认而取消。
