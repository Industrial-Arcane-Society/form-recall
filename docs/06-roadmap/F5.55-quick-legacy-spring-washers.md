# F5.55：Rust Quick 迁移旧 Python 弹簧垫圈配方

## 旧入口与真实几何

对照 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.handle`、`partlib.build_features_ex()` 和 `src/legacy/ai_modeler/parts/library/partlib.py::BOLT_PARTS['弹垫']` / `_washer_thin()`。旧部件库名称叫“弹垫”，实际生成的是一个完整平圆环，不包含弹簧开口或波形。

| 输入 | 旧 Python Quick 结果 |
|---|---|
| `弹簧垫圈 内径6 外径12 厚度2` | 两个操作：直径12、高2 mm、居中且沿 Z 的 48 分段圆柱；直径6 mm 的中心贯穿孔。网格包围盒 12×12×2 mm，192 面、382 三角形，面片近似体积 169.161945 mm³、面积 282.178552 mm²。 |
| `弹簧垫圈 内径6 外径12` | 与上面相同的平环，厚度按旧公式 `max(0.5, (D-d)×0.35)` 回退为 2.1 mm；旧网格体积 177.620042 mm³。 |
| `弹簧垫圈 d6 D12 h2` | 识别短参数并建立同尺寸的平环。 |
| `弹簧垫圈` | 旧入口未识别，未建模。 |
| `弹簧垫圈 内径0.6cm 外径1.2cm 厚度2mm` | 旧解析忽略 cm，把外径、内径数值直接当作 mm，结果外径1.2、内径0.6、厚度2 mm。 |
| `弹垫 内径6 外径12 厚2` | 旧解析落入通用圆柱分支，只生成圆柱，漏掉文字明确给出的中心孔。 |

旧路径的多边形网格体积与新 OCCT 连续圆柱 B-Rep 体积不是同一种离散表示，报告时分别记录，不把数值差当作尺寸误差。

## Rust Quick 迁移行为

- `弹簧垫圈`、`弹性垫圈`、`弹垫` 均生成居中平环：`cylinder/add` 加一个 `hole/cut` 中心贯穿孔，外径与内径必须明确提供。
- 未写厚度时沿用旧默认公式 `max(0.5, (D-d)×0.35)`，并在尺寸来源和结构化警告中标明这是推导值。
- 支持 `外径/内径/厚度` 与 `D/d/h` 写法，显式 cm、dm、m、英寸先换算为 mm。修正旧 Quick 忽略 cm 的问题。
- 接受“中心通孔”作为圆环本身的中心孔；偏心孔、额外孔、开口、波形、真实螺旋弹簧及其它加工保持明确的 `unsupported`。
- 单独的“弹簧垫片”仍返回未迁移状态，不猜它是弹垫。
- 对旧 `弹垫 ... 厚2` 漏孔写法，Rust 按明确的内径信息构造圆环，并警告与历史错误输出存在差异。

## 验收

- `src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_spring_washer_contract.json` 记录旧入口、接受写法、旧解析差异、缺失/冲突参数、未迁移结构和几何验收输入。
- `f5_55_legacy_spring_washer_contract_tests` 检查参数、单位、来源信息、CADPlan 校验与几何预检；本次 `cargo check --manifest-path src/apps/desktop/src-tauri/Cargo.toml --tests` 通过。
- `f5_55_legacy_spring_washer_native_acceptance` 提供本地 OCCT 集成验收：检查闭合实体、尺寸、AIMODEL 重载和 GLB/STL/OBJ 输出。该测试需要显式设置暂存 OCCT runtime manifest。
- 发布版 `ai-modeler-headless-smoke` 构建通过。实际通过生产 Quick → OCCT 路径运行显式厚度、旧默认厚度、cm 转换和“中心通孔”四种输入；四种均为 `state=complete`、几何 `passed`、一个闭合实体、AIMODEL 重载通过，并生成 GLB/AIMODEL/STL/OBJ。
- 四种 B-Rep 包围盒分别是 12×12×2、12×12×2.1、12×12×2、12×12×2 mm；对应连续 B-Rep 体积为 169.646003、178.128303、169.646003、169.646003 mm³，输出网格各 288 个三角形。
- Rust 测试目标已由 `cargo check --tests` 编译，但本轮没有声称 Rust 测试 harness 执行通过。此前同一 Windows 环境的 Cargo 测试 harness 启动遇到 `0xC0000139 (STATUS_ENTRYPOINT_NOT_FOUND)`；本次改用发布版生产入口直接验证完整几何构建与文件重载。
- 这些结果只证明 Rust Quick → OCCT → 本地文件输出，不代表 CATIA 或桌面 UI 验收。

## 未包含范围

本迁移复现旧 Quick 的平环简化形状，不等同于真实开口弹簧垫圈或波形弹簧垫圈，也不自动创建 CATPart。CATIA 尚未在本项执行。
