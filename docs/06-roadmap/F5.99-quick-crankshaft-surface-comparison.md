# F5.99：曲轴旧 Quick 与 Rust Quick 几何级比较

## 结论

基线为 `2412ebbeb5971decaeb4d8d0de2dbddc2bf33ff8`。固定输入 `曲轴 主轴颈50 连杆颈42 行程86 拐数4` 分别实际调用旧 Python `Parser().parse → Document.build()`、旧 `Document.build_brep()` 和 Rust native Quick headless。旧 raw 与旧 BREP 文件均成功输出；旧 BREP 报告一个有效闭合实体。

**当前旧 Quick raw 兼容验收通过。** Quick 专用分段轴颈和 32 边圆截面修复已进入 main（代码提交 `9716fe6`、`25b2cd9`）。修复后的 Rust Quick STL 与旧 `Document.build()` raw STL 双向最大采样距离为 `0.040127 mm`，低于 `0.08 mm`；Rust STL 是一个闭合定向组件，边界边、非流形边和绕向冲突边均为 0。表面采样结果不构成连续 Hausdorff 上界。

旧 BREP 网格与 Rust Quick 的双向表面采样最大距离仍为 `9.864 mm`，但这是不同入口的几何契约：旧 `Document.build_brep()` 使用 `analytic_journals_with_rectangular_webs`（全长主轴和矩形腹板），旧 Quick raw 则在曲柄颊与偏心销跨度中断开主轴并使用分段多边形面片。Rust Quick 保持哑铃形曲柄颊以兼容旧 Quick。若要求兼容旧 BREP 的矩形腹板，应单独定义并验收该变体，不能据此否定本项旧 Quick raw 结果。

首次对拍中的旧 raw→Rust `31.969 mm` 差异来自 Rust Quick 多生成的贯通主轴；移除该跨度后仍有约 `0.119 mm` 的圆柱解析面/32 边旧面片弦高差，最终通过上述 Quick-only 32 边轮廓修复消除。旧 raw 本身是由分段面片拼成的开放网格，不可把它的 signed volume 当作闭合实体体积。

## 固定输入、参数与来源

- 原句：`曲轴 主轴颈50 连杆颈42 行程86 拐数4`
- 单位：长度 `mm`；角度 `deg`（本例无角度参数）。
- 旧 parser：1 条 `crankshaft` add 特征，`main_d=50`、`pin_d=42`、`stroke=86`、`throws=4`、`length=null`、`center=[0,0,0]`、`segments=32`；旧 parser 无 warning/assumption/question。
- Rust CADPlan 保留四个显式尺寸为 `user`；自动曲轴长度 `619.2 mm`、中心 `[0,0,0]`、`segments=32` 为 `derived`。长度公式为 `max(1.8×86, 2.2×50)×4 = 619.2 mm`。Rust builder 的几何变体为 `legacy_quick_dumbbell_cheeks`，feature report 记载沿 X 轴、4 个 throws、8 个 cheek/web 段。
- 旧 BREP `build_document` 对该类的 builder 标记为 `analytic_journals_with_rectangular_webs`，不是 Rust Quick 当前选择的 dumbbell cheeks 配方。

## 表面、拓扑与实体有效性

表面比较使用共同毫米世界坐标，不进行独立旋转、平移、缩放或包围盒归一化。每面取 4 个固定面积加权重心样本，用 AABB BVH 查询点到三角面距离。固定采样最大值不是连续 Hausdorff 上界。表面阈值 `0.08 mm`；拓扑焊接阈值 `1e-5 mm`；三向投影使用共同包围盒，分辨率 `64²/128²/256²`。

旧 raw→Rust 的方向采样最大值为 `16.660 mm`，Rust→旧 raw 为 `31.969 mm`。旧 BREP→Rust 为 `9.864 mm`，Rust→旧 BREP 为 `5.691 mm`。旧 BREP 与 Rust 的 XY 投影 256² IoU 为 `0.9778`，XZ 为 `0.9977`，YZ 为 `0.8373`；末项是明显的端视轮廓差异，和矩形 webs / dumbbell cheeks 的 builder 区别一致。旧 raw→Rust 的 256² XY/XZ/YZ IoU 分别为 `0.7245 / 0.9298 / 0.9983`。

旧 BREP 报告实体体积 `1,846,067.704 mm³`；Rust headless 几何报告体积 `1,757,232.181 mm³`，相差 `88,835.523 mm³`（约 4.81%）。这与表面采样不通过一致。旧 raw 的 `Document.stats()` 体积 `1,248,953.413 mm³` 和 raw STL signed volume 仅作为面片统计记录：其网格有 1,024 条边界边、17 个组件，不能按闭合有向实体体积解释。Rust 的 STL signed volume `1,731,123.178 mm³` 与 Rust BREP 几何报告体积也不同；同时 STL 有边界边，因此未把该 mesh scalar volume 当作可靠实体验收值。

## 证据边界与返修建议

- 旧 raw 面片实现位于 [`kernel.py`](../../src/legacy/ai_modeler/core/geometry/kernel.py) 的 `make_crankshaft`（约 1802 行）；旧 BREP 实现分支位于 [`occ_kernel.py`](../../src/legacy/ai_modeler/core/geometry/occ_kernel.py) 的 `_feature_geometry`（约 1576 行）。前者的 STL 拓扑实际为开放面片组件，后者实际构成有效闭合单实体，但几何建造策略不是同一配方。
- Rust B-Rep builder 位于 [`native_parametric_features.rs`](../../src/apps/desktop/src-tauri/src/native_parametric_features.rs) 的 `build_crankshaft_with_geometry_variant`（约 89 行），选择变体时把旧 Quick 曲柄颊轮廓 prism 化并 fuse；随后几何报告确认单闭合实体。Rust STL 的 156 条边界边说明导出网格还需单独检查，即使 OCCT shape 本身报告有效也不能略去网格级拓扑差异。
- 返修优先级：按旧 Quick 的分段主轴颈实现修正 Quick 变体并重比 raw 路径；旧 BREP 仍作为独立合同，单独核对“全长主轴 + 矩形腹板”的 cheek 差异；另行修复并验收 Rust STL 的边界边。当前固定样例不满足表面等价条件，不能宣称 migration parity。

## 旧入口差异分解补充

`Document.build()` 的真实 Quick 路径经 `docmodel.py` 调用 `kernel.py::make_crankshaft`。每个拐只构造 `主轴颈 cursor→web_left → 左颊 → 偏心销 → 右颊 → cursor=web_right`；偏心销和曲柄颊的轴向范围没有铺主轴圆柱。Rust `legacy_quick_dumbbell_cheeks` 当前先建贯穿全长的主轴，再融合销与哑铃颊。因此报告中的 `31.9694 mm` 是 Rust→旧 Quick raw 方向的最大采样值，落在销段里的多余主轴外圆柱面；反向旧 raw→Rust 最大值为 `16.6599 mm`。这是真实几何差异，不是旧 raw 内部面或采样噪声。修复时应仅让 Quick 变体使用分段主轴颈，保留普通 BREP 变体的全长主轴行为。

旧 BREP 是另一条需分开记录的证据路径：它同样有全长主轴，但使用矩形腹板；因此其与 Rust Quick 的 `9.8637 mm` 差异落在旧矩形 web 外角和 Rust 哑铃颊轮廓，不等于上面的 Quick 主轴差异。不得用一个几何 variant 同时代表这两种旧入口。

156 条 Rust STL 边界边也属于独立的输出网格门禁：OCCT 几何报告显示 BREP 有效闭合；提高拓扑焊接容差至 `0.5 mm` 后边界数仍为156，继续加容差不能作为修复。只读源码审查发现 C++ bridge 按面读取并拼接三角化结果，尚需进一步定位具体漏缝原因；在网格级闭合验收通过前，不把有效 BREP 报告当作 STL 闭合证明。

## 补充：旧 Quick raw 表面的修复验收

旧 `make_crankshaft()` 在各拐之间仅构造 `cursor → web_left` 的主轴颈，随后连接左颊、偏心销、右颊；不会在偏心销和曲柄颊的轴向跨度内继续铺设一根贯通主轴。Rust Quick 最初生成了全长主轴，因而对旧 raw 的最大采样距离达到 `31.9694 mm`。分段修复后，轴颈和偏心销仍使用解析圆柱，与旧 Quick 的 32 边离散截面有约 `0.1190 mm` 弦高差。最终 Quick 专用变体同时恢复轴向分段和旧 `segments=32` 的 YZ 多边形相位；未标记该兼容变体的通用 CADPlan 继续使用解析圆柱。

最终定向 OCCT 回归 `f5_99_quick_crankshaft_matches_legacy_journal_segments_and_cheek_sections` 通过（1/1）。保存的旧 `Document.build()` raw STL 与新 Rust Quick STL 按 `0.08 mm` 阈值对拍通过：双向最大采样距离 `0.0401270 mm`，其中旧→Rust 为 `2.26×10⁻⁶ mm`、Rust→旧为 `0.04013 mm`；256² 投影 IoU 为 XY=`1.00000`、XZ=`1.00000`、YZ=`0.999559`。新 Rust STL 为一个闭合定向组件，边界边、非流形边和绕向冲突边均为 0。验收 STL 和比较 JSON 保存在 `%TEMP%\f5.98-99-2412ebb\crankshaft\rust\`。

此处通过的是固定旧 Quick raw 输出的表面采样对拍，不证明连续 Hausdorff 上界、制造精度或真实 CATIA 结果。旧 BREP 的全长轴/矩形连接块路径仍是不同的几何契约，不与本项混用。
