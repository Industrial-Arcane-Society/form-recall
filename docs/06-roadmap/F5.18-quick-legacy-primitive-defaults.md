# F5.18：Quick 圆柱、圆锥与球体默认值

## 范围

恢复旧 Python Quick 对独立圆柱、圆锥和球体的基础默认值及裸尺寸回退。只对没有孔/槽等切除修饰的独立基础体启用；带修饰的基础体继续要求能确定的半径和高度，避免静默补出可能错误的工件尺寸。

## Python oracle

Oracle 为 `src/legacy/ai_modeler/core/parsing/nlparser.py` 中的 `make_cylinder()`、`make_cone()` 和 `make_sphere()`，通过 `nlparser.parse(text).doc.to_dict()` 读取。12 个固定输入、原始参数、包围盒、解析器默认/裸尺寸归类和解析器 warning 保存在 [`quick_legacy_primitive_defaults_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_primitive_defaults_contract.json)。旧 Python parser 对这些样例没有 warning；Rust 增加了参数来源和兼容提示，避免把推导值误报为用户标注值。

旧行为包括：

- 圆柱默认半径 `25 mm`、高度 `50 mm`；显式直径转为半径，裸尺寸组按旧规则取首值为直径、末值为高度。
- 圆锥默认底半径 `25 mm`、高度 `50 mm`；旧规则把裸尺寸最后一个数值用作高度，单一“直径”值也会落入这个高度回退。Rust 如实保留该兼容行为，并将裸尺寸映射标为 `derived`、附加 warning。
- 球体默认半径 `25 mm`；显式直径转为半径，单个裸数值按旧规则除以 2 作为半径。
- 圆柱/圆锥沿用原点底面中心、`base=true`、Z 轴及 48 段；球体沿用原点球心、32 段与 16 环。

这组回退优先复现旧 parser 的真实输出，不代表裸尺寸的工程语义是合理或无歧义的。Rust 为默认尺寸、中心/轴/离散度等缺省数值记录 `derived` 来源；未明确单位的数值仍按 mm 解释并提示。

## CADPlan 与几何实现

- 当前公开 CADPlan 用 `kind="cylinder"`、`radius>0`、`radius2=0` 表示尖顶圆锥。`radius2` 的校验/schema 下限因此从严格正数放宽为非负数；负值仍是错误。OCCT 原生圆台/圆锥建模可处理此输入。
- 参数说明同步记录 `radius2>=0` 且零代表尖锥。这是为旧 Quick 圆锥数据补齐必要的 CADPlan 兼容能力。
- 有孔/槽修饰的描述不使用本次默认值；缺少必需半径时返回澄清。圆台/带第二个非零半径的圆锥、复杂复合描述和其他裸尺寸语法不属于本次范围。
