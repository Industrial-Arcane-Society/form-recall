# F5.45：Quick 旧 Python 曲轴

## 迁移依据

旧 Quick 入口为 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.parse`，零件库构造器为 `src/legacy/ai_modeler/parts/library/partlib.py::_crankshaft`，网格构造器为 `src/legacy/ai_modeler/core/geometry/kernel.py::make_crankshaft`。旧零件库的典型参数为主轴颈直径 `d=50 mm`、连杆颈直径 `dp=42 mm`、行程 `S=86 mm`；构造器默认四拐。未给总长时，内核按 `max(1.8×行程, 2.2×主轴颈直径)×拐数` 推导。包围盒为 `[总长, 行程+连杆颈直径, max(主轴颈直径, 连杆颈直径)]`。

旧的曲柄臂是主轴颈与偏心连杆颈的外公切凸包，外缘为哑铃形。旧解析器接受中文别名、`d/dp/S/n/L` 简写以及零件名后的三个裸数。它会丢弃非正尺寸并回退到典型值、将非正拐数回退为 4、向零截断小数拐数；带 `cm` 的值会保留数值、不换算单位。

## Rust Quick 行为

- 支持“曲轴/发动机曲轴/crankshaft”、中文尺寸名、`d/dp/S/n/L` 简写和三个裸数。补充识别“连杆颈直径 42”这类旧解析器容易漏掉的别名组合，并对重复冲突值要求澄清。
- 未写主轴颈、连杆颈或行程时沿用旧典型值 `50/42/86 mm`；未写拐数或写非正拐数时沿用旧默认 4；总长缺失或非正时沿用旧自动总长公式。每项默认/推导值在 warning 与 CADPlan `sources` 中标记。
- 正拐数小数按旧规则向零截断；大于 128 拐的输入因本地几何融合资源边界返回 `unsupported`。
- Rust 将明确标注的厘米、米、分米和英寸换算为毫米，修复旧解析器把单位标注丢掉的问题。以 `d=5 cm、dp=4.2 cm、S=8.6 cm、L=32 cm` 为例，Rust 尺寸为 `320×128×50 mm`，旧解析器得到 `32×12.8×5 mm`；差异保存在 Python oracle fixture。
- 本地 OCCT 建模使用解析圆柱和矩形曲柄臂并融合为一个闭合实体。它只在参数、外包尺寸和曲拐布局上近似旧网格；旧网格的哑铃形曲柄臂及其多边形体积不能由当前 B-Rep 复现。CATIA 映射仍标为近似，本项没有验证 CATIA。
- 油孔、油道、配重、键槽、螺纹、倒角、圆角和额外切除尚未迁移，明确返回 `unsupported`。
