# F5.50：Quick 旧 Python 涡旋盘配方

## 迁移依据

旧 Quick 零件库入口为 `src/legacy/ai_modeler/parts/library/partlib.py::HARD_PARTS['涡旋盘']`，参数构造由 `_scroll` 完成；旧网格由 `src/legacy/ai_modeler/core/geometry/kernel.py::make_scroll_disc/profile_scroll` 生成。已直接运行 `partlib.build_features_ex()` 核对参数，并调用旧几何函数采集网格统计。

旧配方输出一个 `scroll_disc` 特征，参数依次为外径 D、总高 H、壁厚 t、圈数 n、原点中心和固定 120 段采样。螺旋截面使用阿基米德半径公式：

- `R=max(2, D/2)`，`h=max(1,H)`，`wt=max(0.5,t)`，`turns=max(0.5,n)`。
- 起始半径 `r0=0.2R`，每圈径向行程 `pitch=max(0.5,(R-wt/2-r0)/turns)`。
- 以 `theta=2π·turns·i/120` 对内外壁各采 121 点，截面点数为 242。
- 螺旋墙沿 Z 轴贯穿总高；底盘半径为 R，高度 `max(0.5,0.35h)`，从 `z=-h/2` 起建。两部分在旧网格中重叠拼接。

旧 Python Quick 实测：

| 输入 | 旧特征外形 | 旧网格 | 旧网格体积估算 |
|---|---:|---:|---:|
| `涡旋盘 外径100 高度30 壁厚4 圈数2.5` | 100×100×30 mm | 1030 polygons / 1688 triangles | 533930.4910 mm³ |
| `给我做个外径150 高度40 壁厚5 圈数3 的涡旋盘` | 150×150×40 mm | 1030 polygons / 1688 triangles | 1893596.9627 mm³ |
| `涡旋压缩机 外径160 高度45 壁厚6 圈数3` | 160×160×45 mm | 1030 polygons / 1688 triangles | 2409475.6823 mm³ |

这些体积是相交网格面的旧估算，不代表单一有效实体的物理质量。旧特征参数含 `wall_t`，但其 `provenance` 未记下壁厚来源；Rust 会补上用户来源标记。

## Rust Quick 行为与差异

- `涡旋盘`、`涡旋压缩机` 迁移到已有 `native_scroll_disc`，沿用旧半径、壁厚、圈数、中心和 120 段轮廓参数。OCCT 将螺旋墙和底盘融合为一个有效闭合实体，并检查自交、相切和采样预算；面数及体积不直接和旧重叠网格比较。
- 圈数缺省时沿用旧构造器的 2.5 圈并标记为推导值。旧配方虽把 `t` 列为可选字段，但 `_scroll` 会用 `p['t']` 直接索引；未写壁厚时实测抛 `KeyError`。Rust 返回补充壁厚的澄清，不伪造成功结果。
- Rust 将显式 cm 等单位换算为 mm；旧 Quick 保留原数字。例如 `外径10cm 高度3cm` 在旧路径得到 10×10×3，Rust 按 100×100×30 mm 构建并返回差异警告。
- 保留旧构造器外径至少 4 mm、总高至少 1 mm、壁厚至少 0.5 mm、圈数至少 0.5 的下限钳制，但在 Rust 结果中显式告警。
- 动盘/静盘配对、偏心、孔槽、密封槽及自定义螺距没有从旧 Quick 配方迁移；Rust 明确标为 unsupported。

## 验收

- `quick_legacy_scroll_disc_contract.json` 固定 Python 参数/网格 oracle、别名、默认圈数、单位差异和拒绝边界。
- `f5_50_legacy_scroll_disc_contract_tests` 对拍 parser 输出、特征来源、Schema、本地几何预检及轮廓采样参数。
- `f5_50_legacy_scroll_discs_build_measure_reopen_and_export` 通过真实 OCCT 对样例构建，核对有效闭合实体、包围盒、支持细节、AIMODEL 重载和 GLB/STL/OBJ 文件。运行需要设置 `AIMODELER_OCCT_MANIFEST`。

本项只覆盖单体旧式涡旋盘，不代表动静盘压缩机副、精密解析螺旋曲面或 CATIA 原生涡旋结构已迁移。
