# F5.67：迁移旧目录默认基础体

## 范围

将固定零件目录中 15 个旧 Python Quick 裸名称回退样例迁移到 Rust Quick：10 个方块/简化体名称、4 个圆柱名称和 `EGT型材`。本项复现旧 Parser 实际给出的默认几何，不宣称这些默认值是工程标准，也不把简化方盒描述为真实型材或气缸结构。只匹配裸目录名称；添加尺寸或结构修饰时交还其他解析分支，不吞掉输入。

迁移名称：`EGT型材`、`EGT连接件`、`销座`、`支座`、`支座(铝)`、`止块`、`分气块`、`阀岛`、`标牌`、`补高台`、`气缸连接块`、`夹紧气缸`、`手动夹紧气缸`、`双导杆气缸`、`接近开关`。

## 兼容参数与限制

- 除 `分气块` 外，方块旧默认均为 `50×30×10 mm`；`分气块` 为 `120×65×35 mm`。均沿 Z 轴、中心位于原点、`base=false`、直角。
- `EGT型材` 按旧 Quick 实际结果复现为 `80×80×88 mm` 的直角方盒。警告说明它不是 EGT 挤压截面。
- 四个圆柱名称沿用旧目录的半径 `25 mm`、高度 `100 mm`、Z 轴居中放置及 48 段设置。警告说明这些只是历史回退值，不代表行业标准气缸尺寸或真实结构。
- 所有回退尺寸均记录为 derived 来源；尺寸和附加结构不会误命中这些裸名称模板。

## 验收结果

Release headless/OCCT 固定目录全量对照覆盖 66 个输入，其中旧 Python Quick 有 60 个成功结果。F5.66 到 F5.67 的对照如下：

| 指标 | F5.66 | F5.67 |
|---|---:|---:|
| 目录输入数 | 66 | 66 |
| 旧 Python 成功 | 60 | 60 |
| Rust `complete` | 43 | 58 |
| 旧成功、Rust 未完成 | 17 | 2 |
| 本项新完成样例 | 0 | 15 |

本批 15 条新增输入全部得到通过的几何报告和一个闭合实体，外形尺寸与旧 Parser 的固定输出一致。其他 51 条输入的状态、包围盒和体积在前后快照中保持一致。

仍未完成的两个旧 Python 成功输入是 `内六角螺钉` 和 `吊环`，分别留给独立迁移项继续核对。本项不代表 F5 整体完成。
