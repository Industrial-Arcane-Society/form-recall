# F5.103：旧 Quick 花键轴凹槽 modifier 差异基线

## 固定输入与旧入口证据

固定提示词：`花键轴 小径20 大径25 长度40 齿数8 键槽宽5`。本项实际运行旧 Python `Parser().parse → Document.build()` 并保存 raw binary STL；完整 Feature 参数/provenance、解析步骤、统计值和 SHA-256 见 [`legacy_raw_baseline.json`](../../artifacts/f5-spline-shaft-groove/legacy_raw_baseline.json)，网格为 [`legacy_document_build_raw.stl`](../../artifacts/f5-spline-shaft-groove/legacy_document_build_raw.stl)。复跑脚本为 [`capture_legacy_baseline.py`](../../artifacts/f5-spline-shaft-groove/capture_legacy_baseline.py)。

旧 Parser 成功并生成花键轴 prism 与 pocket cut 两个特征。后者由旧通用凹槽默认规则得到 `length=20 mm, width=5 mm, depth=5 mm`、`axis=Z`、`corner=0`；旧输入没有键槽坐标，不能据此声称有工程定位、配合或标准符合性。

## Rust 差异与范围

Rust native Quick 当前将此输入返回 `unsupported`，issue 为 `legacy_spline_shaft_modifier_not_migrated`，入口见 `src/apps/desktop/src-tauri/src/native_quick_parser.rs::parse_legacy_spline_shaft`；固定拒绝样例见 `src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_spline_shaft_contract.json`。本证据只建立旧 Python Quick raw mesh 基线，不代表 Rust parity，也不使用 `Document.build_brep()`、CATIA 或 Cargo。

下一窄迁移/验收边界限于“旧花键轴主体 + 一个旧通用凹槽 modifier”，逐项保留或显式提示旧默认尺寸与放置语义。孔、多个槽、阵列、边缘修饰、自定义齿形另行处理。旧 Python 网格结果本身不是制造适用性证明。

## 复跑

在仓库根目录 PowerShell 执行：

```powershell
$env:PYTHONPATH = 'src/legacy'
python artifacts/f5-spline-shaft-groove/capture_legacy_baseline.py
```

脚本通过旧 `export_stl` 写出 mesh，并重写 JSON 报告；它不调用 Rust、Cargo、B-Rep builder 或 CATIA。输出 SHA 用于核对当前环境下复跑产物是否逐字节相同。
