# F5.70：修复 Quick 叶片展长/弦长解析

## 范围

修复一个 66 项零件目录之外的旧 Quick 成功输入：`叶片 展长80 弦长40`。旧 Python Parser 能将 `展长` 绑定为叶片 span、将 `弦长` 绑定为 root chord，并沿用默认 tip chord；Rust 原解析把单字“长”同时扫入 span 和 chord，造成值冲突并返回 `parse_failed`。

本项调整叶片模板内的字段识别顺序：span 识别 `展长/叶展/叶高/叶片长度` 等明确标签，不再让泛化的“长”匹配误读“展长/弦长”；根弦长支持 `弦长` 与 `根弦长`，梢弦长按显式梢标签识别。既有 loft 几何算法不变，仍是当前本地 facet-BREP 近似，不代表解析曲面或 CATIA 原生多截面放样。

## Parser 对照

| 输入 | 旧 Python Quick | Rust Quick |
|---|---|---|
| `叶片 展长80 弦长40` | `loft`: span 80、root chord 40、tip chord 20；其余厚度比 0.12、弯度比 0.05、扭转 18°、后掠 0、8 截面、26 点 | 同样为 `loft`，span/root/tip 为 80/40/20；显式 span/root 标记为 user，tip 的 20 标为 derived |

额外测试 `叶片 展长80 根弦长40 梢弦长25` 验证 Rust 对明确根/梢标签的新增支持，得到 80/40/25。旧 Python 对该新写法仍回退为 80/40/20（忽略显式梢弦标签）；这是额外语法扩展，不计作旧行为逐字段等价。

## 几何验收

通过 Rust Release headless/OCCT 直接运行两个目标输入。旧兼容输入生成通过的几何报告和一个闭合实体，外形尺寸为 `40×7.6286769×80 mm`，与旧 Python 一致。旧 Python 网格体积为 `5963.5410 mm³`，OCCT facet-BREP 体积为 `6093.0914 mm³`，相差约 `129.5504 mm³`（约 `2.1724%`）；这是旧网格与 OCCT facet-BREP 的不同计算结果，不代表逐三角面等价。显式根/梢标签扩展输入也通过几何报告。
