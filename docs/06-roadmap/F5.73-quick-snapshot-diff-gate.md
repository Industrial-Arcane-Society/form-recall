# F5.73：为 Quick 历史快照增加可失败的差分门禁

## 目的

目录审计会保存旧 Python 与 Rust headless/OCCT 的完整结果，但原脚本只生成快照，不会因为输入集变化、几何状态退化或样例数量不符而失败。本项新增只读快照比较 CLI，可在每次 Quick 兼容迁移后复用历史快照并设置期望范围。

## 当前比较范围

- 先验证两份快照的行结构、样例数量、重复输入和输入集合。
- 汇总旧 Python 成功数与 Rust complete 数。
- 按输入比较 Rust 状态、包围盒、几何报告状态、闭合实体数量和体积。
- 尺寸/体积使用可配置的绝对与相对误差容限。
- 可为旧 Parser 成功数、Rust 完成数和发生变化的样例数设置固定值或范围；门禁失败返回非零码，非法快照返回错误码。

该工具比较 Rust 历史快照字段，不宣称逐字段比较旧 Python 特征树与 Rust CADPlan，也不替代 Quick UI、工程保存/重载、网格导出重开或 CATIA 验收。

## 验证记录

使用 F5.68 与 F5.69 的 66 项目录快照，结果为输入集一致、旧 Python 成功 60 项、Rust complete 60 项，只有 `吊环` 一项从 `parse_failed` 变为 `complete`；该项新快照包围盒为 `63.0000002×35.0000002×89.5000002 mm`，几何状态 `passed`，闭合实体数 1。期望 60/60/变化 1 的门禁通过；将 Rust complete 期望改为 61–65 后，脚本按预期返回非零。

复跑命令：

```powershell
python tools/compare_quick_legacy_snapshots.py src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_catalog_baseline_after_f5_68.json src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_catalog_baseline_after_f5_69.json --expect-legacy-success 60 --expect-rust-complete 60 --expect-changed 1
```

对同一快照比较时设置 `--expect-changed 0` 也通过。
