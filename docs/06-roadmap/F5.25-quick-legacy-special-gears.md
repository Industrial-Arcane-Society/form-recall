# F5.25：迁移旧 Quick 斜齿与锥齿轮

## 范围

将旧 Python Quick 零件库中的斜齿圆柱齿轮与锥齿轮配方接入 Rust Quick。Rust 按旧 parser/partlib 参数和默认值生成 CADPlan，再走生产路径 `native_quick_parser → CADPlan 校验 → Rust/OCCT → GLB/AIMODEL/STL/OBJ → AIMODEL 重载`。

本项只迁移齿轮主体和配方内置中心孔。圆角、倒角、键槽、额外螺纹和孔阵列仍明确返回 `unsupported`。普通裸词 `斜齿轮` 没有参数提示时继续走旧通用齿轮分支。不会将旧螺旋角参数误称为真正的螺旋齿面，也没有验收 CATIA 原生特殊齿轮。

## 旧版契约

Python oracle 位于 `src/legacy/ai_modeler/core/parsing/nlparser.py` 与 `src/legacy/ai_modeler/parts/library/partlib.py`。输入、参数和测量值保存在 [`quick_legacy_special_gears_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_special_gears_contract.json)。

- `斜齿圆柱齿轮` / `斜齿轮` / `螺旋齿轮`：默认模数 3、24 齿、齿宽 25 mm、螺旋角 18°、中心孔 0、分段数 20。
- `直齿锥齿轮` / `螺旋锥齿轮` / `锥齿轮` / `伞齿轮`：默认模数 4、20 齿、齿宽 22 mm、锥角 45°、中心孔 0、分段数 12。
- 两个特殊配方均以全局原点为中心。未给尺寸时沿用旧零件库默认值，并把默认参数记为 `derived` 来源；显式尺寸记为 `user`。
- 特征树名称保留旧 `Document.KIND_LABELS`：斜齿显示“斜齿轮”，锥齿显示“锥齿轮”。
- 旧 `Document` 几何将斜齿螺旋角记录在参数中，但实际齿廓沿 Z 直线挤出；这不是螺旋齿面。锥齿用梯形轮廓沿齿宽线性收缩，是离散近似。
- 裸输入 `斜齿轮` 不满足特殊 partlib 参数触发条件，旧 parser 会创建通用 `gear`：模数 2、20 齿、厚度 10 mm。

## 解析修复

首轮生产 CLI 验收发现 `斜齿圆柱齿轮` 被误判成“特殊齿轮 + 圆柱基础体”，随后由通用 parser 拒绝。原因是混合基础体检查仅按子串查找 `圆柱`，而该词本身就在旧斜齿零件名中。Rust parser 现在先分派旧齿轮配方，并在检查第二个基础体前剥离 `圆柱齿轮` 零件名片段；输入若另外描述了实际圆柱，仍走原有拒绝路径。

## 几何复核

Python 与 Rust 都使用 OCCT 7.9 系列。由于 Python 的旧 BSP 网格体积与 OCCT 闭合 BREP 的体积不是同一测量，验收分别记录二者；几何通过依据为 `Document.build_brep()` 对照 Rust/OCCT BREP。旧网格 `K.volume_of` 数据只保留作历史观测，不拿来与 BREP 体积比较。

| 输入 | Python 旧 BREP 尺寸 / 体积 | Rust Quick 尺寸 / 体积 | Rust 三角面 | 结果 |
|---|---|---|---:|---|
| `斜齿圆柱齿轮 模数3 齿数24 齿宽25 螺旋角18 中心孔20` | 77.9615 × 77.9615 × 25 mm / 90,564.95420822094 mm³ | 77.9615 × 77.9615 × 25 mm / 90,564.95420822069 mm³ | 928 | 一个有效闭合体；AIMODEL 重载通过 |
| `直齿锥齿轮 模数4 齿数20 齿宽22 锥角45 中心孔15` | 87.9375 × 87.9375 × 22 mm / 56,462.015011005606 mm³ | 87.9375 × 87.9375 × 22 mm / 56,462.015011005606 mm³ | 4,400 | 一个有效闭合体；AIMODEL 重载通过 |
| `斜齿轮 模数3 齿数24` | 77.9615 × 77.9615 × 25 mm / 98,386.67746023196 mm³ | 77.9615 × 77.9615 × 25 mm / 98,386.67746023207 mm³ | 764 | 旧默认值一致；AIMODEL 重载通过 |
| `锥齿轮 模数4 齿数20` | 87.9375 × 87.9375 × 22 mm / 53,838.71076682808 mm³ | 87.9375 × 87.9375 × 22 mm / 53,838.71076682808 mm³ | 4,400 | 旧默认值一致；AIMODEL 重载通过 |
| `斜齿轮` | 通用 gear：43.9687 × 43.9687 × 10 mm / 12,088.028942485375 mm³ | 通用 gear：43.9687 × 43.9687 × 10 mm / 12,088.028942485375 mm³ | 636 | 保持旧回退语义；AIMODEL 重载通过 |

显式斜齿的旧 `Document.build()` 网格为 9,744 个三角形、包围盒一致，但其自定义网格体积记录为 30,188.318069 mm³；`Document.build_brep()` 的闭合实体体积是 90,564.954208 mm³。显式锥齿的对应网格体积为 15,375.435253 mm³，BREP 体积为 56,462.015012 mm³。Rust 的 BREP 结果与旧 BREP 数值一致；Rust STL/GLB 由 Rust OCCT 再三角化，面片数不要求复制 Python 原网格剖分。该数值对照不等于视图像素级或 CATIA 特征级对照。

## 解析边界

- `斜齿轮 模数0 齿数24 齿宽25` 返回 `needs_clarification`，不生成计划。
- `锥齿轮 模数4 齿数20 齿宽22 键槽宽6` 返回 `unsupported`，不会静默忽略键槽。
- 普通通用齿轮语法及参数继续由 F5.21 覆盖；蜗轮、蜗杆和内齿轮仍不支持。
