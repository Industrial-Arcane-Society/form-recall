# F5.64：修复活塞环槽数与销孔尺寸误绑定

## 范围

修复已迁移的 Python Quick 活塞配方在旧目录输入“活塞 外径80 高度70 销孔22 环槽数3”上的解析回归。此项只调整环槽数词法消歧并扩充 F5.48 的固定参数/几何验收输入，不另建一套活塞几何。

## 根因与实现

`piston_groove_count` 同时读取“环槽数3”这种标签后置参数，以及“3道环槽”这种数量前置写法。旧正则也把紧邻“环槽数”前的数字当成数量，于是将销孔直径 22 与环槽数 3 判为冲突，返回 `parse_failed`。

现在先检查数量前置匹配结束后的剩余文本：若后面紧接中文“数”或英文“count”，该匹配属于标签后置语法，前面的数字不参与数量前置解析。其余明确的前置数量写法仍保留；不同语法确实给出冲突数量时继续返回澄清。该实现不依赖 Rust `regex` 不支持的 look-around。

旧 Python 公共入口 `Parser.parse` 对该目录输入返回一个 `piston` 特征：D=80 mm、H=70 mm、销孔=22 mm、环槽=3、外圆 48 段，包围盒 80×80×70 mm，旧多边形网格体积统计 489433.0027 mm³。

活塞样例 Release headless 实测结果：

- OCCT：几何报告 `passed`、`valid=true`、一个闭合实体；包围盒 80.0000002×80.0000002×70.0000002 mm；报告 3 道槽均已构建。
- AIMODEL reload：`passed`，重载后保留一个特征。
- AIMODEL、GLB、STL、OBJ 四个输出文件均实际生成。

Python `Document.stats()` 的旧网格体积为 489433.0027 mm³，Rust B-Rep 体积为 227823.8704 mm³。旧体积来自 `kernel.volume_of` 对多边形网格使用的有向散度求和；旧 `make_revolve` 用 `rmax×0.4=16 mm` 作为活塞面的定向参考点，而该点落在内半径 22 mm 的中空区。此外，旧 Python 活塞槽循环按顶部到下部遍历，而剖面从下向上构造。代码显示旧面方向/槽轮廓的体积统计存在风险，但本项没有逐面修复或验证旧三角网格，也没有宣称新旧表面完全等同。因此，体积差异和活塞旧网格的几何差异仍是 F5.48 的后续几何审计项；本项的通过范围是解析参数恢复和 Rust 当前候选实体的有效构建，不是活塞完整几何等价验收。
