# F5.52：Rust Quick 迁移旧 Python 三角转子配方

## 迁移依据

旧 Quick 的入口为 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.handle`，部件库路由为 `partlib.build_features_ex()`，零件配方为 `src/legacy/ai_modeler/parts/library/partlib.py::_wankel`。旧特征参数是外接圆半径 `R`、厚度 `H`、中心孔 `d`、几何中心 `(0,0,0)` 和固定采样数 `n=48`。

本次在当前 Python 环境中直接运行了旧 `Parser.parse()`：

| 输入 | 旧 Quick 结果 |
|---|---|
| `三角转子 外接圆半径60 厚度40 中心孔24` | 1 个 `rotor` 特征；包围盒 111.992828×109.368750×40 mm；806 面、1542 三角形；旧 B-Rep 体积 352265.101060 mm³ |
| `三角转子 厚度40` | 使用典型值 R=60、d=24 mm；H=40 mm 来自用户；成功生成 1 个转子 |
| `三角转子 外接圆半径60` | 旧解析器未生成转子，因为 `_wankel` 必需的 H 缺失 |
| `转子发动机转子 半径45 厚度25 中心孔10` | 识别别名并生成 R45×H25、中心孔⌀10 mm 的转子 |
| `三角转子 厚度40 中心孔0` | Python 将 `0` 当作未填写，错误代入典型中心孔⌀24 mm |
| `三角转子 外接圆半径6cm 厚度4cm 中心孔1cm` | Python 主体仍按 6×4 mm；⌀10 被拆成额外通用孔特征，最终不是预期的 60×40 mm 转子 |

## Rust Quick 行为

- 新增三角转子和“转子发动机转子”路由，映射到现有 `native_rotor` OCCT 实现；参数校验与几何能力仍标记为近似轮廓，不声称是精确 Reuleaux 曲线或完整 Wankel 发动机转子。
- 保持旧缺省规则：厚度必须明确；仅缺少半径或中心孔时分别使用 R=60 mm、⌀24 mm，并给出 warning 和 `derived` 参数来源。转子中心原点与 48 点轮廓作为派生参数记录。
- 解析显式 cm、in 等尺寸并换算为 mm；中心孔直接写入 `rotor.bore_d`，不会额外拆出通用孔特征。
- 明确输入中心孔 0 时生成无孔转子，并提示这是对旧 Python truthiness 默认错误的修正。
- 高度、重复参数、无效尺寸或超出实际孔壁净距时返回澄清；偏置孔、侧孔、壳体、偏心轴、密封槽、进排气结构、键槽、螺纹和边缘修饰返回未迁移状态，不会静默忽略。

## 验收

- 固定旧解析器对照、默认值、来源、单位差异、零孔差异、澄清和未迁移边界：`src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_rotor_contract.json`。
- Rust 回归覆盖解析/CADPlan/原生预检：`f5_52_legacy_rotor_contract_tests`；OCCT 端到端验收覆盖几何、AIMODEL 重载与 GLB/STL/OBJ 输出：`f5_52_legacy_rotors_build_measure_reopen_and_export`。后者通过 `AIMODELER_OCCT_MANIFEST` 指定本地 runtime。
- `cargo check --tests` 通过。`cargo test f5_52_legacy_rotor_contract_tests` 已编译测试二进制，但 Windows 在测试进程启动阶段返回 `0xC0000139 STATUS_ENTRYPOINT_NOT_FOUND`，Rust harness 未执行断言。
- 使用更新后的生产 `ai-modeler-headless-smoke.exe` 实际构建了显式尺寸、典型缺省、cm 换算、中心孔 0 四种模型。四者均为 `complete`、几何 `passed`、单个有效闭合实体；包围盒均为 111.992828×109.368750×40 mm。显式⌀24 模型的 OCCT B-Rep 体积为 352265.101060 mm³，与旧配方记录值一致；cm 输入被纠正为 R60、H40、⌀10。输出包含 AIMODEL、GLB、STL、OBJ，生产 smoke 路径执行了 AIMODEL 重载校验。
- 同一生产入口验证了只给 R 时返回 `legacy_rotor_height_required`，偏置/非中心孔返回 `legacy_rotor_hole_location_not_migrated` 或 `legacy_rotor_modifier_not_migrated`。

本项仅完成本地 Rust Quick 转子主体。发动机壳体、偏心轴、密封结构及 CATIA 原生特征仍未迁移或验证。
