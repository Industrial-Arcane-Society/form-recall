# F5.105：A100 三槽旧 V 带轮宽度重叠基线

## 固定输入与入口

固定提示词：`V带轮 基准直径100 槽数3 槽型A 内孔25 宽度30`。

本次在仓库根目录通过旧 Python Quick 公共入口 `Parser().parse(prompt)`，再实际调用 `result.doc.build()`、`result.doc.stats()` 并导出 binary STL。另对同一 Document 独立调用 `Document.build_brep()`；此调用与 raw mesh 分开记录。运行时为 CPython 3.11.9。未调用 Rust parser/CADPlan validator、Cargo、CATIA 或桌面 UI。

## 旧 Quick 实测结果

旧 `Parser.parse()` 成功：`ok=true`、`recognized=1`、无 questions/assumptions。它对 30 mm 请求宽度发出 warning，按旧标准规则调整为 `46.31971385738069 mm`。输出一个 `vbelt_pulley/add` Feature，实际参数为：

- `pitch_d=100`、`grooves=3`、`groove_type=A`、`bore_d=25`、`height=46.31971385738069 mm`；外径 `105.5 mm`，中心 `[0,0,0]`。
- Feature provenance 将五个提示词给出的输入标记为 `explicit`，派生外径标记为 `derived`；完整 `params`、`explain`、`std_warnings` 与来源字段见 JSON 中 `document_feature`。

`Document.build()` 成功生成旧 raw STL：1,536 个 polygons、3,072 个 triangles；bbox `[-52.75,-52.75,-23.159856928690346,52.75,52.75,23.159856928690346] mm`，尺寸 `105.5×105.5×46.31971385738069 mm`。旧 `Document.stats().volume` 为 `584036.1790703516 mm³`，是该旧多边形网格的体积标量；鉴于剖面自交，它不是有效闭合实体的 B-Rep 体积。

## 实际槽位置与旧剖面自交

捕获脚本以实际解析 Feature 参数调用旧 `std_pulley.spec(..., keep_width=True)` 和 `std_pulley.profile()`；这是 `Document.build()` 的 `vbelt_pulley` 分支使用的同一剖面生成函数。A 型三槽剖面的实际根半径为 `41.3 mm`，三个槽根区间和中心为：

| 槽 | 根区间 Z (mm) | 中心 Z (mm) |
|---:|---:|---:|
| 1 | `[-22.959856928690346, -6.640143071309655]` | `-14.8` |
| 2 | `[-8.159856928690346, 8.159856928690346]` | `0` |
| 3 | `[6.640143071309655, 22.959856928690346]` | `14.8` |

相邻槽根中心距为 `14.8 mm`，根宽为 `16.31971385738069 mm`，所以两个相邻根区间各重叠 `1.51971385738069 mm`。对闭合轴向剖面所有非相邻线段做 2D 交叉检查，实测到 4 对自交：两对根线段共线重叠、两对槽壁 proper crossing。旧 `make_revolve` 按剖面边逐段绕轴生成 raw triangle mesh，因此该 mesh 是由自交剖面扫掠而来；本基线未执行完整 3D triangle-triangle 碰撞计数。

Raw STL 顶点按 `1e-5 mm` 量化焊接后的边 incidence 为 0 boundary edges、0 nonmanifold edges、1 个共享边连通组件，但有 1,086 条边的相邻三角面绕向冲突。**边 incidence 闭合不等于方向一致，也不消除几何自交**；该 raw STL 不作为有效 B-Rep 实体。

## 独立旧 `Document.build_brep()` 尝试

对同一旧 Document 单独调用 `Document.build_brep()` 未得到 B-Rep，也没有写出 BREP 文件。实测异常为 `GeometryBuildError`：

`特征 0 (vbelt_pulley) 建模失败：输入轮宽 46.3197 mm 无法容纳 3 个标准 V 槽；无自交剖面的最小轮宽为 50.4591 mm。`

因此这里有两个不同的旧 Quick 结果：旧 Parser → `Document.build()` 接受并调整到 `46.3197138574 mm`，成功输出自交 raw 网格；同一参数经单独 `Document.build_brep()` 的更严格 OCCT/轮廓路径则失败。不能把后者的失败反推成旧 Parser 或旧 raw Quick 输入失败，也不能把 raw 网格体积称作有效实体体积。

## Rust validator 失败的归属（静态基线）

现有 F5.29/F5.79 记录已说明 `Document.build()` 旧路径保留重叠槽根，而 CADPlan/B-Rep validator 仍按无自交实体的最小轮宽校验。此固定 A100 输入在共享 validator 中报告 `vbelt_width_below_profile_minimum`，正是该合同差异；旧 Python Quick raw 路径本身并未拒绝该输入。本次只运行旧 Python，未执行 Rust parser、validator 或测试，故不声称复现了 Rust 错误。

保留 F5.79 的旧宽度 `46.3197138574 mm` 并走 Quick mesh-only，才符合该输入的旧 raw 行为；不能把尺寸改成 `50.4591415721 mm` 后再称为旧宽度对拍。`mesh_only` 应明确标示不提供 B-Rep、闭合实体/CATPart 或 CATIA 结果。若另需实体建模，只能作为独立新行为/经用户接受的近似，不得静默替换旧尺寸合同。

建议的最小验收证据：

1. Parser oracle 保留旧 `height=46.31971385738069`、warning、输入/derived provenance 和槽根中心 `[-14.8,0,14.8] mm`。
2. Quick mesh-only 路径逐字节保存或以固定网格对拍验证 3,072 triangle raw mesh、bbox 与特征槽位；报告自交/绕向限制，保持 B-Rep/solid count 未知或 unavailable。
3. Validator 对这条旧兼容候选的宽度错误只通过明确受限的 Quick mesh-only 路由绕过；其他 CADPlan 原生实体和非匹配 plans 仍受原 validator 约束。
4. 若验收实体路线，保留单独的 `Document.build_brep()` 失败事实并说明任何参数扩大均属新合同，不能拿它替代旧 raw oracle。
