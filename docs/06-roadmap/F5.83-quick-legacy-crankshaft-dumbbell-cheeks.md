# F5.83：Quick 旧 Python 曲轴哑铃形曲柄颊

## Python Quick 基线

基线位于 `%TEMP%\f5-83-crankshaft-legacy-baseline\`。输入为 `曲轴 主轴颈50 连杆颈42 行程86 拐数4`，真实调用链是 `Parser.parse` → `Document.build` → `kernel.make_crankshaft` → 旧二进制 STL 导出；未经过 `build_brep`、OCCT、CATIA 通道。

- 特征参数：`main_d=50`、`pin_d=42`、`stroke=86`、`throws=4`、`length=null`、`center=[0,0,0]`、`segments=32`。
- 实际解析后总长 619.2 mm；网格包围盒 619.2×128×50 mm，1074 polygon faces、1692 triangles；有向网格体积 `+1248953.4128572405 mm³`。
- STL SHA-256：`b76934eca0b4e3b6e70099554397e8d3bfde3fc4526ca8352601f78ea30c424d`。
- 三视投影在同目录 `projection-xy.png`、`projection-xz.png`、`projection-yz.png`。

旧 Python Quick 曲柄颊轮廓是主轴颈圆和偏心连杆颈圆的外公切凸包；几何内核按 32 段圆弧离散，然后沿 X 轴连接两圆。它不同于旧 Python OCCT/CATIA B-Rep 路径的矩形腹板，因此本项对拍基准明确使用 Quick 网格入口。

## Rust Quick 实现范围

Quick parser 在曲轴特征上附加可选 `geometry_variant=legacy_quick_dumbbell_cheeks`。Rust OCCT builder 以旧外公切轮廓生成 YZ 多边形截面，沿 X 棱柱化并与解析主轴颈、偏心连杆颈融合为单一闭合实体；未提供该字段的普通 CADPlan / Agent 继续使用现有矩形web实现。该变体复刻主要轮廓，不声明三角 STL 完全一致；解析圆柱与旧 32 段圆网格的轮廓差在定向截面验收中以 0.25 mm 容差评估。
