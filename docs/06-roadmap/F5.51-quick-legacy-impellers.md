# F5.51：Quick 旧 Python 叶轮配方

## 迁移依据

旧 Quick 的识别入口为 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.handle`。它先调用 `partlib.build_features_ex()`；若缺少叶轮外径 D 或高度 H，部件库不生成叶轮，随后通用 `try_template` 将“叶轮”回退为 blisk 模板。Rust 保留这个路由边界：只有明确提供 D 和 H 才生成 `impeller`，不把无尺寸的旧 blisk 误认成叶轮。

旧特征构造位于 `src/legacy/ai_modeler/parts/library/partlib.py::_impeller`，几何配方位于 `src/legacy/ai_modeler/core/geometry/kernel.py::make_impeller`。旧参数为 `hub_d`、`tip_d`、`height`、`blades`、`twist_deg`，以及原点中心和 12 个截面间隔。未提供时沿用旧默认轮毂直径 30 mm、9 个叶片、扭转角 55°。本次直接运行旧 Python Quick，确认以下网格统计：

| 输入 | 旧网格包围盒 | 面数 | 三角形 | 网格体积估值 |
|---|---:|---:|---:|---:|
| `涡轮叶轮 轮毂直径30 外径120 高度40 叶片数9 扭转角55` | 120×120×40 mm | 698 | 1316 | 419247.9323 mm³ |
| `压气机叶轮 轮毂直径20 外径80 高度26 叶片数7 扭转角60` | 80×80×26 mm | 586 | 1108 | 102919.4533 mm³ |

旧几何将轮毂做成锥体，轮盘半径范围为 `0.45×rh` 到 `rt`、厚度为 `max(0.5, 0.28×height)`，叶片以 12 个间隔采样并融合。旧代码计算了局部叶片厚度 `th`，但没有把它用于叶片轮廓；实际叶片贯穿全高。Rust 因此将 `blade_t` 从必填项改为可选项，省略时按全高处理，并在支持详情中返回 `blade_t_defaulted=true`。

## Rust Quick 行为与差异

- Rust 迁移旧轮毂、轮盘、扭转矩形叶片配方，使用本地 OCCT facet-BREP 近似叶片；CATIA 映射仍只包含轮毂和轮盘，未创建 CATIA 扭转叶片。
- 旧 `make_impeller` 会静默钳制轮毂直径至少 2 mm、尖端直径至少 `1.05×hub_d`、高度至少 1 mm、叶片数至少 3 并取整。Rust 保留结果并附带警告；超出原生预算或不能形成有效几何时返回澄清/不支持。
- 对明确的轴向中心孔尺寸（如 `中心孔10`）追加贯穿 Z 轴的 `hole` 切除；偏置孔、叶片孔、叶片曲面/厚度、流道、分流叶片、键槽、螺纹和边缘修饰显式标记为未迁移。
- Rust 将明确标注的 cm 等长度转换为 mm。旧 Python Quick 曾把单位后的原数字当作 mm，例如 `外径12cm 高度4cm 轮毂直径3cm` 在旧几何中按 12×12×4 mm 解释，Rust 按 120×120×40 mm 建模并返回单位差异警告。
- 显式输入来源标记为 user，旧默认和派生参数标记为 derived；旧 provenance 对部分叶轮参数缺少来源记录，Rust 补全来源信息。

## 验收

- `src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_impeller_contract.json` 固定旧 Python Quick 参数/网格 oracle、默认值、中心孔、单位差异、无尺寸回退和未迁移边界。
- `f5_51_legacy_impeller_contract_tests` 对拍解析参数、来源、默认提示、CADPlan 校验、本地几何预检以及 `blade_t` 可选语义。
- `f5_51_legacy_impellers_build_measure_reopen_and_export` 使用已暂存 OCCT runtime 实际构建两种叶轮与带中心孔变体，检查单闭合实体、有效性、包围盒、AIMODEL 重载及 GLB/STL/OBJ 输出。运行需要设置 `AIMODELER_OCCT_MANIFEST`。

## 本次验证结果

- `cargo check --tests` 通过，包含解析器和 OCCT 验收测试的编译检查。
- 使用生产 `ai-modeler-headless-smoke` 和 OCCT 7.9.3 实际构建并重载 AIMODEL：120×120×40 mm、80×80×26 mm，以及 120×120×40 mm + ⌀10 轴向中心孔。三者均为有效的单闭合实体；报告的 B-Rep 体积依次为 336076.793953、87324.856526、332935.201299 mm³。均生成 GLB、STL、OBJ、AIMODEL。
- 生产 smoke 另验证了旧默认轮毂/叶片数/扭转角，以及 cm 输入换算到 120×120×40 mm；来源标记和警告可见。
- `cargo test f5_51_legacy_impeller_contract_tests` 已成功编译测试二进制，但 Windows 在启动二进制时返回 `0xC0000139 STATUS_ENTRYPOINT_NOT_FOUND`，因此断言没有实际运行。几何验收改用上述生产 CLI 完成。
- 仓库级 `cargo fmt -- --check` 报告了大量既有 Rust 文件格式差异；本项没有对全仓库做格式化，以免引入无关改动。

本项只迁移旧 Quick 的整体叶轮主体和同轴中心孔。不代表高阶水力叶型、流道、叶片真实薄壳曲面、偏置孔或 CATIA 原生叶片已迁移。
