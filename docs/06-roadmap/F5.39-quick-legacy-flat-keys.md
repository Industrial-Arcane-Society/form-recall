# F5.39：Quick 旧 Python 平键

## 迁移依据

旧 Quick 入口为 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.parse`，零件库构造器为 `src/legacy/ai_modeler/parts/library/partlib.py::_key`。构造器只生成一个居中长方体，并使用零件参数轴映射：键宽 `b` 沿 X、键高 `h` 沿 Y、键长 `L` 沿 Z。因此 CADPlan 的 `box.length/width/height` 分别为 `b/h/L`，外形为 `b×h×L`，`base=false`。

旧 Python oracle 输入、特征参数、默认来源及网格统计记录在 [`quick_legacy_flat_key_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_flat_key_contract.json)。它覆盖中文完整尺寸、`b/h/L` 符号写法、仅省略宽度时沿用 `b=8 mm`，以及平键截面的倒角和圆角。

## Rust Quick 行为

- 支持 `平键 宽度8 高度7 长度40`、`键 b8 h7 L40`，并接受显式短标签 `平键 宽8 高7 长40`。短标签是 Rust 输入扩展，因为旧 Python 对该写法没有生成模型。
- 仅当 `h` 和 `L` 都是有效显式值时，缺少 `b` 才沿用旧零件库的典型宽度 8 mm，并以 warning 和 `derived` 来源记录。缺少 `h` 或 `L`、尺寸冲突或非正尺寸时要求补充，不静默补值。
- 支持截面上的显式圆角/倒角，几何仍按现有 Rust box 轮廓实现；同时指定两种方式需要澄清。带键槽、孔、花键、螺纹或其它未迁移结构的请求返回 `unsupported`。
- 裸别名 `键` 加短中文尺寸（例如 `键 宽10 高8 长40`）在旧 Python 中会落入通用长方体路径。Rust 不会把它误认作平键，避免悄悄改变既有通用解析语义。

解析合同测试 `native_quick_parser::tests::legacy_flat_keys_match_python_oracle_axis_mapping_and_provenance` 对照 Python fixture，覆盖 5 个旧版有效输入、缺失/无效值、未迁移键槽、明确短标签扩展，以及避免误接管裸 `键` 通用长方体。

OCCT 集成测试 `native_quick::acceptance_tests::f5_39_legacy_flat_keys_build_measure_reopen_and_export` 构建直角、倒角和圆角 3 个样例。三者包围盒均为 `8×7×40 mm`；Rust OCCT 体积分别为 `2240`、`2160`、`2204.857806090322 mm³`，与旧 Python 三角网格统计差异小于 `1e-6` 相对误差。每个样例均为单个有效闭合实体，并通过 AIMODEL 保存/重载及 GLB、STL、OBJ 文件生成检查。
