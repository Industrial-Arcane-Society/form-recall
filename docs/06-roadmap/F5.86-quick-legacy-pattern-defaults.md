# F5.86 Quick 旧版阵列默认值兼容

## 范围

补回旧 Python Quick 对线性阵列和圆周阵列的默认参数与别名行为。只迁移一个可判定的阵列操作；多个或冲突操作继续拒绝，避免把一段描述猜成多个特征。

- 线性阵列缺少参数时，默认数量为 4、轴为 Z、步距为 20 mm。
- 圆周阵列缺少参数时，默认数量为 4、轴为 Z、角度为 360°。
- 通过别名推导出的值标记为 `derived`，并写入来源说明和告警。
- 数量、轴、步距和角度可从同一请求的逗号分隔片段提取；显式冲突或非法值仍然拒绝。

## 旧版入口核对

通过旧 Python `Parser().parse(text)` 公共入口实测 5 个输入，结果保存在 `quick_legacy_pattern_defaults_contract.json`。旧实现 `Parser.try_pattern` 的默认规则为：数量 `4`、轴 `Z`、线性步距 `20 mm`、圆周角 `360°`。5 个 oracle 样例均与 fixture 一致。

## 验收结果

- F5.86 parser 定向测试：`1 passed`。
- 后续提交 `f53fbe1` 修正了 validator 对所有特征都要求恰好一个闭合实体的错误约束：显式 additive pattern 仅在 OCCT shape 有效、每个实体均闭合且闭合实体数与 pattern count 相同时接受。
- 修复后，F5.12 的 OCCT 几何集成测试 5/5 通过。线性阵列生成 4 个闭合实体，包围盒为 `150×30×50 mm`，OCCT B-Rep 体积为 `141371.6694 mm³`；其他 4 个案例仍各为 1 个闭合实体。测试同时覆盖 AIMODEL 重新载入、STL 导出及三角面计数。
- 未运行全量测试；本功能证据限于旧 parser oracle、F5.86 parser 测试、F5.12 OCCT 几何集成测试及上述修复。
