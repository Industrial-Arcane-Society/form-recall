# F5.42：Quick 旧 Python 花键轴

## 迁移依据

旧 Quick 零件库构造器为 `src/legacy/ai_modeler/parts/library/partlib.py::_spline_shaft`，截面算法为 `src/legacy/ai_modeler/core/geometry/kernel.py::profile_spline`。构造器生成一个从原点沿 +Z 拉伸的单一 `prism`，轴向长度为 `L`。轮廓每齿 7 个采样点，齿顶半径为 `D/2`，齿根半径为 `min(d/2, 0.92×D/2)`；点坐标在构造特征时四舍五入到 0.0001 mm。

Python 实际入口、4/6/8 齿轮廓点列、默认值及 mesh 统计保存在 [`quick_legacy_spline_shaft_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_spline_shaft_contract.json)。旧零件库把“花键轴”“矩形花键”“渐开线花键”都路由到同一个 `profile_spline`；“渐开线花键”名称并未生成渐开线齿形。

## Rust Quick 行为

- 支持“花键轴”“矩形花键”“渐开线花键”名称及 `d/D/L/z` 字母参数。大径 `D` 和长度 `L` 必须给出；缺失时 Rust 要求澄清，避免旧 Parser 退化成普通圆柱或不出结果。
- 外径和长度明确时，可沿用旧典型小径 `d=20 mm`、齿数 `z=8`，并通过 warning 及来源标记默认。默认单位为 mm。
- 齿数下限沿用旧 kernel 的 4 齿钳位；Rust 将齿数限制为最多 128 以约束多边形规模。小数齿数会要求澄清，而不是重复旧 builder 对小数静默截断的行为。
- 小径必须小于大径。旧解析器对颠倒尺寸会误退化成圆柱；Rust 明确要求修正。显式孔、键槽、螺纹、修饰、阵列和自定义齿形返回 unsupported。
- “渐开线花键”仍复现旧版错误命名下的简化矩形齿轮廓，并给出警告。该形状没有中心孔，也没有渐开线、配合公差、齿侧修形或标准校核。

## 验收

解析合同测试 `native_quick_parser::tests::legacy_spline_shafts_match_python_oracle_and_default_provenance` 对照旧 Python 的 4、6、8 齿完整点列，覆盖显式参数、缺省小径/齿数、符号参数、别名、缺失/冲突尺寸、非整数齿数和复合特征拒绝。CADPlan 校验与原生 preflight 均通过。

OCCT 集成测试 `native_quick::acceptance_tests::f5_42_legacy_spline_shafts_build_measure_reopen_and_export` 构建 8 齿、6 齿和旧下限钳位后的 4 齿实体。三者均为单个有效闭合实体，包围盒分别为 `24.9892×24.9892×40`、`24.9808×24.9808×40` 和 `24.9566×24.9566×40 mm`。B-Rep 体积与旧 Python mesh 体积的相对差均低于 `6×10⁻¹⁶`；AIMODEL 重载及 GLB、STL、OBJ 输出检查通过。
