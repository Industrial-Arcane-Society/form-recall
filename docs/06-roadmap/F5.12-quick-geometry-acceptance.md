2026-10-05 在 `feat/f5-12-quick-geometry-acceptance` worktree 中，固定五条 Quick 描述已通过 Rust parser → CADPlan 校验 → OCCT B-Rep → AIMODEL/STL 导出验收。五例均生成一个有效闭合实体，预期特征均实际执行，几何包围盒、孔实例数和正有限体积符合 fixture；AIMODEL 能重新载入，STL 的二进制长度与三角面计数相符。四角孔、PCD 孔与中心沉孔的最终孔计量均通过。

阵列 fixture 的源特征是实体圆柱，因此它们验收的是 feature pattern，不计作孔。沉孔仍使用同轴 through pilot 与较大直径 blind cut 的原 Quick 解析顺序。

每个几何构建均断言 OCCT `valid=true`、`closed_solid_count=1`、CADPlan 特征映射与 built 特征数一致、体积有限且大于零。带孔的三例还要求全部实例的最终 B-Rep 测量完成：圆柱半径、轴线、轴向长度与 360° 覆盖必须被接受。

### 同轴沉孔的几何验证

原执行器通过中心线推断盲孔入口，因此在小径 through pilot 已打通中心线后无法构造沉孔。现只在存在更早、同轴、同方向、直径较小的 through pilot 时识别该组合：切刀入口依据 pilot 外侧与沉孔内侧之间 16 条环带材料射线的共同区间确定；若样本材料区间不唯一或不一致则拒绝，不回退到全局包围盒猜值。

沉孔复核使用 48 条环带射线检查指定深度及底部余料，另用 32 条沉孔外射线要求外侧材料存在且前后不变。pilot 在最终模型上改用沉孔外侧保护射线检查贯穿性，并按母材轴向长度减去沉孔深度核对 pilot 圆柱 B-Rep 面。最终验收五例中，pilot 与沉孔 B-Rep 计量及几何报告完成门均通过。

另有普通中心盲孔控制输入 `长方体 长100宽80高20，中心盲孔直径10mm深5mm`：通过原中心线材料核验与最终盲孔 B-Rep 深度核验，证明该特殊环带路径没有放宽普通盲孔规则。该控制不计入五条固定 fixture。

## 复跑方式

在仓库根目录进入 Rust crate 后，用真实 staging manifest 显式运行被普通测试集忽略的 OCCT 集成验收。未提供 manifest 或路径不存在时，显式运行会失败，不会记录成成功或静默跳过。

```powershell
Set-Location src/apps/desktop/src-tauri
$env:AIMODELER_TEST_OCCT_MANIFEST = 'C:\path\to\staged\runtime-manifest.json'
.\scripts\test-lib.ps1 -Filter native_quick::tests::f5_12_quick_geometry_acceptance_builds_supported_hole_and_pattern_cases -Exact -Ignored -NoCapture
```

本次使用的 manifest 是主 checkout `src/apps/desktop/src-tauri/target/f4-occt/runtime-manifest.json`；worktree 单独编译并运行测试。普通 `test-lib.ps1` 不执行该集成测试（状态为 ignored）；要复验必须保留 `-Ignored` 并配置上述环境变量。

已通过的定向命令：

