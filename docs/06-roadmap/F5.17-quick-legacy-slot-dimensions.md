# F5.17：Quick 矩形槽默认尺寸

## 范围

恢复旧 Python Quick 对已识别矩形槽缺失尺寸的默认值：槽长、槽宽默认为 `20 mm`，槽深默认为 `5 mm`。已有尺寸对、尺寸三元组及标注尺寸优先；只为没有提供的字段补默认值。圆槽不在本项范围。

## Python oracle

Oracle 入口为 `src/legacy/ai_modeler/core/parsing/nlparser.py` 的 `try_pocket()`，由 `nlparser.parse(text).doc.to_dict()` 直接读取。原始特征参数、顺序及警告记录于 [`quick_legacy_slot_defaults_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_slot_defaults_contract.json)。已对拍的输入包括：

| 输入槽描述 | 旧 Quick 槽尺寸（长×宽×深，mm） | 旧 Python warning |
|---|---:|---|
| `矩形槽` | 20×20×5 | 无 |
| `矩形槽 长30` | 30×20×5 | 无 |
| `矩形槽 20×8` | 20×8×5 | 无 |
| `矩形槽 深2` | 20×20×2 | 无 |
| `铣两个槽` | 两个 20×20×5，中心 X=-15、15 | 未指定间距时按 1.5×槽长居中排布，间距 30 mm |

旧 parser 的 `Feature.provenance` 对槽尺寸为空；Rust 为保持来源透明度，把输入明确提供的尺寸标为 `user`，把默认补齐值标为 `derived`，并发出 `legacy_slot_dimensions_defaulted` 警告。这是面向新 CADPlan 的来源/提示扩展，不声称与旧 provenance/warnings 字段逐字相同。未给单位时 Rust 也保留自己的默认毫米提示。

## Rust 边界

- 只在已识别的矩形槽上启用 `20×20×5 mm` 补值；数组的数量、中心间距和特征展开仍按旧 Quick 规则。
- 输入给出的槽尺寸若非有限正数，返回 `needs_clarification`；不以默认值覆盖错误值。
- 圆槽继续返回明确的 `unsupported_slot_profile`，不按矩形槽建模。
- 多个槽未给坐标时，Rust 记录默认值来源与槽间距警告；OCCT 验收验证真实切除实体与实测体积。

## 验收

`native_quick_parser::tests::rectangular_slots_fill_missing_dimensions_from_python_defaults` 对照五种固定 Python oracle 输出、CADPlan 校验、默认值来源、数组位置和拒绝边界。忽略测试 `native_quick::tests::f5_17_legacy_slot_defaults_build_and_export` 对五种输入逐项实建，检查 OCCT B-Rep、闭合实体数、包围盒、体积、AIMODEL/STL 导出及 AIMODEL 重载。

2026-10-06 实测：Python oracle 固定样例 **5/5**、Rust parser 专项 **22/22**、F5.17 OCCT 实建 **5/5** 均通过；每个模型都是一个有效闭合实体，五种情况的 AIMODEL/STL 写出与 AIMODEL 重载均通过。测得体积分别为 `118000`、`117000`、`119200`、`119200`、`116000 mm³`，均在 `1e-4 mm³` 误差内符合预期。额外回归 F5.15 双显式尺寸槽的 OCCT 用例 **1/1** 通过，实测体积 `119360 mm³`，确认显式尺寸保持原行为。测试使用 OCCT 7.9.3 runtime manifest；未运行 CATIA 或桌面可见 UI。
