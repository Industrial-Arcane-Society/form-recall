# F5.9：Quick 显式线性阵列

## 兼容范围

Rust Quick 迁入 legacy Python Quick 的一项线性阵列语法：对紧邻前一特征复制，保留源特征的 `add`/`cut` 操作，并创建指向源特征的唯一 `pattern_source` 关系。当前仅接受明确阵列数量、X/Y/Z 方向和正间距；数量范围为 2 至原生阵列上限。圆周阵列、镜像和省略尺寸的 legacy 默认行为仍拒绝。

## Python oracle

Oracle 是 `src/legacy/ai_modeler/core/parsing/nlparser.py`。输入 `圆柱 直径30mm 长50mm，沿X方向阵列4个，间距40mm` 的 `parse(text).doc.to_dict()` 输出第二个特征为 `kind=pattern`、`op=add`，参数为 `mode=linear`、`count=4`、`axis=X`、`step=[40,0,0]`；legacy 另带 `compound=false` 和 `stack=true`。CADPlan pattern schema 不接受这两个 legacy 专用旗标，Rust 按 native 变换执行路径映射几何契约参数，并核对源链接及 CADPlan validation。Fixture `src/apps/desktop/src-tauri/tests/fixtures/quick_linear_pattern_contract.json` 保存 oracle 参数及旗标。

## 拒绝行为

缺少数量、方向或间距，数量小于 2，或非正间距都会返回 `needs_clarification` 且不产生 plan。圆周阵列和其他未迁入语法仍返回 `unsupported`，不会静默忽略阵列要求。

## 边界

该项是 Quick parser/CADPlan 层契约，不代表 OCCT 阵列执行、UI、Agent 或 CATIA 实测。当前 CATIA capability 对 X 轴阵列标为 unsupported；不得将 Quick 解析通过当成 CATIA 导出通过。原生几何与端到端行为须由对应独立验收覆盖。
