# F5.22：旧 Quick 的 PCD 均布沉孔

## 迁移范围

Rust Quick 支持在同一子句中描述一组 PCD 贯穿孔及其同轴沉孔，例如：

```text
长方体 长120宽80高20，均布4个直径6通孔分度圆60带直径12沉孔深4
```

解析结果按顺序生成一组小径 `hole/cut` 贯穿孔和一组大径 `hole/cut` 盲沉孔。后者继承先导孔的 PCD、孔数、轴向、相位和圆周分段；尺寸来源继续标记为用户输入或推导。Rust 不恢复旧 Python 沉孔省略深度时静默使用 5 mm 的行为，缺少明确深度时返回待澄清且不生成 CADPlan。

本项只迁移**同一子句里的 PCD 孔阵列沉孔**。坐标孔、四角孔、中心孔与 PCD 混用、多修饰子句、缺失/冲突尺寸和非正深度均不属于支持范围。

## Python Quick 对照

Fixture [`quick_pcd_counterbore_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_pcd_counterbore_contract.json) 来自旧 `nlparser.parse(text).doc`。原始输入产生长方体 `120×80×20 mm`、4 个 ⌀6 通孔和 4 个 ⌀12、深 4 mm 的沉孔，均位于 PCD 60 mm 上；Python warning 为空。旧 Python 的无深度默认行为仍记录为 Rust 的拒绝边界，不作为兼容目标。

## 几何验收

使用 OCCT 7.9.3 构建该样例，检查一个有效闭合实体、8 个孔实例、四组同轴先导孔/沉孔、孔 B-Rep 终态测量全部通过、AIMODEL 保存重载和 STL 导出。实测包围盒为 `120×80×20 mm`，体积 `188380.8852630645 mm³`；与解析子句对应的解析体积 `192000 - 1152π = 188380.88526306496 mm³` 相差小于 `1e-4 mm³`。CATIA 与桌面可见预览不在本项验证范围。
