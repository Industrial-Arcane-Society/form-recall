# F5.48：Quick 旧 Python 活塞配方

## 迁移依据

旧入口 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.parse` 调用 `partlib.build_features_ex`，特征构造在 `src/legacy/ai_modeler/parts/library/partlib.py::_piston`，网格构造在 `src/legacy/ai_modeler/core/geometry/kernel.py::make_piston`。

旧配方要求活塞外径与高度；没有指定销孔直径时使用典型值 22 mm，环槽数在构造器中默认 3。中心在原点，外圆网格按 48 段生成。活塞回转剖面内半径为 `max(1 mm, 0.55×外半径)`，槽深为 `max(0.4 mm, 0.06×外半径)`，槽宽为 `max(0.6 mm, 0.035×高度)`，环槽均匀放在顶部 34% 高度带内。销孔沿全局 X 轴贯穿，刀具半径按 `min(pin_d/2, 0.75×外半径, 0.45×高度)` 限制。

冷启动 Python oracle 对照：

| 输入 | 旧特征参数 | 旧网格包围盒 | 旧网格体积 |
|---|---|---|---:|
| `活塞 外径80 高度60` | D=80、H=60、销孔=22、环槽=3 | 80×80×60 mm | 414560.5008 mm³ |
| `活塞 外径80 高度60 销孔24 环槽数2` | D=80、H=60、销孔=24、环槽=2 | 80×80×60 mm | 407913.2938 mm³ |
| `活塞 D80 H70 d22 n3` | D=80、H=70、销孔=22、环槽=3 | 80×80×70 mm | 489433.0027 mm³ |

体积与旧网格离散有关，不能要求解析 OCCT B-Rep 体积逐数相等；迁移验收以闭合有效实体、包围盒、销孔参数/轴向和实际构建环槽数为准。

## Rust Quick 行为

- 将 `活塞`、`发动机活塞`、`piston` 映射到现有 `piston` 原生几何特征；外径、高度为必需尺寸。
- 缺省销孔为 22 mm，缺省环槽为 3；CADPlan `sources` 区分用户尺寸和旧配方默认/几何来源。
- 支持 `外径/直径/D`、`高度/高/H`、`销孔/d`、`环槽数/n` 及明确长度单位。小数环槽按旧 Python `int()` 截断，负数按 0 处理；超出 Rust 原生资源范围时返回澄清。
- 本地 OCCT 使用闭合剖面解析回转与 X 向布尔销孔，环槽剖面点与旧网格公式一致；本地圆周面改为解析曲面。CATIA 映射仍近似，不宣称 CATIA 原生活塞环槽或销孔特征。
- 旧解析器输入 `活塞 外径80 高60 销孔22 环槽数2` 会退回普通圆柱、漏掉销孔和环槽；Rust 按工件名和尺寸将 `高` 解释为活塞高度，并返回差异 warning。显式厘米单位的旧输入也可能退回圆柱和独立通用切除；Rust 则正确换算后建活塞。这两项是记录出来的行为修正，不伪称逐字节兼容。
- 独立活塞环、顶部燃烧室/阀坑、油道、键槽、倒角及其它附加结构明确拒绝。

## 验收代码与限制

- `native_quick_parser::f5_48_legacy_piston_contract_tests` 对拍旧 Python 参数、默认、来源、典型别名、差异 warning、缺尺寸/冲突、无效尺寸及未迁移结构，并检查 CADPlan 和原生几何预检。
- `native_quick::acceptance_tests::f5_48_legacy_pistons_build_measure_reopen_and_export` 会通过 OCCT 构建 3 个样例，检查有效闭合单实体、包围盒、pin bore 构造参数和环槽构造数，保存/重载 AIMODEL 并验收 GLB/STL/OBJ 文件。
- 集成验收需本机配置 `AIMODELER_OCCT_MANIFEST` 并使用项目的本地 OCCT runtime manifest。

此项覆盖旧 Quick 的简化活塞配方，不代表真实燃烧室形状、活塞裙复杂型面、活塞环独立装配或 CATIA 原生特征已迁移。
