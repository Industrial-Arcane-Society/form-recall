# F5.10：Quick 显式圆周阵列

## 范围

把旧 Python Quick 已支持、Rust Quick 明确拒绝的一项圆周阵列语法迁入 native parser。接受 `圆周阵列` 与 `环形阵列`，对紧邻前一特征生成 `pattern`；要求显式数量、X/Y/Z 旋转轴，以及带 `°`、`deg` 或 `度` 的正角度。数量范围为 2–4096。阵列 operation 保留源特征的 `add` 或 `cut`，并创建唯一 `pattern_source` 关系。

阵列旋转中心固定为全局原点，`full` 根据角度是否为 360° 推导。Python 旧模板的 `compound`/`stack` 旗标不属于 CADPlan pattern 参数，不迁入。旧 parser 对数量、轴和角度的默认值（4、Z、360°）不沿用；缺少必需值时 Rust Quick 返回 `needs_clarification`。

## Python oracle

Oracle 是 `src/legacy/ai_modeler/core/parsing/nlparser.py` 的 `try_pattern()` 与 `parse(text).doc.to_dict()`。Fixture `src/apps/desktop/src-tauri/tests/fixtures/quick_circular_pattern_contract.json` 保存三个实测结果：半圆 `圆周阵列`、全圆 `环形阵列`，以及源特征为 `cut` 的中心孔阵列。Python 对拍字段分别覆盖 `mode=circular`、数量、轴、角度、`full`、全局原点，以及源 operation。

在仓库根目录用 PowerShell 重放 fixture：

```powershell
$env:PYTHONPATH = "src/legacy"
@'
import json
from pathlib import Path
from ai_modeler.core.parsing.nlparser import parse

fixture_path = Path("src/apps/desktop/src-tauri/tests/fixtures/quick_circular_pattern_contract.json")
fixture = json.loads(fixture_path.read_text(encoding="utf-8"))
for case in fixture["legacy_accepted"]:
    # Normalize tuples and other Python values to the JSON contract used by the fixture.
    doc = json.loads(json.dumps(parse(case["input"]).doc.to_dict(), ensure_ascii=False))
    source = doc["features"][case["source_index"]]
    pattern = doc["features"][-1]
    assert source["kind"] == case["source_kind"]
    assert source["op"] == case["source_operation"]
    for key, expected in case["pattern"].items():
        assert pattern["params"][key] == expected, (case["input"], key)
    for key, expected in case["legacy_flags"].items():
        assert pattern["params"][key] == expected, (case["input"], key)
    print("PASS", case["input"])
print(f"{len(fixture['legacy_accepted'])} cases passed")
'@ | python -
```

Rust parser 将数量、轴和角度记为 user provenance；固定原点及由角度计算的 `full` 记为 derived provenance。pattern 引用紧邻前一 feature，并与 CADPlan validation 接口检查。

## 限制与验收边界

- 当前 Quick 子集只接收明确的数量、轴和正度数角；省略任一项、弧度、数量小于 2 或超过 4096、角度非正时澄清且不生成计划。
- `圆周阵列`/`环形阵列` 沿用旧 parser 在全局原点旋转的语义；不新增自定义旋转中心。
- golden 只证明 parser/CADPlan 参数和 provenance 对拍，不代表此项执行了 OCCT B-Rep 阵列、CATIA 导出、Tauri UI 或 Quick→Agent 端到端验收。
