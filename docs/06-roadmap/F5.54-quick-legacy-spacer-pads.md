# F5.54：Rust Quick 迁移旧 Python 垫片垫块配方

## 旧入口对照

对照 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.handle`、`partlib.build_features_ex()`、`src/legacy/ai_modeler/parts/library/partlib.py::PROFILE_PARTS['垫片垫块']` 与 `_spacer_pad()`。旧公共 Quick 入口的真实输出是一个居中长方体，不是圆环垫片。

| 输入 | 旧 Python Quick 结果 |
|---|---|
| `垫片垫块 长50 宽20 厚5` | 一个 `box/add`，尺寸 50×20×5 mm，中心 `[0,0,0]`，`base=false`、`axis=Z`；旧网格包围盒 `[-25,-10,-2.5,25,10,2.5]`，8 面、12 三角形，体积 5000 mm³、表面积 2700 mm²。 |
| `垫块` | 零件库回退到 50×20×5 mm 默认垫块，网格统计与上一行相同。 |
| `垫块 长50 宽20` | 长宽按文本取值，厚度回退到 5 mm。 |
| `垫片垫块 50x50x5` | 旧解析器未解析紧凑三维尺寸，错误生成默认 50×20×5 mm。 |
| `垫片垫块 长30cm 宽10cm 厚4mm` | 旧解析器忽略 cm 单位，生成 30×10×4 mm。 |

旧部件库对部分显式长宽的识别不稳定，例如 `长65 宽20` 会回退到 50×20；迁移不会复制这种覆盖用户明确尺寸的错误。旧输入以 `50x50x5` 明确给出三维尺寸时，Rust 按长×宽×厚读取，优先保留用户数据。

## Rust Quick 行为

- 新增 `垫片垫块`、`垫块` 旧名称路由，生成一个居中 `box/add`，默认值沿用旧 Quick 50×20×5 mm。
- 支持 `长/长度`、`宽/宽度`、`厚/厚度`、`高/高度`、`L/W/t`、`长×宽×厚` 紧凑尺寸；显式单位统一换算到 mm。
- 每个尺寸带 `user` 或 `derived` 来源；任何沿用默认尺寸都写入结构化警告。
- 对孔、槽、倒角、圆角、阵列或组合加工显式返回 `unsupported`，不静默生成不完整模型。
- “垫片”仍由原平垫圈/环形垫片解析处理；本项仅迁移明确的垫片垫块/垫块名称。

## 验收

- `tests/fixtures/quick_legacy_spacer_pad_contract.json` 固定旧 Quick 输出、默认值、旧解析差异、缺失/冲突尺寸、未迁移修饰及几何验收输入。
- `f5_54_legacy_spacer_pad_contract_tests` 覆盖参数、来源、CADPlan 校验、几何预检、旧紧凑尺寸与单位行为差异以及拒绝边界。
- `f5_54_legacy_spacer_pads_build_measure_reopen_and_export` 增加本地 OCCT 集成验收覆盖；项目测试可执行文件已编译，但此 Windows 环境启动测试 harness 时返回 `0xC0000139 (STATUS_ENTRYPOINT_NOT_FOUND)`，因此该 harness 本轮未执行。
- `cargo check --manifest-path src/apps/desktop/src-tauri/Cargo.toml --tests` 通过；Release `ai-modeler-headless-smoke` 构建通过。
- 用 Release 生产 headless Quick 入口实际运行四种输入：显式 50×20×5、紧凑 50×50×5、默认垫块、5 cm×2 cm×5 mm。均返回 `state=complete`、几何 `passed`、一个有效闭合实体，AIMODEL 重载通过，并生成 GLB、STL、OBJ、AIMODEL。
- 四种模型包围盒分别为 50×20×5、50×50×5、50×20×5、50×20×5 mm；对应 B-Rep 体积为 5000、12500、5000、5000 mm³。此为生产 Quick → OCCT → 本地工程导出验收，不代表 CATIA 或桌面 UI 可见性验收。

## 范围

本项迁移的是旧 Quick 的简化矩形垫块构造，不包含弹垫、环形平垫圈、安装孔、真实夹具装配或 CATIA 特征映射。
