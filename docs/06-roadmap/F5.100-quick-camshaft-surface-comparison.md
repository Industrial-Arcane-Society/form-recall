# F5.100：凸轮轴旧 Quick 与 Rust Quick 几何级比较

## 结论

当前 Rust 基线为 `2412ebbeb5971decaeb4d8d0de2dbddc2bf33ff8`。复用旧 oracle 工件（其 manifest 标记生成基线 `2641369`），并复用当前隔离 worktree 中的 Rust headless binary；没有再次运行 Cargo。固定输入 `凸轮轴 基圆直径30 升程8 长度320 凸轮数4 轴颈26` 的旧 Python Parser、raw mesh 和 BREP 均成功，Rust Quick 输出 `complete`、有效单闭合实体。

结论为 **not equivalent（当前固定采样验收未通过）**。旧 BREP 重载后以 `0.08 mm / 0.35 rad` 重新三角化，和 Rust STL 的双向最大采样距离为 `0.11059 mm`，超过 `0.08 mm` 阈值；包围盒完全一致，拓扑均为一个闭合定向组件，BRep/STL signed-volume 差 `564.397 mm³`，在 comparator 报告的面积容差 allowance 内。这个结果很接近阈值，正交投影的最大差异也小，但按当前比较器的通过条件仍不能记为通过。采样最大值是离散估计，不是连续 Hausdorff 上界；因此这里表示“不满足本轮证据门槛”，不是断言制造级外形必然偏差超过 0.08 mm。

旧 raw 与 Rust 的最大双向采样距离 `11.454 mm`，旧 raw→旧 BREP 为 `11.377 mm`。旧 raw 网格由轴和 4 个凸轮的 5 个闭合组件组成；旧 BREP 和 Rust 则各为一个闭合组件。旧 raw `Document.stats()` 的体积明显高于两种闭合实体路线，不用它覆盖表面证据或当作一个融合实体的体积。

## 固定输入、参数与来源

- 原句：`凸轮轴 基圆直径30 升程8 长度320 凸轮数4 轴颈26`
- 单位：长度 `mm`；角度 `deg`。
- 旧 parser 输出 1 条 `camshaft` add 特征：`base_d=30`、`lift=8`、`length=320`、`lobes=4`、`journal_d=26`、`center=[0,0,0]`、`segments=24`；无 parser warning/question。oracle 对 `lobes/length/journal_d` 标记为 explicit。
- Rust CADPlan 保留 5 个输入尺寸/数量为 `user`，`center=[0,0,0]` 和 `lobe_deg=0°` 为 `derived`；4 个凸轮沿 X 轴等距，profile 用 48 个样点，升程轮廓采用 legacy 120° harmonic rise。
- 旧 BREP 报告来自旧 `Document.build_brep()` 的 `faceted_brep_approximation`，有效、closed、1 solid；Rust headless 几何报告也为 `valid=true`、`solid_count=1`、`closed_solid_count=1`。本次没有 CATIA 或视觉验收。

## 证据边界与后续验证

旧网格构造位于 [`kernel.py`](../../src/legacy/ai_modeler/core/geometry/kernel.py) 的 `make_camshaft`（约 1937 行）：沿 X 轴添加轴颈圆柱，再生成 4 个 48 点 cam profile loft。Rust [`native_parametric_features.rs`](../../src/apps/desktop/src-tauri/src/native_parametric_features.rs) 的 `build_camshaft`（约 193 行）以 X 轴圆柱加 48 点 profile prism fuse。两条 BREP 路线都生成一个有效闭合实体，但构造/三角化路径并非逐面相同。

返修/复验建议：在旧 BREP 和 Rust BREP 上提高相同精度做自适应或截面核对，重点检查每个凸轮 profile 的峰顶与回程角段；如果要把本项升为 pass，需在固定采样最大距离不超过 `0.08 mm` 后重写结论。当前数据既不能称通过，也不应把“只高于阈值约 0.031 mm”夸大为精确连续曲面误差上界。
