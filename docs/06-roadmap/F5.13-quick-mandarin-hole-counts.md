# F5.13：Quick PCD 孔阵列中文数字数量

## 范围

补齐旧 Python Quick 已识别、Rust Quick 旧实现遗漏的单字中文孔数：`一二两三四五六七八九十` 后接旧 parser 所支持的数量单位。重点回归“均布四个”与 `count=4` 的 PCD 孔阵列。`count` 仍按 user 来源保存；孔数范围仍由现有 Quick/几何上限校验。

只迁移旧解析器的单字符匹配规则，不扩展成通用中文数词解释器。旧 Python 不会把“十一”按整数 11 解释，其单字符正则可能只匹配末位“ 一 ”而得到错误数量；该类多字数词的旧行为另列为待改进项，不作为正确数值兼容承诺。

## Rust 改动与兼容边界

- `hole_pattern_count()` 现在可从一个受限中文数词加数量单位读取孔数；阿拉伯数字路径、冲突拒绝和 `2..=MAX_HOLE_PATTERN_COUNT` 边界保持不变。
- 新识别的孔数使用完整原始描述作为 user evidence；`CADPlan` 中仍映射到原 PCD hole feature，不增加新的几何类型或额外默认位置。
- 多字中文数词、跨子句继承和省略 PCD/孔径等旧 parser 宽松行为不在此项修改范围内。
