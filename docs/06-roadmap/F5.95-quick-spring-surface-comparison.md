# F5.95：旧 Quick 弹簧网格、旧 B-Rep 与 Rust Quick 表面对比

## 结论

基线为提交 `e9f4324`。对 F5.27 的圆柱螺旋弹簧与锥形螺旋弹簧，分别保留旧 `Document.build()` 原始 STL、旧 `Document.build_brep()` 序列化 BREP 与其 STL、Rust headless Quick STL。用共同世界坐标系下的双向点到三角面采样比较后，两类弹簧的三组配对都在 `0.08 mm` 表面阈值内。

旧 raw mesh 的有向体积与旧 B-Rep / Rust B-Rep 明显不一致。拓扑检查发现 raw mesh 有方向冲突边，所以 raw mesh 的 signed-volume 数值标记为无效测量；这不抵消独立测得的表面距离结果。旧 B-Rep 与 Rust 的 STL 距离、包围盒和实体体积均一致到当前输出精度。

该结论是固定采样下的表面等价证据，不是连续 Hausdorff 距离上界、图片视觉验收或 CATIA 验收。旧 B-Rep oracle 是旧 Python 从其特征网格构造的 facet-BREP；Rust Quick 通过独立的 native Quick/CADPlan/OCCT 路径生成。

## 样例与结果

| 输入 | 旧 raw 面片 | 旧 raw `Document.stats()` 体积 | 旧 B-Rep 报告体积 | Rust B-Rep 报告体积 | 最大双向采样距离：raw→Rust / B-Rep→Rust | raw 绕向冲突边 |
|---|---:|---:|---:|---:|---:|---:|
| `螺旋弹簧 外径20 线径2 高度30 圈数8` | 6,192 | 7,078.287680 mm³ | 1,391.543508 mm³ | 1,391.543508 mm³ | 4.39×10⁻¹⁴ / 4.39×10⁻¹⁴ mm | 296 |
| `锥形弹簧 外径24 线径2 高度40 圈数6` | 4,656 | 5,923.570669 mm³ | 1,009.993976 mm³ | 1,009.993976 mm³ | 4.61×10⁻¹⁴ / 6.99×10⁻¹⁴ mm | 234 |

两例旧 B-Rep 与 Rust 都报告一个有效、闭合实体，且包围盒分别为 `20×20×30 mm` 与 `24×24×40 mm`。B-Rep 对比 STL 的 signed volume 差为 `0 mm³`。旧 raw 与 Rust 的拓扑网格各有 0 条边界边、0 条非流形边、0 个退化面、0 个重复面、1 个连通分量；但 raw 分别有 296 / 234 条相邻三角面使用同向边的绕向冲突。raw 到 B-Rep 的 STL 有向体积差分别为 5,686.743892 / 4,913.576616 mm³，故记录 `raw_mesh_volume_invalid=true`。

详细报告、各路径的输入哈希和 STL/BREP 文件位于 [`artifacts/f5.95`](../../artifacts/f5.95/acceptance_report.json)。旧 Python 参数与 B-Rep 检查保存在 [`legacy_oracle_report.json`](../../artifacts/f5.95/oracle/legacy_oracle_report.json)；Rust/表面比较逐样例记录在各 `rust/<case>/surface_comparison.json`。

## 比较算法与阈值

- STL 在各自原始毫米世界坐标中比较；不平移、不缩放、不各自归一包围盒。正交投影辅助报告使用两个网格包围盒的并集作为共同像素坐标框，分辨率为 64、128、256；投影不单独决定通过。
- 每个源三角面取 4 个固定重心内采样点，每点权重为该三角面积的四分之一。对两个方向分别计算源点到目标三角面的最近距离分布，报告面积加权均值、RMS、P50、P95、P99 和采样最大值。最近点对三角面距离通过 AABB BVH 加速，候选三角面距离使用精确点到三角形距离算法。
- 最大采样距离是固定样本的估计，不能视为整个连续曲面的 Hausdorff 上界。三角面不要求相同；面数与三角剖分差异不会单独判失败。
- 默认表面容差为 `0.08 mm`，与 Rust Quick 及旧 B-Rep STL 的 OCCT 线性偏差设置一致；角度偏差均为 `0.35 rad`。旧 `Document.build()` raw 网格不重网格化，也没有 OCCT 线性偏差保证，仍按同一阈值报告距离，解释时须保留该路径差异。
- 拓扑顶点以 `1e-5 mm` 网格量化焊接。10 µm 大于此处 20–40 mm 尺度下 STL float32 坐标量化误差，并比 0.08 mm 表面容差小 8 倍。报告边界/非流形边、退化/重复三角面、连通分量和边方向冲突。
- 表面等价、拓扑健康和 signed volume 分开报告。对 raw mesh，`raw_mesh_volume_invalid` 表示其有向体积不能作为有效闭合实体体积使用；该字段不覆盖 `surface_equivalence_passed`。

实现及合成合同：[`compare_mesh_surfaces.py`](../../tools/compare_mesh_surfaces.py)、[`run_f5_95_spring_surface_acceptance.py`](../../tools/run_f5_95_spring_surface_acceptance.py)、[`test_compare_mesh_surfaces.py`](../../tools/tests/test_compare_mesh_surfaces.py)、[`test_f5_95_spring_surface_samples.py`](../../tools/tests/test_f5_95_spring_surface_samples.py)。合成网格测试覆盖相同表面、平移 1 mm、缩放 2 倍。

## 复跑

在 Windows PowerShell 的隔离 worktree 中构建 headless 可执行文件。此检验不打桌面安装包；`TAURI_CONFIG` 只在该命令中跳过缺失的打包资源目录。headless 运行时仍通过显式参数加载项目资源根和 OCCT manifest。

```powershell
cd src/apps/desktop/src-tauri
$env:CARGO_BUILD_JOBS = '2'
$env:TAURI_CONFIG = '{"bundle":{"resources":[]}}'
cargo build --locked --bin ai-modeler-headless-smoke
```

然后由一个 runner 重建旧 Python 两种路径、调用 Rust headless、保存 STL/报告/哈希并运行比较：

```powershell
cd C:\path\to\AI-_-
py -3.11 -B tools\run_f5_95_spring_surface_acceptance.py `
  --headless-exe src\apps\desktop\src-tauri\target\debug\ai-modeler-headless-smoke.exe `
  --resource-root src\legacy `
  --occt-manifest C:\path\to\occt-runtime\runtime-manifest.json
```

只重跑固定样例验收与合成算法合同：

```powershell
py -3.11 -B -m unittest tools.tests.test_compare_mesh_surfaces tools.tests.test_f5_95_spring_surface_samples -v
```

本次使用 Python `3.11.9`、OCP `7.9.3.1`、Rust `ai-modeler-headless-smoke`，并通过只读 OCCT runtime manifest 加载 OCCT `7.9.3`。本次 Cargo headless 构建成功；未运行 CATIA，也未作安装包验证。
