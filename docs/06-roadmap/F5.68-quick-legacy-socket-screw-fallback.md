# F5.68：迁移旧目录内六角螺钉裸名称模板

## 范围

迁移固定零件目录输入 `内六角螺钉` 的旧 Python Quick 裸名称默认模板。现有按 M 规格查询实测螺钉的原生解析仍负责带规格输入；新回退只认裸名称，避免将用户给出的规格或附加结构吞入旧默认模板。

## 兼容参数与 CADPlan 表达

旧 Parser 的三项特征按顺序保留：

1. 杆：圆柱，半径 5 mm、高 30 mm、中心 `[0,0,-15]`、Z 轴、32 段、`base=false`。
2. 头：圆柱，半径 8 mm、高 10 mm、中心 `[0,0,5]`、Z 轴、48 段、`base=false`。
3. 内六角凹槽：对边约 8 mm、深 5 mm 的六边形棱柱切除，中心 `[0,0,5]`、Z 轴。

杆、头、凹槽尺寸均沿用旧裸名称固定回退，并作为 derived 来源记录；警告明确指出它们不代表任何具体 ISO/GB 规格，按规格建模须提供 M 尺寸。CADPlan 棱柱契约不接受冗余 `segments` 参数，因此六角形以旧 Parser 的六个精确轮廓点表达，未把 `segments=6` 传入几何参数。

## 验收结果

Release headless/OCCT 实际建模状态为 `complete`；几何报告通过，得到一个闭合实体，包围盒 `16×16×40 mm`，与旧 Parser 的尺寸一致。旧 Python 三角网格统计体积为 `4068.8380475 mm³`，Rust OCCT B-Rep 体积为 `4089.6856593 mm³`，相差约 `20.8476 mm³`（约 `0.512%`）。此体积对比跨越离散网格与解析 B-Rep 计算口径，不声称三角面逐面一致。

66 条固定目录输入的前后对照：

| 指标 | F5.67 | F5.68 |
|---|---:|---:|
| 目录输入数 | 66 | 66 |
| 旧 Python 成功 | 60 | 60 |
| Rust `complete` | 58 | 59 |
| 旧成功、Rust 未完成 | 2 | 1 |
| 本项目录螺钉样例 | `parse_failed` | `complete` |

唯一状态变化是裸名称 `内六角螺钉`；其他 65 条样例的状态、包围盒和体积保持不变。剩余一条旧 Python 成功但 Rust 未完成的目录样例是 `吊环`，由单独迁移项继续验收。
