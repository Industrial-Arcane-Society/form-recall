# F5.30：Quick 实测内六角螺钉配方

## 迁移依据

旧 Quick 输入 `帮我建 M5x8 内六角螺钉` 实际命中 `nlparser.Parser.parse -> partlib.build_features_ex -> measured.realparts.build_socket_bolt_real`。本轮重新运行旧 `Parser()`，结果为 `ok=true`、`recognized=1`、无 warning，生成 7 个有序特征：弹垫圆柱与内孔、平垫圆柱与内孔、螺杆圆柱、螺钉头圆柱和内六角切除。

尺寸来自 `kb/bolt_library.json` 的实测 M5x8 STEP 条目：螺杆 Ø5×8、头部 Ø8.5×5、内六角对边 4、弹垫 Ø8.8×1.2（孔 Ø5.1）、平垫 Ø10×1（孔 Ø5.3），整件实测包围盒 10×10×13 mm。标准粗牙螺距 0.8 mm、内六角深度 2.5 mm 取自 `kb/bolt_std.json`。旧配方将螺杆重建为光杆，并未输出螺纹几何。

## Rust Quick 行为

- 支持实测目录中存在且有标准螺距记录的 `M×L` 内六角圆柱头螺钉；未知型号、头型不明和冲突尺寸会明确拒绝或请求澄清。
- 默认保留目录里的弹垫和平垫，可由明确文字分别省略；圆环直接用 360° revolve 特征建模，避免把不同垫圈孔径合并成同一个切孔。
- 生成 `revolve` 弹垫、`revolve` 平垫和一个 `socket_head_bolt` 特征。M5x8 的包围盒目标仍为 10×10×13 mm。
- Rust 侧增加可见的三角网格螺纹；这是针对用户先前指出“螺钉没有螺纹”的有意增强，因此不声称与旧 Python 的光杆几何完全一致。螺纹是局部近似，不是解析螺旋面或 CATIA 原生螺纹。
- 额外孔槽、倒角、局部螺纹和明确的光杆要求会返回 unsupported；不把未迁移的附加要求吞掉。

## 验收结果

固定的 Python oracle、Rust CADPlan 期望和澄清边界记录在 `tests/fixtures/quick_legacy_socket_head_bolt_contract.json`。Rust parser 合同测试 **4/4 通过**；隔离 Cargo target 并挂载 Common Controls v6 sidecar manifest 后，OCCT 集成测试 `native_quick::acceptance_tests::f5_30_measured_socket_head_bolts_build_reopen_and_export` **1/1 通过**：

- 默认垫圈配置得到一个有效闭合实体，包围盒 10×10×13 mm，体积 477.871752 mm³，线程支持报告 `visible_geometry=true`；AIMODEL 重载以及 GLB/STL/OBJ 输出检查通过。
- 显式省略垫圈得到一个有效闭合实体，包围盒 8.5×8.5×13 mm，体积 372.922137 mm³；AIMODEL 重载及网格输出检查通过。
- 由于 socket-head 外螺纹为 facet-BREP 近似、垫圈采用精确回转剖面，本地结果与旧 Python 多边形/光杆结果并非逐面相同。此项只验证本地 Rust/OCCT，不代表 CATIA 已运行或验收。

## 已知差异

旧 Python 的 7 项特征树拆开了每个圆柱和孔；Rust 将每个精确圆环合并为一个 revolve。Rust 最终几何包含两个独立垫圈截面和螺钉主体，但实体由 OCCT 并为一个有效闭合 solid。装配坐标方向和旧 STEP 插入方向不同，当前验收约束以同轴布局、特征参数和包围盒为准。
