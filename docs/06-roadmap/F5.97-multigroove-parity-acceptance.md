# F5.97：多槽带轮 Quick 网格几何 parity 固定回归

## 固定输入与旧端 fixture 来源

固定输入为 `多槽带轮 内径25 基准直径100 宽度30 槽数3`。旧端 fixture 使用旧 Python Quick 公共入口实际生成：

```text
Parser().parse(input) -> ParseResult.doc.build() ->
ai_modeler.core.export.exporters.export_stl(binary=True)
```

在当前 F5.97 worktree 的 legacy Python 基线 `8c40d669377b8004162cc6642e477d786bc22466` 上，以 Python 3.11.9 独立重跑得到 `parser_ok=true`、1 个 feature、同一标准宽度 warning、1536 个 polygon、3072 个 STL triangle、153684 bytes。导出时保留原始 STL 头名称 `legacy quick multi-groove pulley`，生成文件 SHA-256 为 `674607d555816d450f589e182ab61d2ba45b11951403dc7563304c183df8448d`，与 `quick_legacy_multigroove_raw.stl` 完全一致。默认头名称 `Part1` 会产生不同的整文件 hash；三角坐标记录仍由同一 legacy exporter 产生，STL header 也是 fixture provenance 的一部分。

另检查了 TEMP 下同为 153684 bytes 的 STL 文件；它们的 SHA-256 不同且属于 F5.79 记录，不能作为本用例来源。保留的 oracle JSON 记录了固定输入、旧入口、warning、参数、网格数、包围盒及 hash；原始 STL 不经手工合成。

## Rust 回归检查内容

测试从固定二进制 STL 和 JSON oracle 读取旧端数据，并实际调用 Rust Quick `build()` 生成本轮网格。检查包含：

- 解析器输出为 `vbelt_pulley`，参数为基准直径 100、三槽、内孔 25；几何状态必须是 `mesh_only`，且 `brep_available=false`、`catpart_available=false`，实体有效性/实体数保持未知值。
- 校验 fixture 的 SHA-256、3072 facets 与 binary STL 长度；对比三轴包围盒，公差 0.001 mm。
- 对两边网格各取每个三角形的三个顶点和重心，按“旧→Rust”和“Rust→旧”两个方向计算点到三角面的最近距离。每个方向 12288 个样本，最大距离门槛 0.08 mm，同时记录 RMS。
- 在 `y=0.137 mm` 的固定径向/轴向剖面平面切出完整三角网格交线。旧 STL 在该平面产生 96 条截面线段，即 480 个样本；Rust 截面要求至少 81 条线段，即 405 个样本。两侧各对每条线段取端点、四分之一点、中点、四分之三点，计算到另一条截面折线的最近距离，双向最大距离门槛 0.08 mm，同时记录 RMS。这条截面贯穿内孔、轮毂/辐板过渡、轮缘外侧及三条 V 槽的两侧槽壁和槽根。
- 继续核对旧报告中的孔和三个槽根 probe 点；每点距两端网格均不超过 0.08 mm。

测试通过时会打印 bbox 差、双向表面距离 max/RMS、双向截面距离 max/RMS、截面段数及 probe 数，便于留下可复核的比较输出。旧端尺寸为 `105.5 × 105.5 × 46.319713857 mm`。oracle 将根半径记为 41.3 mm，轴向根区间按旧网格实测记录；旧 mesh 自身标记为 raw surface，且说明槽根区间存在自交，不构成闭合实体或 B-Rep 证据。

集成 worktree HEAD `93c325a`（基于当时 main `cf39738`）中的目标测试已通过。构建由 `scripts/test-lib.ps1` 完成，耗时 23.76 秒。首次脚本筛选仅返回 0 tests（`--exact` 需要完整 harness 名），随后通过刚编译出的 test runner 按完整名称执行，没有启动第二个 Cargo 任务：

Rust 输出三角数为 3072，三个包围盒尺寸差均为 0 mm；旧→Rust 与 Rust→旧两个方向各 12288 个表面样本，max/RMS 均为 0；完整截面两侧各 96 段、合计 960 样本，max/RMS 均为 0；孔及槽根四个 probe 均通过 0.08 mm 阈值。旧端 fixture SHA-256 为 `674607d555816d450f589e182ab61d2ba45b11951403dc7563304c183df8448d`，已与旧 Python 实跑输出逐字节匹配。测试的临时 Rust STL 在退出时由 `RemoveOnDrop` 清理，因此**Rust 输出 STL hash 未保留、未采集**；本次结果仅记录了 fixture hash。
