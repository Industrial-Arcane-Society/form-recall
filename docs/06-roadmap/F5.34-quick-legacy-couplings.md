# F5.34：Quick 旧 Python 简化联轴器配方

## 迁移依据

旧 Quick 的解析入口是 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.parse`，联轴器几何配方位于 `src/legacy/ai_modeler/parts/library/partlib.py::_coupling`。实际配方只建立一个居中圆柱主体，并在需要时切中心贯穿孔；它没有建立梅花块、膜片、齿形、键槽或连接螺栓。

旧参数表将 `d` 绑定到“内径/轴孔直径”，`D` 绑定到“外径”，`L` 绑定到“长度/长”。若没有给内孔直径，零件库实际默认 `d=25 mm`；若 `d` 不小于 `D`，旧构造器静默不切孔，留下实心圆柱。旧圆柱使用 48 段，中心孔使用 32 段。

Python 输出、旧解析差异与 Rust 预期记录在 [`quick_legacy_coupling_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_coupling_contract.json)。

## Rust Quick 行为

- `联轴器` 仅迁移为居中 Z 轴圆柱加中心贯穿孔；需要正数外径和长度，内孔必须小于外径。
- 接受明确的 `外径/内径/孔径/长度` 与 `D/d/L` 写法。缺少内孔时沿用 25 mm 历史默认值，来源标成 `derived` 并返回警告。
- 修复 Python 旧参数别名遗漏：输入 `孔径10` 会按明确的 10 mm 内孔建模，并报告 `legacy_coupling_bore_alias_repaired`。
- 缺少主体尺寸、孔径不小于外径时要求补充或修正；不沿用旧构造器静默退化为实心圆柱的结果。
- 梅花、膜片、齿式、爪式等复合联轴器，以及键槽、花键、附加孔槽和边缘加工，返回 `unsupported`。当前不把单圆柱简化模型冒充为完整联轴器。
