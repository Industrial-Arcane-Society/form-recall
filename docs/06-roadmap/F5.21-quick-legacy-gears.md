# F5.21：Quick 旧版直齿轮与中心通孔

## 迁移范围

Rust Quick 现在能解析并建模旧 Python Quick 的直齿轮主体，可选切出中心通孔。实现复用现有 `gear` 原生 OCCT 几何，不改共享齿轮构造器，也不改 CATIA 导出流程。

解析 oracle 是 `src/legacy/ai_modeler/core/parsing/nlparser.py::make_gear()`：

- 未写齿数时默认 20；未写模数但写了齿顶圆/外径时按 `diameter / (teeth + 2)` 推导；两者都没有时模数默认 2。
- 厚度默认 10 mm；中心为 `[0,0,0]`，沿 Z 轴，`base=true`。
- 显式中心孔尺寸生成贯穿中心的 `hole` 切除特征。
- 默认值和推导值写入 CADPlan `sources`，同时返回结构化警告；用户写入的参数标为 `user`。

支持的基础词包括“齿轮、直齿轮、齿坯、gear”。当前只接受全局 Z 轴；齿数限制为原生几何可执行范围 `6..=10000`。缺少齿数、模数、厚度时沿用旧默认值。锥齿轮、伞齿轮、蜗轮/蜗杆、斜齿轮和内齿轮会返回 `unsupported`，不会套用直齿轮几何。齿轮上的倒角、圆角、键槽、螺纹及阵列也不在本项范围内。

## 几何边界

本地 B-Rep 复用了 `core/geometry/kernel.py::profile_gear()` 的八点/齿梯形轮廓并沿 Z 拉伸；这与旧 Quick 一样是可编辑、可量测的多边形近似，不是渐开线齿面。CATIA 文件自动导出和 CATIA 内检查不属于 Quick 此路径，本项没有以 CATIA 结果验收。

外径推导模数后，外径是用于推导的输入证据；CADPlan 的 `gear` 参数本身仍保留旧数据模型字段 `teeth/module/height/center/axis/base`，不增加新的外径参数。
