# F5.102：直齿锥齿轮旧 Quick 与 Rust Quick 表面对拍

## 结论

固定输入 `直齿锥齿轮 模数4 齿数20 齿宽22 节锥角45 中心孔15` 的 Rust native Quick 输出，与旧 Python `Document.build()` raw STL 和旧 `Document.build_brep()` tessellated STL 在本次确定性表面采样下完全重合（最大采样距离约 `10⁻¹² mm`，共同坐标系 bbox 差 `0 mm`，三平面投影 IoU 均为 `1.0`）。三份 STL 均为 4,400 个三角形；Rust 与 BREP 网格各为一个闭合、定向、无边界/非流形边组件。

**F5.102 固定样例表面对拍通过，无需修改实现。** Rust feature/CADPlan 报告 20 齿、中心孔直径 15 mm、节锥角 45°、齿宽 22 mm，最终实体尺寸为 `87.9374736 × 87.9374736 × 22 mm`。导出的端面顶点测量显示 `z=-11 mm` 的外径约 88 mm、孔径 15 mm；`z=+11 mm` 的外径约 39.6 mm、孔径 6.75 mm，大小端截面缩放比均为 `0.45`。模型围绕全局 Z 轴、原点居中；该实现是旧梯形齿配方的近似 facet-BREP，不代表解析渐开线齿面或真实 CATIA 几何。

- 旧 raw STL：4,400 triangles，SHA-256 `1bf4bb51d9bc31559c7b839248f7bf2870d04493a39a2e7714e54dee1947c7de`。旧 BREP tessellated STL：4,400 triangles，SHA-256 `c4bb83871dc34c5eff157aa901a9d20b52548c99599a8ebed3428d3018279806`。

## 三方比较证据

比较脚本 `tools/compare_mesh_surfaces.py`，阈值 `0.08 mm`、weld tolerance `0.00001 mm`，投影分辨率 `64 / 128 / 256`；共世界坐标，无归一化或配准。原始完整 JSON：`%TEMP%\f5.102-special-gear-surface\rust\surface_comparison.json`，SHA-256 `c7b527662f8616396f4800bb845ceca600fd5782fda0606081652880259ef0ae`。

|---|---:|---:|---|---|
| 旧 raw ↔ Rust | `2.56e-12` | `0` | `1 / 1 / 1` | 通过 |
| 旧 BREP mesh ↔ Rust | `1.72e-12` | `0` | `1 / 1 / 1` | 通过 |
| 旧 raw ↔ 旧 BREP mesh | `2.56e-12` | `0` | `1 / 1 / 1` | 通过 |

Rust 与旧 BREP mesh 的拓扑均为 2,200 welded vertices、6,600 edges、0 boundary edges、0 nonmanifold edges、0 orientation conflicts、1 个连通组件，闭合且定向。旧 raw 虽然闭合流形并有 1 个连通组件，但存在 400 条方向冲突边；signed volume 差异因此标记为不可比较，不影响独立表面对拍。Rust/BREP signed volume 均约 `56462.01529 mm³`。比较器报告的距离是每个非退化三角形按面积权重选取 4 个确定性重心采样点，再通过三角面 BVH 查询；**它是表面距离的采样近似，不是连续 Hausdorff 距离上界**。
