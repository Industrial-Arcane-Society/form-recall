# F5.58 — Quick 旧支腿配方迁移

## 旧入口行为

以 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.parse/Parser.handle` 为权威入口，对照 `src/legacy/ai_modeler/parts/library/partlib.py::WELDMENT_PARTS['支腿']`、`_support_leg` 与 `Document.build()` 的实际网格输出。

- 零件库认可“支腿 / 支撑腿 / 立柱”，需要外径 `D` 和高度 `H`；库构造器本身没有外径或高度默认值。
- 默认生成以全局原点为中心的 Z 向圆柱，半径 `D/2`、高度 `H`、48 段。
- `边数 >= 3` 时生成半径 `D/2` 的正多边形棱柱并从 `Z=0` 沿 +Z 拉伸；旧配方用 `int(sides)`，因此小于 3 时退回圆柱。
- 可选“孔径 / 孔直径”生成中心 Z 向贯穿孔，圆孔分段数 32。
- 主入口存在可见的语法分流：`支腿 外径50 长度100` 和 `支腿 D50 H100` 进入部件库，生成 Z 居中圆柱；`支腿 直径50 高100` 由通用圆柱解析，生成从 `Z=0` 起算的圆柱。Rust 保留这两个实际结果。
- 旧部件库忽略 `dh12` 这种紧写参数；Rust 不因此添加孔，并返回明确警告。

## Rust Quick 迁移

- 在通用圆柱解析前识别旧部件库实际接受的 D/H、外径/直径 + 高度/长度写法。
- 圆柱沿用旧居中放置；正多边形沿用旧轮廓点和 `Z=0` 拉伸方向；孔仍是单独的中心 cut 特征。
- CADPlan 的 `prism` 不接受旧参数 `segments`；迁移时将边数编码为 profile 点数，避免把旧专用字段传给通用 schema。
- 中心孔直径达到圆柱直径或多边形对边尺寸时返回待确认，避免声称生成封闭中心孔；侧孔、槽、沉孔、螺纹、阵列等仍明确标为未迁移。
- Rust/OCCT 使用解析圆柱 B-Rep，与旧 48 段网格的包围盒相同，但圆柱及带孔圆柱的体积更接近解析几何真值。六边形截面网格与 B-Rep 体积一致；带孔六边形的 BSP 网格体积与 B-Rep 有约 72.53 mm³ 差异，分别报告，不混为同一指标。
