# F5.24：迁移旧 Quick 叶片与叶盘模板

## 范围

把旧 Python Quick 的独立叶片和叶盘模板接入 Rust Quick。旧入口以 `src/legacy/ai_modeler/core/parsing/nlparser.py::try_template` 为准；几何由旧 `Document.build()` 生成。Rust 侧使用现有 CADPlan `loft`、`pattern` 与 OCCT 执行器，不新增几何特征类型。

本项不覆盖叶片孔槽、倒角、螺纹或其它模板修饰；遇到这些附加要求时明确拒绝整项请求，不静默丢掉修饰。

## 旧 Python Quick oracle

2026-10-06 通过 `nlparser.parse(text).doc` 并调用 `doc.build()`，取得以下参数与旧网格数据；固定输入存于 [`quick_legacy_blade_blisk_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_blade_blisk_contract.json)。

- `叶片`：展长 80 mm、根弦 40 mm、梢弦 20 mm、厚度比 0.12、弯度比 0.05、扭转 18°、后掠 0、8 段、每侧 26 点。旧网格 520 面/936 三角形，包围盒尺寸 40×7.6286769117×80 mm，体积 5,963.540988 mm³。
- `叶片 长100 宽60`：展长 100 mm、根弦 60 mm、梢弦 30 mm，其余参数同上。旧网格包围盒尺寸 60×11.4430153676×100 mm，体积 16,772.459029 mm³。
- `叶盘`：⌀200×30 mm 轮毂、35 mm 叶展、根弦 25.5 mm、梢弦 15 mm、20 片叶片。旧网格包围盒尺寸 250×250×30 mm，体积 947,434.775014 mm³。
- `叶盘 外径200 厚30 叶片数24 叶展40`：⌀200×30 mm 轮毂、40 mm 叶展、24 片叶片。旧网格包围盒尺寸 260×260×30 mm，体积 952,509.264182 mm³。

## Rust 映射

- 叶盘模板先于单片叶片模板匹配，避免 `叶盘 叶片数…` 被错分为独立叶片。
- 独立叶片按旧优先级读取高度、长度、最后一个裸尺寸、默认 80 mm；根弦取尺寸对第一项或宽度，梢弦取尺寸对第二项或根弦一半。旧模板固定的翼型参数均带 `derived` 来源和可见 warning。
- 叶盘依次建立圆柱、单片 loft 和圆周阵列。旧模板默认外径 200 mm、盘厚 30 mm、叶片数 20、叶展 0.35R；根/梢弦分别按 `max(4, 0.85t)` 和 `max(2, 0.5t)` 推导。显式尺寸和叶片数保留用户来源；跨越轮毂半径的叶展按旧规则重置为 0.35R 并发出 warning。
- CADPlan 中的阵列通过唯一 `pattern_source` 关系指向紧邻前一片叶片特征。旧 Python `compound`/`stack` 是 builder 提示，不是当前 CADPlan 允许的参数；Rust 使用 OCCT 实体并集构造完整闭合体。
- 当前 `loft` 为翼型截面三角化并缝合的 facet-BREP 近似；报告和解析结果会明确标为 approximate。CATIA 多截面原生 loft 本项没有验收。

## 几何验收

通过新增的无界面 `ai-modeler-headless-smoke` 输入参数，使用真实桌面 Quick 生产路径执行 parser → CADPlan 校验 → OCCT → GLB/AIMODEL/STL/OBJ → AIMODEL 重载。runtime 使用本机已校验的 OCCT 7.9.3 manifest；AIMODEL 重载由同一 Rust `native_model_io::load_aimodel` 执行。

| `叶片 长100 宽60` | 60×11.4430×100 mm / 16,772.459 mm³ | 60×11.4430×100 mm / 17,136.819 mm³ | +2.1724% | 1 个有效闭合实体；AIMODEL 重载通过 |

```powershell

  "<desktop app resource root>" "<scratch data directory>" "叶盘 外径200 厚30 叶片数24 叶展40"
```

- `cargo check --target-dir target/f5-24-acceptance --lib --tests`：通过，包含新增解析契约测试的编译。
- headless CLI 对 `叶片`、`叶片 长100 宽60`、`叶盘` 和 24 叶片输入：均 `state=complete`、几何 `state=passed`、AIMODEL Rust 重载通过，并生成四种文件。
- Windows `cargo test` 测试宿主曾在启动前以 `0xC0000139 (STATUS_ENTRYPOINT_NOT_FOUND)` 退出，未进入断言；因此不把该命令记作解析单测通过。生产 CLI 的真实构建、CADPlan 校验、闭合体和重载检查已覆盖上述四个 oracle 输入。

## 结果边界与后续差距

本项完成旧 Quick 叶片/叶盘常用模板的参数、默认、特征顺序和本地几何迁移；局部体积仍有小幅 BREP 近似差异，必须向 Quick 用户展示 `approximate` 状态。旧 Python 的其它零件库模板、复杂叶片修饰、GUI 预览和 CATIA 原生特征映射仍需分别对拍，不能据此宣布 F5 全部完成。
