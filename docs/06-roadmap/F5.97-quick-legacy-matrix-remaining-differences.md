# F5.97：旧 Quick 目录矩阵剩余差异复核

## 基线、证据与范围

本报告以当前 `main` 提交 `2641369` 为代码基线，核对 F5.89 保存的 66 项旧 Python/Rust Quick 矩阵快照。快照位于 [`quick_legacy_catalog_audit_after_f5_90.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_catalog_audit_after_f5_90.json)，比较器为 [`compare_quick_legacy_parity.py`](../../tools/compare_quick_legacy_parity.py)。F5.89 报告的早期提交号不是本次静态核对的当前代码基线；矩阵文件本身是一次较后的固定采集结果，本报告没有重采 Rust 结果。

对表中相关输入，本次另用旧 Python 公共入口 `Parser().parse(input)` 实际解析，并对返回文档执行 `doc.build()` 和 `K.polygons_to_triangles()`；旧网格统计仅说明该路径的输出，不证明闭合实体或 CATIA 几何。未运行 Cargo，未改代码、fixture 或已有 roadmap。当前工作区有其他未提交改动，报告只依据已提交矩阵、旧 Python 实跑和 `2641369` 的 Rust 源码。

复跑矩阵比较器得到：66 个输入、60 个成功配对；状态差异 0；特征签名不同 1 行；参数差异 3 行；细分差异 4 行；说明差异 2 行；包围盒差异超过 0.02 mm 的行 0。具体差异行为：同步带轮、法兰、螺母、曲轴、凸轮轴、连杆、多槽带轮、内六角螺钉。旧 Python 的参数与构建实跑结果如下。

## 逐项差异

### 1. 法兰：中心孔网格细分 `48 → 24`

**输入：** `法兰 外径160 内径60 厚度20 分度圆120 孔数6`

旧 `Parser` 成功、无 warning/question，生成圆柱盘体、中心 Ø60 通孔（`segments=48`）和 6 个 PCD120 的 Ø10 贯穿螺栓孔（`segments=24`）。`Document.build()` 返回 1025 个多边形、1842 个三角形，尺寸 `160×160×20 mm`。

Rust 矩阵中对应 3 个特征、孔径/位置/PCD/孔数相同，几何报告为 `passed`、一个闭合实体，包围盒一致；唯一区别是中心孔 `segments=24`。这属于旧网格采样字段差异，不是孔径、孔位或孔深变化。Rust 的圆柱切孔由解析 B-Rep 表示，不能由 `segments` 缺省或减少直接推出设计几何发生变化。

**判断：低风险，无需为兼容盲目把 48 写入设计参数。** 如该字段仍被预览网格读取，应通过同相机轮廓或渲染检查确认旧、新预览采样差异；B-Rep 尺寸与孔几何合同已匹配。

### 2. 螺母：圆柱网格映射为显式八边形棱柱

**输入：** `螺母 螺纹规格12 对边宽度19 厚度10`

旧 `Parser` 成功、无 warning/question。旧 feature 1 是 `cylinder(radius=9.5,height=10,center=[0,0,0],segments=6)`，再切中心 Ø12 通孔；旧网格构建器把圆柱细分下限设为 8，因此外形实际是八边形网格。`Document.build()` 返回 104 个多边形、160 个三角形，尺寸 `19×19×10 mm`，`K.volume_of()` 得 `1428.9352 mm³`。

Rust 把外形表示为 8 点 `prism(profile, height=10, center.z=-5)`，切孔仍是 Ø12、32 段参数。比较器报告结构 `cylinder → prism`，并报告旧 `radius=9.5`、`center=[0,0,0]`、`base=false`、`segments=6` 未按同名字段保留；Rust 显式 profile 顶点和 prism 拉伸起点承载了这些几何信息。Rust warning 明确说明兼容旧 Python `_nut` 的八边形外形与光孔语义，不生成内螺纹。两端包围盒均 `19×19×10 mm`；Rust B-Rep 为一个闭合实体，矩阵体积 `1421.6821 mm³`。

**判断：这是有证据的表示迁移，不是需恢复圆柱的几何回退。** 八点 profile 等价复现旧圆柱网格的最低八边形分段；旧 mesh scalar 与新 B-Rep scalar 不同，不能仅凭约 0.5% 体积差定为形状偏差。保留当前显式轮廓和“光孔、无内螺纹”说明；将来若要增加真实内螺纹，应作为独立功能。

### 3. 曲轴：旧空 `length` 被旧默认公式物化为 `619.2 mm`

**输入：** `曲轴 主轴颈50 连杆颈42 行程86 拐数4`

旧 feature 有 `main_d=50`、`pin_d=42`、`stroke=86`、`throws=4`、`length=null`、`segments=32`。旧 `Document.build()` 仍会调用 `make_crankshaft()` 的长度默认逻辑，实际网格尺寸为 `619.2×128×50 mm`，返回 1074 个多边形、1692 个三角形；旧 mesh scalar 为 `1,248,953.4129 mm³`。

Rust 显式存储 `length=619.2`，来源标记为 derived，并注明旧 Quick 公式 `max(1.8×行程, 2.2×主轴颈直径)×拐数`。本输入代入为 `max(154.8,110)×4=619.2`。Rust 选用 `legacy_quick_dumbbell_cheeks` 变体，几何报告 `passed`、闭合实体数 1，包围盒与旧路径一致。此项把旧构造器的隐式尺寸具体化，不改变实际 Quick 长度。

**判断：参数默认迁移合理且已实现；仍有独立高风险几何验收。** 旧网格 scalar 与 Rust B-Rep 的 `1,757,232.1812 mm³` 差异明显，包围盒一致不能证明曲柄颊、轴颈交接面相同。F5.83 已引入哑铃颊轮廓兼容变体；后续需保存旧 `Document.build()` 网格和 Rust B-Rep，同公差重网格后做侧视/端视投影、截面、拓扑和双向表面距离检查。

### 4. 凸轮轴：旧 `segments=24` 未保留为同名参数

**输入：** `凸轮轴 基圆直径30 升程8 长度320 凸轮数4 轴颈26`

旧 feature 具有 `base_d=30`、`lift=8`、`length=320`、`lobes=4`、`journal_d=26`、`segments=24`。`Document.build()` 返回 602 个多边形、860 个三角形，尺寸 `320×46×46 mm`，旧 mesh scalar `385281.9082 mm³`。

Rust 保留所有尺寸/数量；没有输出同名 `segments`。源码显示旧 `make_camshaft()` 用该值离散主轴颈圆柱，但凸轮轮廓本身固定 48 个采样点；Rust `build_camshaft()` 使用解析 X 轴圆柱和 48 点凸轮棱柱融合为闭合 B-Rep。矩阵状态为 `passed`、一个闭合实体，包围盒相同，Rust B-Rep 体积 `292828.6254 mm³`。

**判断：细分字段省略不自动代表设计参数缺失；旧轴颈网格细分与新解析圆柱是表示差异。** 不建议把 24 作为 B-Rep 几何参数迁回。不过两端旧 mesh 与 B-Rep 体积相差较大，模型表面/凸轮升程不能只凭 bbox 结案；高优先级核对四个凸轮的轮廓、轴向宽度、相位及轴颈交界截面。

### 5. 连杆：`thick=null` 被显式化为旧核默认 `14.4 mm`

**输入：** `连杆 中心距120 大头外径48 大头孔径40 小头外径24 小头孔径18`

旧 feature 将 `thick=null`、`shank_w=19.2`。旧 `make_conrod()` 实际用 `thick=max(2,min(48,24)×0.6)=14.4 mm`、`shank_w=0.8×24=19.2 mm`；`Document.build()` 返回 264 个多边形、524 个三角形，bbox `156×48×14.4 mm`，旧 mesh scalar `72747.5359 mm³`。

Rust 将 `thick=14.4` 和 `shank_w=19.2` 明确写入 CADPlan，来源为 derived，选择 `legacy_quick_rectangular_shank`；矩阵几何报告 `passed`、闭合实体数 1，bbox 一致。新 B-Rep volume 是 `41758.8952 mm³`。旧 mesh 路径把两个环和矩形杆身作为多边形直接拼接，而 Rust 对环和杆身做 OCCT 融合；旧 mesh 体积因此可能累计重叠部分，但目前没有两端表面/截面结果证明具体差值归因。

**判断：厚度默认的物化属于正确兼容；实际外形等价仍未证实，列为最高风险。** 不要把体积差简单归于网格误差，也不要退回 `null`。需比较大小头环的孔/外径、杆身宽厚、外轮廓过渡和融合接触区。

### 6. 内六角螺钉：六点凹槽 profile 保留，`segments=6` 字段省略

**输入：** `内六角螺钉`

旧裸名称零件库解析成功、无 warning/question，生成 Ø10×30 螺杆、Ø16×10 圆头、对边 8×深 5 的六角凹槽。旧 `Document.build()` 返回 195 个多边形、470 个三角形，尺寸 `16×16×40 mm`。比较器唯一差异是第 3 个 prism cut 的 `segments=6` 在 Rust 中省略；旧 feature 的 6 个二维轮廓坐标完整保存到 Rust `profile`，凹槽的截面实际由该 profile 定义。前两个圆柱的 segments32/48 均保留。

Rust warning 说明这只是旧裸名模板，不能代表具体 ISO/GB 规格，并要求有规格时使用规格建模。**判断：prism 的 segments 属冗余元数据，不改变实际切槽几何，不需迁移。** 回归应断言六点轮廓、切深和孔中心，不应将仅有 segments 字段作为成功标准。

### 7. 同步带轮：旧解释数组未保留；其中一项与实际参数矛盾

**输入：** `同步带轮 内径20 节圆直径80 宽度30`

旧 `Parser` 实跑成功并产生 `timing_pulley(pitch_d=80,teeth=49,height=30,tooth_type=XL,bore_d=20,center=(0,0,0))`；其中 49 齿是旧 Quick 的派生值。旧 `Document.build()` 有 1432 个多边形、2276 个三角形，尺寸 `81.14197×81.18368×30 mm`，mesh scalar `151437.6908 mm³`。旧 `explain` 数组被 Rust 有意换成参数来源与结构化 warnings，比较器仅把缺失 `explain` 记为说明差异；几何字段与bbox一致。Rust 几何报告为一个闭合实体，B-Rep 体积 `141363.2377 mm³`。

旧 `explain` 中“未给宽度按常用带宽取 9.5 mm”与本输入明确的宽度 30、实际 `height=30` 相矛盾。**判断：这条解释文本不应原样迁移；Rust 的结构化默认/近似告警更可信。** 不过新旧体积标量差异约 6.65%，而一端为旧 raw mesh、一端为 B-Rep，尚不能据此认定同形或异形；齿形投影、端视轮廓及同公差表面对照仍是未决几何项。

### 8. 多槽带轮：说明数组换成结构化警告；宽度调整已一致

**输入：** `多槽带轮 内径25 基准直径100 宽度30 槽数3`

旧 parser 实跑成功；A 型三槽标准要求轮缘最小宽度约 `46.3197 mm`，所以将输入 30 mm 调整至 `height=46.319713857 mm` 并发出 warning。`Document.build()` 返回 1536 个多边形、3072 个三角形，尺寸 `105.5×105.5×46.319713857 mm`，旧 mesh scalar `584036.1791 mm³`。Rust 使用相同参数与几乎相同尺寸，并把旧 `explain/std_warnings` 映射为结构化 warning；矩阵中报告 `mesh_only`，体积和闭合实体数为 null，并说明只能预览/导出网格，不能生成 CATPart。

**判断：标准最小宽度、警告和 bbox 已迁移一致；说明字段缺失不造成已知参数变化。** 但 mesh-only 是明确的交付能力边界，不能声称本地原生闭合 B-Rep/CATPart 已完成。仍需验证三槽截面、槽距、开口边/端面和标准调整提示；若目标只要求 Quick 预览网格，当前窄兼容可接受。

## 风险排序与下一批验收

矩阵的旧体积是 `Document.build()` 网格统计，Rust 值是 B-Rep 体积；旧网格可能包含未融合相交部件，二者的 scalar 不能单独作几何差异结论。另一方面，包围盒相同也不能证明局部轮廓或孔正确。建议按以下次序创建单独、可复跑的验收记录：

| 优先级 | 固定输入 | 当前风险与所需证据 |
|---|---|---|
| P0 | `连杆 中心距120 大头外径48 大头孔径40 小头外径24 小头孔径18` | 旧mesh未融合构件与新融合B-Rep的体积差大；同时比对大小头孔、外圆、杆身截面和融合区，做拓扑/双向距离/投影。保留14.4 mm与19.2 mm derived 尺寸。 |
| P0 | `曲轴 主轴颈50 连杆颈42 行程86 拐数4` | 已采用旧哑铃颊变体但两端 scalar 差大；对轴颈交替、偏心量、颊板侧视/端视轮廓和横截面做几何对拍，确认闭合实体与构件数。 |
| P1 | `凸轮轴 基圆直径30 升程8 长度320 凸轮数4 轴颈26` | segments24/解析轴圆柱及旧mesh/BRep体积差；核四个凸轮相位与升程轮廓、宽度及轴颈接触截面。 |
| P1 | `同步带轮 内径20 节圆直径80 宽度30` | 参数及bbox一致但mesh/BRep volume差约6.65%；保存两端几何，比较节齿轮廓、端视投影与内孔截面；不迁移矛盾的“宽度9.5”说明。 |
| P1 | `多槽带轮 内径25 基准直径100 宽度30 槽数3` | 已一致地把宽度调到标准下限；验证三槽剖面/槽距与warning，并明确 mesh-only 不可导CATPart 的边界。 |
| P2 | `法兰 外径160 内径60 厚度20 分度圆120 孔数6` | B-Rep设计参数/bbox相同；仅中心孔 segments48→24。若此字段影响预览采样，比较同公差渲染；否则保持B-Rep解析孔，不追逐旧mesh分段。 |
| P2 | `内六角螺钉` 与 `螺母 螺纹规格12 对边宽度19 厚度10` | 检查显式 profile 点数/点序和拉伸位置；segments 删除不应改变截面。螺母明确仍是八边形外形及光孔，不是带内螺纹标准螺母。 |

每个高风险对拍应保留旧 `Document.build()` 网格、新 AIMODEL/B-Rep 与版本、参数和哈希；检查旧网格边界边/连通性，B-Rep 有效/闭合实体数，再对同公差网格计算双向表面距离、关键截面和多视轮廓。Volume、bbox、feature label 或 parser `ok` 单独都不构成“几何相同”的结论。
