# F5.65：迁移旧目录圆柱齿轮名称

## 范围

修复 Python Quick 零件目录中的输入“直齿圆柱齿轮 模数3 齿数24 齿宽20”在 Rust Quick 中被拒绝的问题，并保留旧 `_gear` 配方关于中心面对称拉伸的语义。本项复用现有齿轮特征与 OCCT 建模器，不新增几何类型。

## 根因与实现

Rust 解析器为了拒绝一条输入中混合指定多个基本体，会检查齿轮描述里是否还包含“圆柱”。此前只剔除了“斜齿圆柱齿轮”别名，导致旧目录名“直齿圆柱齿轮”中的“圆柱”被误当成第二个圆柱基本体，因此该样例返回 `parse_failed`。

解析时现在会先移除已知的完整齿轮族名称（“斜齿圆柱齿轮”“直齿圆柱齿轮”“圆柱齿轮”），再执行混合基本体检查。对旧零件库的直齿圆柱齿轮名称，额外沿用 Python `partlib._gear` 的 `base=false`：实体沿 Z 轴关于中心平面对称拉伸；普通“齿轮/直齿轮”仍保留现有 `base=true`。解析计划会附带 `legacy_partlib_gear_centered_extrusion` 警告，说明这个兼容语义。

## 验收结果

旧 Python Quick 对目录输入给出一个齿轮特征：齿数 24、模数 3、齿宽 20 mm、中心 `[0,0,0]`、`base=false`；包围盒为 77.9615117085×77.9615117085×20 mm，旧体积为 78709.34196818568 mm³。

Rust Release headless/OCCT 实际建模结果：

- 状态 `complete`；CADPlan 校验有效；一个有效、闭合的 OCCT 实体。
- 测得包围盒为 77.9615117085×77.9615117085×20 mm，体积为 78709.34196818559 mm³，与旧 Python Quick 体积相差约 9×10⁻¹¹ mm³。
- 参数保留齿数 24、模数 3、齿宽 20 mm、Z 轴及 `base=false`；AIMODEL 写出并重新载入通过。
- OCCT 齿形仍是旧 Quick 使用的离散梯形齿廓近似，不是精确渐开线；本项不声称齿面精度等价，也未执行 CATIA。
