# F5.7 Quick 普通四角孔与边距

## 范围

为 Rust 原生 Quick 普通切除语法增加长方体四角孔。支持 `四角孔`、`四个角`、`各角`、`four corners`、`corner holes` 位置词，以及 `边距`、`距边`、`离边`、`留边`、`内缩`、`edge margin`、`edge distance`、`margin` 边距词。分开的边距短语会附加到前一个孔子句。

本项只生成固定四个孔，不增加 PCD/均布阵列、不改法兰/套筒模板、不验收 Quick→Agent/UI/CATIA 端到端。

## Python legacy oracle

Oracle 是 `src/legacy/ai_modeler/core/parsing/nlparser.py` 的 `parse(text).doc.to_dict()`。执行：

```powershell
$env:PYTHONPATH='src/legacy'
python -c "from ai_modeler.core.parsing.nlparser import parse; print(parse('长方体长100宽80高20，四角孔直径10通孔，边距15').doc.to_dict()['features'])"
```

观察结果写入 `src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_contract.json`：长方体 100×80×20 mm；孔特征 `diameter=10`、`through=true`、`axis=Z`、`pos=corners`、`segments=24`、`margin=15`。不写边距时旧解析器结果为 `margin=0`。

## 原生解释与失败边界

- 显式边距值按 mm/请求中单位换算，作为边到孔圆周的最小距离；几何内核将孔中心偏移设为 `margin + diameter/2`。
- 没有边距时沿用 Python 默认 0 mm，并为默认边距、Z 轴和 24 段参数保存 derived provenance；用户指定值保存 user provenance。
- Rust Quick 要求明确孔径和通孔/盲孔类型；孔径/孔型缺失、负边距、四角与坐标位置冲突会返回 `needs_clarification`，不生成计划。
- 当前只接受长方体上的固定四角孔。非长方体四角孔，以及把四角孔与 PCD/均布/孔数阵列组合，返回 `unsupported`。
- 仅解析参数与几何位置契约；本项未运行 OCCT B-Rep 布尔切除或 CATIA 检查。

## 验收

- Rust Python-golden parity：`native_quick_parser::tests::migrated_legacy_templates_match_python_parser_golden_contract`。
- Rust parser tests：`native_quick_parser::tests`，覆盖解析、来源、零边距、缺失/非法尺寸和不支持组合。
- 几何位置：`native_plan_geometry::tests::four_corner_hole_positions_apply_edge_margin_plus_hole_radius`。盒体边界 `[0,0,0,100,80,20]`、轴 Z、直径 10、边距 15 得到四孔中心 `[20,20]`、`[80,20]`、`[80,60]`、`[20,60]`。
- CADPlan validation：`cad_plan_validation::tests`；margin 接受非负值，与几何默认 0 mm 契约一致。
- 命令：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-lib.ps1 -Filter <filter>`（从 `src/apps/desktop/src-tauri` 运行）及 `git diff --check`。

定向验收不代表完整旧 Quick 兼容、真实 OCCT 切除、UI/Agent 流程、CATIA 或端到端完成。
