fixture [quick_legacy_round_blind_groove_contract.json](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_round_blind_groove_contract.json) 保存旧 Python feature 列表和 `doc.stats()` 几何结果：包围盒 `50×50×40 mm`，离散网格体积 `76749.401025 mm³`。

## Rust 行为

- `圆形凹槽` 不再进入矩形槽 parser；合法窄路径生成 `hole/cut`，以显式 `diameter`、`depth` 建模，`through=false`，默认 `pos=center`、`axis=Z`、`segments=48`。
- `diameter`、`depth` 来源为 `user`；`through`、未指定的 `pos`/`axis`、`segments` 来源为 `derived`，source evidence 保留原始完整输入。输出结构化兼容警告。
- 范围限制为一个完整 box/cylinder 主体加一个凹槽 modifier。缺少直径或深度、重复尺寸冲突、显式要求贯穿、特殊定位、多个 modifier 或复合主体时返回待澄清，不落成矩形槽，也不静默吞掉特征。
- fixture 的 guard cases 标记为 **intentional Rust guard / not parity**：旧 parser 在缺少直径时回退成 `20×20` 矩形槽、缺少深度时默认 5 mm、冲突直径时取首值；旧 Python 也能顺序构建圆形凹槽和另一孔。Rust 当前对这些歧义/复合范围选择显式澄清。这些情况没有计入 parity 通过数。
