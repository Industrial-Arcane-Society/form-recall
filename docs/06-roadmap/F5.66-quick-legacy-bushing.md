# F5.66：迁移旧目录轴套配方

## 范围

迁移 Python Quick 目录样例“轴套 内径25 外径35 长度40”。旧 Python Parser 会从该描述生成轴套外圆和中心贯穿内孔；Rust Quick 此前没有识别“轴套”名称，最终返回 `parse_failed`。本项只覆盖该目录配方，不改变通用套筒/圆管模板的历史孔径解释。

## 根因与实现

Rust 已有通用“套筒/圆管”模板，但解析入口仅将“套筒、圆管、钢管、sleeve、tube”路由到该模板。模板兼容的是另一种 Quick 语法：它对特定标签顺序的内径做二分并使用不同孔分段数。把“轴套”直接并入通用模板会改变原 Python 目录实际生成的孔径，因此本项单独复刻旧 `partlib._bushing` 的特征序列：

1. 中心外圆柱：半径 17.5 mm，高 40 mm，`base=false`，64 段。
2. 中心贯穿孔：直径 25 mm，48 段。

轴套缺少必需尺寸或内径不小于外径时返回澄清；侧孔、槽、倒角、螺纹等未迁移修饰返回明确的 unsupported，不静默吞掉。

## 验收结果

旧 Python Quick Parser 输出一个 cylinder 加一个 hole，包围盒 35×35×40 mm，网格体积 18843.7901762 mm³。Rust Release headless/OCCT 实际结果：

- 状态 `complete`；CADPlan 校验有效；一个有效闭合实体，包围盒 35×35×40 mm。
- 外圆柱和贯穿孔均构建成功；几何报告通过，并通过圆柱内壁和贯穿射线核验。
- AIMODEL 往返通过，两个特征重载成功；AIMODEL、GLB、STL、OBJ 均生成。
- Rust OCCT B-Rep 体积为 18849.5559215 mm³，比旧 Python 三角网格统计值高 5.7657454 mm³（0.03060%）。包围盒和特征尺寸相同；该体积差异来自旧网格统计与 OCCT B-Rep 计算口径不同，本项不声称两个离散网格的三角面逐面相同。
- 未执行 CATIA COM 或桌面 UI 验收。
