# F6.10：修复安装版模型 GLB 预览读取

日期：2026-10-05

## 现象与根因

用户安装版截图显示 Quick 构建已产出 604 个三角面，但视口为空。日志反复出现“读取 GLB 失败：拒绝读取预览目录之外的文件”，状态栏显示“三维预览加载失败”。这说明前端在拿到 GLB 字节之前就被 Rust IPC 拒绝；不是截图所示模型没有生成。

Quick 和 Agent 将模型 GLB 写入 Tauri `app_local_data_dir` 下的会话目录；原 `read_asset` 只允许 `%LOCALAPPDATA%/AI Modeler/ui-preview` 下的图片和预览文件。几何写出路径与 IPC 允许路径不一致，因此有效 GLB 被拒绝，Three.js `GLTFLoader` 没有收到数据。

## 修复

- `read_asset` 现在接收 `AppHandle`，并将路径解析交给独立策略函数。
- 保留现有 `ui-preview` 资源路径和严格的 Windows LocalCache 重定向检查。
- 额外仅允许从 Tauri 应用数据目录读取 `.glb`；请求和根目录 canonicalize 后仍须处于允许根目录内，保留 256 MiB 文件大小限制。
- 当 `ui-preview` 尚未创建时，仍可读取应用数据目录下的 GLB。
- 规范化路径会解析 symlink/junction；指向应用数据根之外的 GLB 被拒绝。应用数据目录中的 `.txt` 和其他根目录中的 `.glb` 也会被拒绝。
