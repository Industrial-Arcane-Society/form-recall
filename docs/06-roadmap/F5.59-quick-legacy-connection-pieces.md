# F5.59 — Quick 旧连接件配方迁移

## 旧入口基准

以 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.parse/Parser.handle` 为入口，核对 `src/legacy/ai_modeler/parts/library/partlib.py::WELDMENT_PARTS['连接件']`、`_joint_piece` 和 `Document.build()` 的实际网格结果。

- 零件库参数需要长度 `L` 和宽度 `W`；显式厚度 `t` 可省略。默认厚度为 `max(5 mm, min(L,W) × 0.12)`。
- 主体是以原点居中的 Z 向矩形块，`base=false`。虽然 `_joint_piece` 的注释写“带台阶”，实际函数只创建一个 box，没有台阶几何。
- 只有孔径 `dh` 存在且 `int(n) >= 2` 时才创建 Z 向 PCD 贯穿孔，孔分段数为 32；未给分度圆时使用 `max(L,W) × 0.6`。旧解析器对孔径/孔数条件不完整时会无提示地省略孔，Rust 结果现在会加警告。
- Python 入口实测可识别完整中文参数名（`长度/宽度/厚度/孔径/孔数/分度圆`）和主体尺寸短码 `L/W/t`。`长100 宽80` 未被旧入口识别；Rust 会提示缺少长度或宽度。
- PCD 孔位超出矩形边界时，旧 Python 仍输出局部边缘切口。Rust 改为待确认，避免将边缘缺口表示成完整通孔。

## Rust 迁移

- 在普通形体兜底解析前增加连接件配方，将主体映射为居中 box，可选孔映射为单个 PCD hole 特征。
- 显式厚度、长度、宽度、孔径和孔数记录为用户来源；默认厚度和默认分度圆记录为推导来源。
- 对缺失/冲突尺寸、无效孔径/孔数、孔阵列越界作结构化澄清。旧解析器省略不完整孔阵列时保留其几何结果并在 warning 说明。
- 对明确的台阶、凸台、槽、侧孔、中心孔、沉孔、倒角、圆角和螺纹请求返回 `unsupported`，避免把这些形状静默压扁成矩形块。旧 `_joint_piece` 不构造台阶；非 PCD 加工尚未迁移。

## 几何对照

旧 Python 网格指标来自 `Parser.parse` → `Document.build()` → `Document.stats()`；Rust 解析器输入/特征契约和预期解析 B-Rep 指标在 `src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_connection_piece_contract.json`。

| 输入 | 旧网格包围盒 (mm) | 旧网格体积 (mm³) | Rust 预期 B-Rep 体积 (mm³) |
|---|---:|---:|---:|
| `连接件 长度100 宽度80` | `100×80×9.6` | `76800` | `76800` |
| `连接件 长度100 宽度80 厚度10` / `连接件 L100 W80 t10` | `100×80×10` | `80000` | `80000` |
| `连接件 长度100 宽度80 厚度10 孔径8 孔数4` | `100×80×10` | `78002.2751` | `77989.3807` |
| `连件 长度100 宽度80 厚度8 孔径8 孔数3 分度圆64` | `100×80×8` | `62801.3651` | `62793.6284` |
| `连接件 长度100 宽度80 厚度10 孔径8 孔数1` | `100×80×10`（旧配方省略孔） | `80000` | `80000` |

圆孔使用旧 32 边网格与 Rust/OCCT 解析圆柱之间存在体积近似差异；包围盒与孔位数量是主要对照项。PCD=90 mm 的旧结果会在 100×80 mm 板的短边产生两个缺边切口；Rust 对相同输入返回 `legacy_connection_piece_holes_out_of_bounds`，不生成不完整候选。

## 验收边界

- `cargo check --manifest-path src/apps/desktop/src-tauri/Cargo.toml --tests` 通过；Python 旧入口 fixture 6/6 对拍通过。
- Release `ai-modeler-headless-smoke.exe` 通过生产 Quick → OCCT → 活动模型路径运行 6 个成功样例：显式/默认厚度、`L/W/t` 短码、4 孔默认 PCD、3 孔显式 PCD 和旧规则省略单孔。全部为一个有效闭合实体，包围盒及 B-Rep 体积符合 fixture 预期；有孔样例的孔测量完成，AIMODEL 重载成功并生成 GLB、STL、OBJ。
