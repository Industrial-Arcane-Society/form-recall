# F5.36：Quick 旧 Python 制动鼓

## 迁移依据

旧 Quick 入口为 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.parse`，零件库配方位于 `src/legacy/ai_modeler/parts/library/partlib.py::_brake_drum`。这个配方不是薄壁鼓壳：它生成居中圆柱、中心贯穿孔和固定五孔阵列。

五孔参数由旧代码推导：孔径 `max(2, (D-d)/4)`，PCD `(D/2+d/2)×0.85`，孔数固定为 5。未给内径但给出外径与高度时，旧零件库会使用典型内径 260 mm；缺少外径或高度时，Parser 不能识别出完整制动鼓。精确输入、旧 Parser 输出、特征参数和网格统计见 [`quick_legacy_brake_drum_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_brake_drum_contract.json)。

旧几何有两个影响结果的情况：

- `D300 d260 H80` 的五孔圆完全落在中心孔空腔内。旧特征树仍包含该五孔，但最终网格与单纯中心开孔圆柱相同。
- `D352 d230 H52` 的五孔与中心孔相交，最终内缘成为相连的开口切除；它们不是五个完整、互相独立的圆柱孔面。

旧 Parser 对“通风”和自定义 PCD 等附加说明会静默忽略。Rust Quick 对这些请求返回 `unsupported`，避免把未实现部分伪装成已完成。

## Rust Quick 行为

- 支持 `制动鼓`、`刹车鼓`，以及外径/直径、内径、高度/宽度/厚度与 `D/d/H` 参数写法。
- 复现 64 段居中圆柱、48 段中心孔、24 段固定五孔及旧默认内径；尺寸来源明确记录为用户输入或旧 Quick 派生默认值。
- 五孔阵列完全落在既有空腔时，OCCT 保留有效实体并把阵列标成 `no_op`。几何执行器此前会因切除体没有减少材料而返回部分构建；本项将同类 PCD 孔阵列纳入已有的无效切除 no-op 处理，并在特征结果中记录该状态。
- 孔阵列切入环壁但与中心孔相交时，保留旧几何；多模态/几何报告不会把这些局部圆柱面声称为五个独立且全部通过测量的孔。
- 无外径/高度、内外径冲突、外缘/相邻五孔相交时请求澄清；通风、摩擦结构和用户指定的孔数、孔径或 PCD 尚未迁移。

## 几何验收

解析合同测试 `native_quick_parser::tests::legacy_brake_drum_recipes_match_python_oracle_and_provenance` 通过，检查 Python 样例、默认值来源、固定孔阵列、澄清边界、旧解析器静默忽略差异、CADPlan schema 与几何 preflight。

OCCT 测试 `native_quick::acceptance_tests::f5_36_legacy_brake_drums_build_measure_reopen_and_export` 通过两组样例：

- `D300/d260/H80`：包围盒 `300×300×80 mm`；PCD 切除记录为 `no_op`；中心孔解析体积为 `1,407,433.508808 mm³`，相对旧网格体积差 `0.216%`。
- `D352/d230/H52`：包围盒 `352×352×52 mm`；PCD 切除与中心孔相交；OCCT 体积 `2,738,587.447139 mm³`，相对旧网格体积差 `0.053%`。孔测量状态仍为未完全验证，因为这些切除与中心孔相连。
