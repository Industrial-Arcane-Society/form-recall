# F4.2.7：连杆原生执行与平移缺陷修复

Rust 构建两个解析环形头部和外公切梯形杆身，融合后要求单个有效闭合实体。必填数值不兜底，拒绝无效孔径、外公切退化及无法连接的孔壁；所有连杆尺寸和中心参与单位转换。工字截面、锻造过渡和倒角未表达，明确标记 approximate，不宣称制造级完整连杆。

## 发现并修复的旧基线缺陷

Python `occ_kernel` 的杆身 profile 已加绝对 XY 中心，随后 `make_prism` 又加一次中心，导致只移动零件位置就改变形体。限定修复为中心局部 profile，补平移不变性回归。

同一尺寸原点中心包围盒为 (-55,-15,-4,49,15,4)，体积 13425.635002984112 mm³。中心移动到 (20,-11,7) 后，修前为两个连通分量、包围盒 (-35,-32.7197,3,80.41625,4,11)、体积约 14482.5934 mm³；修后为单实体，包围盒 (-35,-26,3,69,4,11)，体积 13425.635002984109 mm³，符合纯平移不变量。
