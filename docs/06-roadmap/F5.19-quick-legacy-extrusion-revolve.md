# F5.19：Quick 旧版拉伸、回转与圆柱识别

## 范围

把旧 Python Quick 中 `make_extrude()`、`make_revolve()` 和 `_looks_like_plain_cylinder()` 的窄范围可复现行为迁移到 Rust Quick。输出仍是可编辑 CADPlan 特征，再由原生 OCCT 构建、测量和导出；本项没有修改 Agent 流程，也不覆盖 CATIA 或桌面 UI 的端到端行为。

## Python oracle 与保留行为

Oracle 位于 `src/legacy/ai_modeler/core/parsing/nlparser.py`，9 个固定输入、Python 特征参数、包围盒及解析体积保存在 [`quick_legacy_extrusion_revolve_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_extrusion_revolve_contract.json)。

- 拉伸映射到 `prism`。无草图提示时沿用矩形轮廓 `100×60 mm`、高度 `20 mm`；单独的裸数值 `拉伸 20` 仍作为高度，轮廓保持默认值。明确的长宽高映射为矩形草图和拉伸高度。
- 带“圆形草图”线索时生成旧版 48 点圆形轮廓；无显式高度时沿用 Python 旧规则，直径 20 mm 样例的拉伸高度为 20 mm。带“矩形草图”线索但没有高度时，高度沿用较短的轮廓边长。
- 回转映射到 `revolve`，以矩形母线绕全局 Z 轴旋转。默认半径 `20 mm`、高度 `40 mm`、角度 `360°`；给出半径/直径时，无高度默认 `20 mm`；可指定 0 到 360 度内的回转角。
- “回转底座 直径160 高35”经 `_looks_like_plain_cylinder()` 判作圆柱，保留零件名含“回转”但表达直径和高度时的旧识别分支。未描述轮廓或草图的显式直径加高度也可走隐式圆柱兼容分支。
- 参数来源对用户明确给出的值保留 `user` 证据；默认值及根据裸尺寸生成的轮廓标为 `derived`，并返回兼容 warning。拉伸/回转方向仍是旧规则的全局 Z 轴；旧回转轴固定为 Z，非 Z 请求会要求澄清。

这些是选定输入的行为兼容，不等于完整迁移 Python 的待建草图交互、所有单位/别名或复合特征语法。圆形轮廓仍以 48 边多边形表示，与解析器中的旧 Quick 表示保持一致。
