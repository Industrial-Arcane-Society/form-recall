# F5.46：Quick 旧 Python 连杆

## 迁移依据

旧 Quick 入口为 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.parse`，零件库构造器为 `src/legacy/ai_modeler/parts/library/partlib.py::_conrod`，网格构造器为 `src/legacy/ai_modeler/core/geometry/kernel.py::make_conrod`。中心距 `L`、大头外径 `D`、小头外径 `d` 是本次解析需要用户给出的尺寸。大头孔、小头孔按各自头部外径的 `0.72` 推导；未给杆厚时，几何内核按 `max(2, 0.6×min(D,d))` 推导厚度；未给杆厚时，零件库按 `0.8×d` 推导杆身宽度。显式杆厚同时作为旧杆身宽度。

旧几何把两端孔中心沿 X 轴放在 `±L/2`，大小头为轴线沿 Z 的圆环，中间杆身连接两端。实际顶点包围盒的 X 尺寸是 `L+(D+d)/2`。旧 `conrod_size()` 却返回 `L+(D+d)/4`，在 `L=120, D=48, d=24` 时报告 138 mm，而实际网格长 156 mm；本地验收以实际几何包围盒为准，并记录旧估算器的 18 mm 低估。

旧 Python 对标注为 cm 的数值只剥掉单位、不做换算。Rust 按单位换算为 mm；例如 `中心距12cm` 旧版按 12 mm 解释，Rust 按 120 mm 建模。

## Rust Quick 行为

- 支持“连杆/发动机连杆/connecting rod/conrod”、中文尺寸标签和 `L/D/d/dh/dh2/thick` 简写。中心距、大头外径、小头外径缺失或冲突时返回待澄清，不用典型尺寸静默补齐。
- 大头孔径和小头孔径缺省时分别按 `0.72×D`、`0.72×d` 推导。缺省杆厚按旧几何内核公式推导；缺省杆身宽度按旧零件库公式推导。每项在 warnings 和 CADPlan `sources` 中标记来源。
- 继承旧几何内核的直径、厚度下限和孔径上限。无法通过原生几何预检的参数返回待澄清；单位明确为厘米、分米、米或英寸时转换为 mm。
- 本地 OCCT 以解析回转构造两端圆环，并用外公切梯形杆身融合为单一闭合实体。杆身与旧矩形网格不同，工字截面、锻造过渡、倒角和 CATIA 原生连杆特征未实现，映射仍为近似。
- 附加油孔、槽、螺纹、边缘修饰、阵列或多个连杆返回 `unsupported`。

## 验收

`native_quick_parser::f5_46_legacy_conrod_contract_tests::legacy_conrods_match_python_oracle_defaults_units_and_boundaries` 对拍旧 Python 解析输出、默认值、来源、单位修正、参数冲突和不支持项，并验证 CADPlan 和本地几何预检。

`native_quick::acceptance_tests::f5_46_legacy_conrods_build_measure_reopen_and_export` 通过 OCCT 实际生成闭合连杆，核对包围盒与正体积，检查 AIMODEL 可重载以及 GLB/STL/OBJ 导出。

```powershell
cargo test --lib f5_46_legacy_conrod_contract_tests -- --nocapture

$env:AIMODELER_OCCT_MANIFEST=(Resolve-Path 'target/release/occt-runtime/runtime-manifest.json').Path
cargo test --lib native_quick::acceptance_tests::f5_46_legacy_conrods_build_measure_reopen_and_export -- --ignored --exact --nocapture
```

本项迁移旧 Quick 的参数化连杆主体，不代表它与旧多边形网格的杆身外形、旧错误包围盒估算或 CATIA 几何完全等价。
