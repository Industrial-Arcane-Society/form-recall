# F5.74：迁移旧 Quick 圆形基础体别名

## 范围

旧 Python Quick 接受 `柱体`、`圆钢`、`凸台`、`圆盘`、`盘体`、`球` 等作为基础体名称；Rust Quick 的基础体词表未包含这些输入。本项增加受限归一化：只有单一前置零件名后紧接明确尺寸字段时才改写，再由现有圆柱/球体语法处理尺寸。复合描述、不完整尺寸和更长名称不会被改写。

## Python Quick 对照

七个旧样例均由旧公开解析入口实测成功，并保留旧参数：

| 输入 | 几何体 | 关键参数 | 外包围盒（mm） |
|---|---|---|---:|
| `柱体 直径20高50` | cylinder | R10，H50，48 段 | 20×20×50 |
| `圆钢 直径20长度50` | cylinder | R10，H50，48 段 | 20×20×50 |
| `凸台 直径20高10` | cylinder | R10，H10，48 段 | 20×20×10 |
| `圆盘 直径50厚10` | cylinder | R25，H10，48 段 | 50×50×10 |
| `盘体 直径50厚10` | cylinder | R25，H10，48 段 | 50×50×10 |
| `球 半径10` | sphere | R10，32 段、16 环 | 20×20×20 |
| `锥体 底径20高30` | cylinder | R10，H30，48 段 | 20×20×30 |

`锥体` 这个完整直径+高度短语在旧 Python 中按圆柱快捷路径解析。本次忠实复现旧结果，不将它改成通常语义中的圆锥。此行为仅在窄范围的旧输入别名中保留。

## 几何验收

用 Rust Release `ai-modeler-headless-smoke` 对全部七例运行 OCCT。每例均返回 `complete`，与旧 Parser 的单特征 kind 一致，尺寸与旧 Parser 的网格包围盒在 0.02 mm 容差内一致；几何报告 `passed`，闭合实体数为 1。

旧网格体积与 Rust OCCT B-rep 体积不同：圆柱差约 0.286%，低分段球体差约 1.62%。旧侧使用多边形网格统计，Rust 侧由 OCCT B-rep 计算；本项只确认尺寸、拓扑类别和闭合实体，不将两种体积实现误报为精确相等。

逐字段核对旧 Python 与 Rust 参数时，把旧 Python 的 tuple 坐标转为 JSON 数组，并把旧值 `radius2: null` 视为 CADPlan 中省略的可空字段；除这两项序列化归一化外，七例参数相同。

## 验证边界

- 新增 Python 旧解析快照 fixture 和 Rust Parser 契约测试。
- `cargo check --tests` 用于编译验证；Windows 定向 Rust 测试进程在当前环境有 `0xc0000139 / STATUS_ENTRYPOINT_NOT_FOUND` 启动问题，因此未将单测执行标为通过。
- Rust Release headless/OCCT 七例矩阵通过。
- 未做桌面 UI 或 CATIA COM 验收。

该批只覆盖表中的七个显式尺寸输入。裸名称默认尺寸、只给单一尺寸、填充语句及 `锥形` 的尺寸数量优先级是另外一批旧行为，不在本项范围内。
