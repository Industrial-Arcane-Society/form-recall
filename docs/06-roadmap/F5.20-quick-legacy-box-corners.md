# F5.20：Quick 旧版长方体圆角与倒角

## 范围

迁移旧 Python Quick 长方体轮廓圆角/倒角到 Rust Quick 和原生 OCCT 几何执行器。旧实现不是对完整实体的 12 条棱做通用圆角，而是先修改 XY 平面矩形轮廓，再沿 Z 方向拉伸；Rust 继续以 `box` CADPlan 特征保存参数，由 native builder 生成相同离散轮廓的 OCCT 棱柱。

## Python oracle 与兼容规则

解析 oracle 为 `src/legacy/ai_modeler/core/parsing/nlparser.py::make_box()`；几何 oracle 为 `src/legacy/ai_modeler/core/geometry/kernel.py::profile_rect()` 与 `src/legacy/ai_modeler/core/geometry/occ_kernel.py::make_box()`。4 个固定输入、特征参数、包围盒和 OCP 几何体积保存在 [`quick_legacy_box_corners_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_box_corners_contract.json)。

- 旧 Python 输入 `圆角R5` 生成四个 8 段/象限的离散圆弧，每个圆角共 9 个轮廓点；`倒角C3` 为每个轮廓角生成两个直线端点。Rust 还接受 `fillet R5` / `chamfer 3` 作为额外英文写法；Python 当前对这些英文写法会忽略修饰并给 warning，它们不是本次 oracle 的兼容样例。
- `corner` 半径或倒角边长按旧 Python 算法裁剪到 `max(0, min(corner, min(length/2, width/2) - 1e-6))`。AIMODEL 保留用户输入的原 `corner` 数值；实际几何按裁剪值生成。
- 没有尺寸的圆角/倒角子句沿用旧行为：长方体仍可建成直角体，`corner=0` 并附 warning。圆角与倒角同时出现时返回澄清；目前该修饰只迁入长方体基础形体，其他基础体明确返回 unsupported。
- 长方体始终记录 `center=[0,0,0]`、`base=true`、`axis="Z"` 的旧默认及 `derived` 来源。显式 corner 尺寸按 `user` 来源保存。旧 Python 样例在明确写了 R/C 数值时仍错误地把 `corner` provenance 标成 `default`；Rust 按文本证据将其标为 `user`。

圆角轮廓是 8 段/象限的多边形近似，与旧 Python Quick/OCP 的轮廓表达保持一致；它不是解析曲面或制造级圆角。CATIA 映射和桌面可见 UI 不在本项验收范围内。

## 原生几何改动

`native_plan_geometry` 不再拒绝 `box.corner`。corner 为正时，执行器沿现有右手轴框架构造 2D 离散矩形轮廓，再按 `box.axis` 和 `base/center` 语义执行 OCCT prism；corner 为零仍使用解析长方体。非零 `pocket.corner` 仍明确拒绝，避免把未迁移的槽圆角静默忽略。能力表将长方体圆角/倒角标为离散轮廓近似。

## 验收

Rust parser 专项 `legacy_box_corner_profiles_match_python_contract` 对照 4 个 OCP oracle 输入，校验完整 box 参数、`corner` 来源、CADPlan、缺少 corner 数值的 warning，以及非长方体 corner 拒绝和互斥模式澄清。parser 专项 **25/25** 通过；原生几何专项 **28/28**、CADPlan 校验专项 **10/10** 通过。

忽略测试 `native_quick::tests::f5_20_legacy_box_corner_profiles_build_and_export` 用 OCCT 实建圆角、倒角、超限裁剪和未给 corner 数值 4 个输入。测试检查完成状态、有效闭合实体、包围盒误差 `<=1e-8 mm`、体积误差 `<=1e-4 mm³`、CADPlan 修饰参数、AIMODEL/STL 导出及 AIMODEL 重载；F5.20 **4/4** 通过。Rust OCCT 实测体积与旧 Python OCP oracle 分别一致为 `119560.72257612903`、`38184.0`、`28800.000959999976`、`38399.99999999999 mm³`。

回归：F5.16 独立长方体 **4/4**、F5.17 槽默认值 **5/5**、F5.15 多矩形槽 **1/1** 通过。测试为本地 Rust/OCCT 和文件验收；未运行 CATIA、桌面 UI 或安装版验收。
