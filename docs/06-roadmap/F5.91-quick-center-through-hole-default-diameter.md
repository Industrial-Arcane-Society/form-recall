# F5.91：显式中心贯穿孔恢复旧直径默认值

## 兼容边界

旧 Python Quick 对输入 `长方体100x60x20，然后中心打通孔` 解析为一个中心、Z 轴贯穿孔，缺省直径为 Ø10 mm。Rust Quick 以前对该描述因缺少孔径返回 `hole_diameter_missing`。

本项只恢复“明确中心 + 单个孔 + 明确贯穿 + 未给任何尺寸”的情形。Ø10 的 diameter provenance 标为 `derived`，证据保留原始输入，说明和 warning code 都明确指出这是旧 Python Quick 历史默认值；同时沿用旧普通孔的 Z 轴和 24 段圆周默认，也标为 `derived`。用户给出直径时继续按 `user` 来源绑定。

未标中心、盲孔、深度孔、阵列/多孔、侧孔、坐标孔、含其他 modifier 的描述仍澄清；不会从显式非法或冲突尺寸推导默认值。本项不更改现有孔位、孔轴或其它尺寸的来源绑定规则。

## 验收

parser 契约验证固定描述 ready、CADPlan valid、Ø10、through、center、Z/24 段及 derived provenance/warning；并覆盖未标中心、盲孔、侧向、阵列、带深度等拒绝路径和显式 Ø8 user 来源回归。

OCCT 定向验收确认有效单闭合实体、包围盒 `100×60×20 mm`、单个已验证中心 Ø10 贯穿孔、解析体积 `120000 - π×5²×20 mm³`，并验证 AIMODEL reload 保留 CADPlan 特征及 derived 直径来源。

pwsh -NoProfile -ExecutionPolicy Bypass -File src/apps/desktop/src-tauri/scripts/test-lib.ps1 -Offline -Filter 'native_quick_parser::tests::f5_91_legacy_default_center_hole_builds_verified_aimodel_round_trip' -Exact -Ignored -NoCapture
