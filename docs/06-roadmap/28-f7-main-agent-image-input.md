# F7.G1：主建模 Agent 图片输入

## 修复

删除 stream bridge 对主 provider 请求图片块的无条件过滤。保留按来源映射、预览 generation 判定的旧工具预览清理；用户原图、当前预览和未知来源图片不被静默删除。原图与旧预览 SHA 相同时优先保留用户来源。

工具描述与系统提示明确主 Agent 可以获得原图/ROI及当前单视图图片块。主 Agent 自述不能替代独立观察或复核；知识样例不能当作用户目标原图；文字续话可通过 reference_id 重取原图。

## 已验证

- `node --test src/legacy/tests/test_dsh_stream_bridge.mjs`：7/7，通过 mock provider 实际捕获的请求 body 验证跨轮原图、当前预览、过期预览删除、图片能力错误透明返回。
- Rust 视觉工具描述契约测试：1/1，防止 schema 回退为不返回图片的错误说明。

## 剩余验收

此提交证明桥接层的本地传输行为，不证明真实 provider/模型接收和理解图片。生产配置下的真实请求、原图 SHA 上行证据、单视图返修和续话仍须 F7.G8 实跑。因此 G1 记录为代码完成、真实链路验收待完成。
