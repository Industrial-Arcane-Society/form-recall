# F5.94：带中心通孔的长方体宽高缺省

## 旧 Python Quick 对照

实跑旧 `Parser().parse` 输入 `长方体长100，然后中心通孔直径8`，得到 `ok=true`、无 warnings/questions；生成 box `100×60×20 mm` 和中心 Z 轴 Ø8 通孔（24 段）。Rust 原先因检测到孔 modifier 而关闭长方体缺省，追问缺少宽度和高度。

Rust 现仅对一个长方体主体（显式正长度、宽和高都缺失）加一个独立、明确中心、明确贯穿且有唯一正直径的孔开放 `width=60 mm`、`height=20 mm` 旧默认。长度与孔径保留 `user` 来源；宽高分别标 `derived` 并由 `legacy_box_dimensions_defaulted` warning 列出。该受限路径中的孔轴 Z 与 24 段默认也标 `derived` 并带兼容 warning。其他普通长方体+孔语法仍走已有显式尺寸要求。

未给长度/给非法长度、未明确中心、侧孔、多孔/阵列、盲孔/深度、槽/沉孔/倒角/螺纹等复合 modifier 都不使用这个主体尺寸默认。本项不修改显式孔径或长度的来源绑定。

## 验收

- Parser contract：固定输入 ready 且 CADPlan valid；只补宽/高，保留长度/孔径 user provenance，孔位中心、Z 轴与 24 段默认按 user/derived 正确标注；范围外输入不得生成部分默认计划。
- OCCT 定向验收：一个有效闭合实体、`100×60×20 mm` 包围盒、一个已验证中心 Z 轴 Ø8 贯穿孔、体积等于长方体减圆柱孔的解析值；AIMODEL reload 保留特征参数和来源。
