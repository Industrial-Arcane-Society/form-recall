# F5.60 Quick 旧连接块配方迁移

## 目标与旧入口

本项将旧 Python Quick 中的 `连接块` 搬到 Rust Quick，保持默认尺寸、特征参数和网格结果的语义可追溯，并用生产 Rust → OCCT 路径核验可编辑模型与导出文件。

旧入口及配方来源：

- `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.parse/Parser.handle`
- `src/legacy/ai_modeler/parts/library/partlib.py::WELDMENT_PARTS['连接块']`、`_connect_block()`、`_clamp_cuts()`
- `src/legacy/ai_modeler/core/model/docmodel.py::Document.build/Feature._build_holes`

旧配方用以 mm 为单位的居中长方体作为主体。未给高度时，使用 `max(10, min(L, W) × 0.4)`；参数表中的 `孔径/孔直径` 创建一个 Z 向中心贯穿孔，孔径达到较小平面边长 96% 时钳到该上限。`孔数` 本身不会把中心孔展开为阵列。旧通用尾部还会处理默认孔、盲孔、矩形槽和角部修饰；`台阶` 描述会被忽略。

## Rust 迁移范围

已迁移：

- `连接块 长度80 宽度50 高度30` 与 `L/W/H` 尺寸写法。
- 旧高度公式，缺少尺寸时明确返回待确认项。
- 可选中心贯穿孔，包含旧的 96% 直径钳位和 provenance 说明。
- 没写直径的通孔/中心孔默认 Ø10、24 段；盲孔默认深度 5 mm；显式盲孔深度、矩形槽、圆角和倒角。
- `孔数` 不创建阵列；`台阶/凸台` 仍保持旧配方的直角长方体结果，并通过结构化警告说明。

边界：

- PCD/均布/孔阵列输入明确返回 `unsupported`，不生成少孔或位置错误的候选。本次只迁移单个中心孔；旧通用解析器的 PCD 尾部仍待单独迁移。
- 旧 Python 会将部分“侧孔”“四角孔”“螺纹孔”尾部解析成中心光孔。Rust 延续该旧几何行为并发出螺纹光孔警告；这不是侧向/四角定位孔，也不含真实螺纹。
- 输出是 Rust 本地 OCCT B-Rep；未推送 CATIA，也未声称 CATPart 验收通过。

## 验收记录

旧 Python 基准和 Rust 生产 CLI 的输入、参数、旧网格统计及预期 B-Rep 数据记录在 [quick_legacy_connection_block_contract.json](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_connection_block_contract.json)。覆盖显式/默认高度、L/W/H、中心贯穿孔、过大孔径钳位、单中心孔而非孔阵列、无直径中心孔、矩形槽、忽略的台阶、盲孔、圆角、倒角和仅给孔数。

Release `ai-modeler-headless-smoke.exe` 使用 `src/apps/desktop/src-tauri/target/release/app` 作为 OCCT 资源根实际运行 13 个成功场景。每个场景均为 `complete`、几何 `passed`、一个有效闭合实体；外形尺寸与夹具在 `1e-4 mm` 内、B-Rep 体积与预期在 `1e-3 mm³` 内。孔类特征的 OCCT 孔测量完成，AIMODEL 重载成功，并产生 AIMODEL、GLB、STL、OBJ 文件。PCD 边界输入返回 `parse_failed`、不含特征，因此没有输出错误阵列。

旧网格和 OCCT B-Rep 的圆孔体积略有差异，因为旧网格使用离散圆周，OCCT 使用解析圆柱。例如 Ø10×30 通孔：旧网格体积 `117658.916136 mm³`，新 B-Rep 体积 `117643.805510 mm³`；外形尺寸和孔径测量一致。这属于网格核到解析 B-Rep 的表示变化，不是尺寸估算。

`cargo check --manifest-path src/apps/desktop/src-tauri/Cargo.toml --tests` 通过。F5.60 Rust 单测和原生 OCCT 验收测试均已编译；直接启动 Cargo 的测试可执行文件仍被当前 Windows 环境以 `0xc0000139 (STATUS_ENTRYPOINT_NOT_FOUND)` 拒绝。因而本次运行证据来自 Release 生产 headless CLI；Rust 单测未声称运行通过。未执行 CATIA 验收。
