# F5.81：Quick 法兰螺栓孔旧默认值

## 状态

**旧 Python 默认值已恢复；parser 与 OCCT 几何验收通过。** 该项只调整法兰 Quick 路径中未给出螺栓孔径时的默认值与来源标记。

## 旧 Python Quick 基线

验收输入：

```text
法兰 外径160 内径60 厚度20 分度圆120 孔数6
```

旧公共入口实际先由 `Parser.handle()` 命中法兰零件库配方，再由 `partlib._disc()` 建孔。`model_params` 含 `D=160`、`d=60`、`b=20`、`K=120`、`n=6`，没有 `dh`；`_disc()` 以 `p.get('dh', 10.0)` 得到六个直径 10 mm 的贯穿孔。旧解析与几何入口已对该输入实际重放。

旧 `tpl_flange()` 中另有 `max(6, D*0.08)` 的 fallback；它不是该输入经旧 public Quick 入口实际选择的路径。对外径 160 mm 使用它会错误地产生直径 12.8 mm 的螺栓孔。

## Rust Quick 兼容行为

- 未明确给出螺栓孔径时沿用旧零件库值 ⌀10 mm，来源标记为 `derived`，并返回 `legacy_flange_default_bolt_hole_diameter` 警告。
- 明确给出的螺栓孔径继续优先，并标记为 `user`。
- 只有明确给出至少两个孔数时才创建 PCD 孔阵列；没有孔数时不因法兰名称自动补孔。
- 中心内孔与螺栓孔径分开解析；本输入的中心孔为 ⌀60 mm，螺栓孔为 ⌀10 mm。
