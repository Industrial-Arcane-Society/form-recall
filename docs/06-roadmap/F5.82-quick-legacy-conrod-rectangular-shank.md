# F5.82：Quick 旧连杆矩形杆身兼容

## 范围与旧实现证据

旧 Quick 连杆 recipe 将两个环形端部与一根矩形杆身合并。`partlib._conrod` 的默认杆身宽度为小头外径的 0.8 倍；旧几何内核在未指定杆厚时使用 `max(2, 0.6 * min(big_d, small_d))`。因此 `连杆 L120 D48 d24` 的杆厚为 14.4 mm，旧网格外包围盒为 156×48×14.4 mm。

## 实现契约

CADPlan 可选字段 `geometry_variant` 是受约束的几何能力标记：当前仅 conrod 接受 `legacy_quick_rectangular_shank`。Quick parser 对其旧连杆 recipe 默认写入该标记。构造器据此以中心距为矩形杆身长度、`shank_w` 为宽度、`thick` 为厚度，形成全长矩形杆身。CADPlan / Agent 未提供该字段时保持现有外公切梯形 web；该字段表达的是可选构造变体，不宣称其来源仅限 Quick。
