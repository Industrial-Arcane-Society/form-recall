# F5.41：Quick 旧 Python 盘形凸轮

## 迁移依据

旧 Quick 零件库构造器为 `src/legacy/ai_modeler/parts/library/partlib.py::_cam`，轮廓算法为 `src/legacy/ai_modeler/core/geometry/kernel.py::profile_cam`。构造器生成一个沿 Z 轴拉伸的 72 点极坐标棱柱：升程角固定为 120°，前 72° 简谐上升、接着保持到 120°，其余角度简谐下降；轮廓坐标在拉伸前四舍五入到 0.0001 mm。

Python 真实入口输出、72 个轮廓点、尺寸来源和网格统计保存在 [`quick_legacy_disc_cam_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_disc_cam_contract.json)。完整尺寸样例为“盘形凸轮 基圆直径40 外径56 厚度10”，旧版生成 1 个 `prism`，包围盒为 `47.0411×50.6278×10 mm`，网格体积为 `19158.78553895 mm³`。

## Rust Quick 行为

- 迁移显式“盘形凸轮”名称和旧版短参数 `d/D/b`。外径 `D` 必须明确；旧 Parser 缺外径时会退回普通圆柱或未能识别，Rust 改为要求补充外径，避免把错误圆柱当凸轮。
- 旧 Python Quick 在外径明确时允许使用典型值：基圆直径 `d=40 mm`、厚度 `b=10 mm`。Rust 保留这两个默认值，并在警告和特征来源中标记；没有单位时按 mm 解释。
- 轮廓升程沿用旧 `max(0.5, (D-d)/2)` 公式。小于 1 mm 的外径差会触发旧最小升程，Rust 会警告实际轮廓最大直径将比输入基圆大 1 mm。要求 `D>d`；矛盾时要求修正。
- 本项只生成凸轮主体。孔、槽、键槽、螺纹、倒圆/倒角、阵列和自定义升程角会明确报告 unsupported。旧 Quick 参数表没有把可选 `angle` 暴露给用户，故本项固定复现 120°。
- 这是旧 Quick 的 72 段多边形简化轮廓，不是解析凸轮曲线、滚子从动件、压力角设计或 CATIA 原生凸轮特征。
