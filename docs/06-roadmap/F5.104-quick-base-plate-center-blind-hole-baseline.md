## 旧 Parser 实测

旧入口返回 `ParseResult(ok=true, recognized=2)`，没有 message、warning、question 或 assumption。步骤为：识别基板零件库配方；将“中心盲孔直径12深5”作为同句附加要求递归交给通用 Parser；生成中心 Ø12、深5 mm 盲孔。

完整 Feature JSON 保存在基线报告 `document.features`。摘要如下：

1. `box/add`：长 100、宽 80、高 10 mm；圆角 0；中心 `[0,0,0]`；`base=false`、`axis=Z`。旧 `provenance` 只记录 `length/width/height=explicit`。
2. `hole/cut`：直径 12 mm；`through=false`；`axis=Z`、`pos=center`、`segments=24`、`depth=5 mm`。旧 `provenance` 只记录 `diameter/depth=explicit`；孔的中心和轴向没有 provenance 字段，因此不能把它们表述为有旧端来源标记。

这里的盲孔不是 `_base_plate` 零件配方自带能力，而是旧 Parser 在零件库主体之后把附加孔句交给通用孔规则的组合语义。固定样例只证明这一输入和这一尺寸组合。

## `Document.build()` raw 网格实测

`Document.build()` 成功生成并保存 binary STL。`Document.stats()` 给出 66 个 polygons、128 个 triangles，bbox `[-50,-40,-5,50,40,5] mm`，size `100×80×10 mm`，网格体积标量 `79440.95086257835 mm³`，面积 `19787.95771679696 mm²`。

独立拓扑诊断将三角形顶点按 `1e-5 mm` 量化焊接，发现 104 条边界边、0 条非流形边、0 条绕向冲突边及 16 个通过共享边连接的三角形组件；按该方法，raw mesh **不是闭合网格**。该结果是 raw 三角网格边 incidence 检查，不是 B-Rep 有效性结论。网格体积仅为旧多边形网格统计，不能冒充 B-Rep 体积或有效实体体积。

## 独立 `Document.build_brep()` 实测

这次额外对同一旧 Document 调用独立 OCCT builder。该调用成功并写出 BREP 文件。报告显示：OCCT 7.9.3.1、`brep_valid=true`、1 个 solid、1 个 closed shell、`closed=true`、0 free edges，B-Rep volume `79434.51332235384 mm³`，bbox 与 raw 尺寸相同。孔报告实测为 Z 轴、中心线 `[0,0,0]`、直径 12 mm、深度 5 mm、`through=false`，状态 `verified_blind`。

这里的 B-Rep volume 与上节 `Document.stats()` mesh scalar 来自不同几何/计算路径，应并列记录，不将差值单独解释成旧 raw 的形状偏差。报告的 `visual_validation=not_performed`、`catia_executed=false`；没有做两种表示间的表面/截面对拍，也没有 UI 或 CATIA 验收。

## Rust Quick 迁移与定向验收

`src/apps/desktop/src-tauri/src/native_quick_parser.rs::parse_legacy_base_plate` 现仅增加单孔“中心盲孔”分支。精确提示词产出板体和孔两个 feature：中心 Z 轴，直径 12 mm、`through=false`、`depth=5 mm`、24 段；孔径、深度、孔类型与中心位置标为用户来源，未显式指定的 Z 轴标为 derived。要求深度显式且小于板厚；孔径仍必须显式且小于板的最小平面尺寸。缺直径/深度或深度非正、达到/超过板厚会澄清；额外修改、复数盲孔、前缀/后缀数量（包括“2个”）、孔数/阵列、角孔/坐标/非中心位置、X/Y 轴、底面入口和通孔冲突仍被拒绝，不会退化成通孔或只产出板体。旧 `docmodel.py::_build_holes()` 对 axis=Z 从 `hi-depth` 起刀，因此孔口在 +Z 顶面、盲底在 z=0；“底面入口”不会静默按默认方向建模。对应合同和边界案例位于 `src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_base_plate_contract.json`。

新增 ignored 几何验收 `f5_104_center_blind_base_plate_builds_verified_brep_matching_legacy_oracle`，通过实际 native Quick→OCCT 构建检查一个闭合实体、bbox、孔计量状态、轴向圆柱面跨度和解析 B-Rep 体积。其断言将孔口/盲底几何固定为圆柱面轴向 z=0..5 mm；配合板体顶面 z=5 mm，孔口位于 +Z 面，盲底为 z=0。体积期望来自旧 `Document.build_brep()`，解析值约 `79434.51332235384 mm³`；旧 raw STL 的 `79440.95086257835 mm³` 仍只是非闭合网格统计量，不参与 B-Rep 实体验收。该 Rust 验收依赖 staged OCCT runtime manifest；只有成功运行该 ignored 测试才能称 B-Rep parity 验收通过。CATIA 与 UI 仍未验证。

新增独立 B-Rep 表面对拍：测试可通过环境变量 `AIMODELER_F5_104_RUST_STL_OUT` 固化 native Quick STL；脚本 `artifacts/f5.104-base-plate-center-blind-hole/compare_brep_surface_to_rust.py` 读取已存旧 `.brep`，使用 OCP `BRepCheck_Analyzer` 确认为有效的单实体，以线性偏差 `(0.08 mm, 0.35 rad)` 三角化并写出 oracle STL，再只比较 oracle STL 与 Rust STL。比较调用现有 `tools.compare_mesh_surfaces._compare_pair`，阈值 `0.08 mm`、weld `1e-5 mm`、投影级别 64/128/256。结果见 `brep_surface_comparison.json`：两边各 156 triangles，双向采样各 624 点，RMS 分别约 `3.74e-13 mm` / `3.38e-13 mm`，采样最大约 `7.06e-12 mm`，bbox 最大差 `0`，拓扑均为闭合定向单组件，表面采样比较通过。比较在共享坐标系进行，无网格对齐或归一化。有限采样不是连续 Hausdorff 上界；旧 `Document.build()` 非闭合 raw STL 没有参与该 parity pass 判据。

### 本次实际验证

在 `src/apps/desktop/src-tauri` 顺序运行：

```powershell
$env:CARGO_BUILD_JOBS = '1'
cargo test --lib native_quick_parser::f5_57_legacy_base_plate_contract_tests::legacy_base_plate_inputs_match_parser_contract_and_fallback_boundaries -- --exact --nocapture
$env:AIMODELER_TEST_OCCT_MANIFEST = 'target/debug/occt-runtime/runtime-manifest.json'
$artifact = (Resolve-Path '..\..\..\..\artifacts\f5.104-base-plate-center-blind-hole').Path
$env:AIMODELER_F5_104_RUST_STL_OUT = Join-Path $artifact 'rust_native_quick.stl'
cargo test --lib native_quick_parser::f5_57_legacy_base_plate_contract_tests::f5_104_center_blind_base_plate_builds_verified_brep_matching_legacy_oracle -- --ignored --exact --nocapture
python ..\..\..\..\artifacts\f5.104-base-plate-center-blind-hole\compare_brep_surface_to_rust.py
```

首次 Cargo 启动刚编译的测试 exe 遇到 `0xc0000139 STATUS_ENTRYPOINT_NOT_FOUND`，parser 断言当时未执行。确认 WinSxS 中存在 `Microsoft.Windows.Common-Controls` 6.0 assembly 后，仅在 `target/debug/deps` 为该 exe 临时添加 Common-Controls v6 sidecar manifest；复用该 exe，parser 与 ignored 几何精确过滤最终均实跑成功，各 `1 passed; 0 failed`。manifest 已移除。parser 过滤编译 `ai-modeler-ui` 成功并执行 fixture 中正负例；ignored 几何过滤通过 Cargo 复用同一个 exe，未重编译源码。全部 Cargo 命令设置 `CARGO_BUILD_JOBS=1`。几何断言实测 Rust native Quick B-Rep 体积与旧 oracle `79434.51332235384 mm³` 在 `1e-3 mm³` 内相符，孔圆柱面范围为 z=0..5 mm、状态 `verified_blind`；随后 OCP 与现有表面比较器实跑成功，详情见 JSON。这证明固定案例的 parser/native B-Rep 及其 STL 表面对拍，不代表 CATIA 或桌面 UI 已验证。
