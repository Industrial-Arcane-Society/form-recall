# F5.98：连杆旧 Quick 与 Rust Quick 几何级比较

## 结论

基线为 `2412ebbeb5971decaeb4d8d0de2dbddc2bf33ff8`。固定输入 `连杆 中心距120 大头外径48 大头孔径40 小头外径24 小头孔径18` 分别实际调用旧 Python `Parser().parse → Document.build()` 和 Rust native Quick headless。旧 `Document.build_brep()` 也实际调用，但失败，因此没有旧 BREP 文件或 BREP 表面比较。

结果标记 **not equivalent / 不等价**。旧 raw 网格与 Rust STL 的双向表面采样最大距离为 `4.8 mm`，超过 `0.08 mm`；包围盒最大坐标差只有 `0.00568 mm`，三向投影大致相似，但这些不能覆盖表面距离失败。旧 raw 网格有 128 条绕向冲突边、3 个三角面连通分量；其 signed volume 不能作为有效实体体积。Rust headless 几何报告为有效单闭合实体，但这不证明其与旧 raw 的表面相同。

旧 BREP 失败的直接原因是旧参数显式包含 `thick: None`，而 `occ_kernel._feature_geometry` 使用 `float(p.get("thick", default))`；`dict.get` 会返回现存的 `None`，于是 `float(None)` 抛错。旧 raw builder 自己将 falsy/None 厚度替换为 `14.4 mm`，而 Rust CADPlan 把该默认厚度记录为 derived `14.4 mm`。现有证据无法用旧 BREP 判断融合后外表面是否与 Rust 一致。

## 固定输入、参数与来源

- 原句：`连杆 中心距120 大头外径48 大头孔径40 小头外径24 小头孔径18`
- 单位：长度 `mm`；角度 `deg`（本例无角度参数）。
- 旧 parser：1 条 `conrod` add 特征，`length=120`、`big_d=48`、`big_bore=40`、`small_d=24`、`small_bore=18`、`shank_w=19.2`、`thick=null`、`segments=32`、`center=[0,0,0]`；旧 parser 无 warning/assumption/question。

## 表面、拓扑和体积结果

表面比较在共同毫米世界坐标中运行，不作旋转、平移、缩放或包围盒归一化。每个三角面固定取 4 个面积加权重心样本，通过 AABB BVH 计算精确点到三角形距离；最大值是采样估计，不是连续 Hausdorff 上界。表面阈值 `0.08 mm`，拓扑焊接阈值 `1e-5 mm`。

| 对比/网格 | 三角面 | 包围盒 (mm) | 有向体积 (mm³) | 拓扑/表面结果 |
|---|---:|---|---:|---|
| 旧 raw | 524 | `[-84,-24,-7.2]` 至 `[72,24,7.2]` | `72,747.536` | closed manifold；128 绕向冲突边；3 个连通分量 |
| Rust STL | 748 | `[-84,-23.9943,-7.2]` 至 `[72,23.9943,7.2]` | `41,740.324` | closed、oriented manifold；0 边界/非流形/绕向冲突；1 个分量 |
| 旧 raw ↔ Rust | — | bbox 最大绝对差 `0.005676 mm` | raw 体积不可比较；绕向无效 | 双向采样最大 `4.800 mm`，不通过 `0.08 mm` |

旧 raw→Rust 方向的加权 P95 为 `1.440 mm`、采样最大 `4.800 mm`；Rust→raw 的加权 P95 为 `0.0798 mm`、采样最大 `0.1015 mm`。差异具有方向性：Rust 外表面大多能在 raw 三角面附近找到，但 raw 上的一部分面点不在 Rust 的外表面附近。旧 raw 与 Rust 的 XY 投影 256² IoU 为 `0.9957`，XZ/YZ 均为 `1.0000`；投影相似不能消除双向表面距离失败。

旧 raw 的 `Document.stats()` volume 为 `72,747.536 mm³`，而 Rust几何报告实体体积为 `41,758.895 mm³`；raw STL signed volume 是 `72,747.536 mm³`。由于 raw 有绕向冲突和 3 个分离三角面组件，这组 raw scalar volume 不作为实体差异判据。表面采样是独立失败证据。

## 证据边界与返修建议

旧 raw builder 在 [`kernel.py`](../../src/legacy/ai_modeler/core/geometry/kernel.py) 的 `make_conrod`（约 2073 行）分别生成大头环、小头环和矩形杆身；raw STL 拓扑报告显示这些网格没有焊接为单个连通壳，且存在绕向冲突。Rust 在 [`native_parametric_features.rs`](../../src/apps/desktop/src-tauri/src/native_parametric_features.rs) 的 `build_conrod_with_geometry_variant`（约 422 行）把三部分 fuse 成一个有效实体。由此推断，raw 多出的内部/重叠面可能造成方向性距离尾部；这是对拓扑和距离结果的解释，不是逐面语义归因。

最小后续步骤：不要只修复旧 BREP builder 后就把它当作旧 Quick oracle；它使用外公切梯形杆身，与旧 `Document.build()` 的全长矩形腹板不是同一几何配方。应以旧 raw 的三组件并集作为 Quick 占据区域基准，比较其外部边界与 Rust 融合 BREP，再对 `x=-60/+60 mm` 截面核实孔道。当前 whole-mesh raw 比较不通过；融合后外部表面的严格 parity 仍待这项针对性验证。

## 旧 Quick 组件并集与孔道语义补充

只读核对旧 Quick `make_conrod` 与 Rust `legacy_quick_rectangular_shank` 的构造参数后，4.8 mm 的最大采样差对应旧 raw 网格端环上被腹板覆盖的内部面：旧 raw→Rust 的最大距离来自环壁点 `z=±2.4 mm`，而同处融合实体的最近外边界在 `z=±7.2 mm`。这解释了整个 raw 面集合的最大距离，但不等同于外露轮廓的 4.8 mm 偏差。旧 `Document.build()` 返回的是未布尔融合的三组件面片，因此其全部三角面不应直接当作有效实体的最终外表面。

本例两条 Quick 配方的圆环与矩形腹板名义位置/尺寸对齐（不含旧 raw 的分段面片近似）：大端中心 `x=-60 mm`、外半径 `24 mm`、孔半径 `20 mm`；小端中心 `x=+60 mm`、外半径 `12 mm`、孔半径 `9 mm`；腹板为 `x∈[-60,60]`、`y∈[-9.6,9.6]`、`z∈[-7.2,7.2] mm`。Rust 对三个组件做布尔融合。腹板侵入名义孔盘：小端剩下右半圆形的 Z 向贯通截面；大端剩余孔腔绕过腹板端部连通，近似 C 形。两个名义圆孔都没有保持完整。这是旧 Quick 简化配方的几何语义，不等于符合可制造连杆设计的孔形。

因此原始网格全表面比较仍标记 not equivalent；4.8 mm 不能直接作为融合后外露表面的偏差，也不能据此放宽阈值。孔道截面推导来自源码与固定参数，尚未替代针对融合 BREP 的截面/射线验收。
