# F5.35：Quick 旧 Python 制动盘与 PCD 孔阵列

## 迁移依据

旧入口为 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.parse`，盘体配方位于 `src/legacy/ai_modeler/parts/library/partlib.py::_disc`。制动盘旧配方实际构造为居中圆柱、中心贯穿孔，以及可选的 PCD 贯穿孔阵列；它没有通风槽、浮动盘或摩擦面几何。

旧参数别名包括外径 `D`、厚度 `T`、中心孔 `d`、分度圆 `K`、孔数 `n` 和螺栓孔直径 `dh`。Parser 只会从尺寸描述中提取部分参数；D/T/d 的典型值为 280/22/64 mm，缺少 D 时它通常不能识别成制动盘。已识别制动盘但缺少 T 或 d 时，零件库静默填入 T=22 mm、d=64 mm；PCD 阵列在有 K 和 n 时，缺少 `dh` 会静默使用 ⌀10 mm。

Python Parser 实测结果、网格体积和差异记录在 [`quick_legacy_brake_disc_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_brake_disc_contract.json)。

## Rust Quick 行为

- 支持 `制动盘`、`制动碟`、`刹车盘`、`刹车碟`；需明确外径，厚度缺省 22 mm、中心孔缺省 64 mm，并将默认来源标记为 `derived`。
- 支持中心贯穿孔和 PCD 孔阵列。PCD 与孔数缺一时返回待澄清；PCD 阵列缺少螺栓孔径时保留旧默认 ⌀10 mm 并告警。
- 检查外径、厚度、中心孔、孔数、PCD 与孔径的正数/范围，以及中心孔、盘外缘和相邻螺栓孔间的几何间隙。
- 修复旧 Parser 未读取 `dh` 短写的问题；`D200 T20 d30 K160 n4 dh12` 按 ⌀12 mm 建模并发出 `legacy_brake_disc_dh_alias_repaired`，而旧 Python 默认为 ⌀10 mm。
- 旧 Python 会静默丢弃“孔数但没有 PCD”或“有螺栓孔径但无孔阵列”的输入。Rust 会要求补齐孔阵列数据；复合通风、浮动盘或边缘加工请求明确标为 `unsupported`。

## 几何验收

解析合同测试 `native_quick_parser::tests::legacy_brake_disc_recipes_match_python_oracle_and_provenance` 校验了中英文名称、通用直径别名、显式与默认尺寸来源、PCD 阵列、旧短写差异、澄清边界、CADPlan schema 和几何 preflight。

本地 OCCT 测试 `native_quick::acceptance_tests::f5_35_legacy_brake_discs_build_measure_reopen_and_export` 验收了 4 个旧 Python 样例：盘体包围盒分别为 `200×200×20 mm` 或按旧厚度默认得到 `200×200×22 mm`；每个中心孔及每个 PCD 孔都通过最终 B-Rep 圆柱面测量。AIMODEL 重载后特征树一致，并生成 GLB、STL、OBJ。解析圆盘体积与旧 Python 多边形网格体积差为 0.14%–0.16%。

这项验收证明本地 Rust/OCCT 几何和文件导出；不证明真实 CATIA COM，也不涵盖通风盘、浮动盘、摩擦面或整车制动系统结构。
