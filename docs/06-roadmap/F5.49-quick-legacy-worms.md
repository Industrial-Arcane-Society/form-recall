# F5.49：Quick 旧 Python 蜗杆配方

## 迁移依据

旧 Quick 入口是 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.parse`，零件识别和参数补齐经过 `partlib.find_part` / `partlib.model_params`，几何特征由 `partlib._worm` 生成，旧网格在 `docmodel.Feature.build(kind='worm')` 中构造。

旧配方使用分度圆直径 `d`、齿顶外径 `D` 和长度 `L`，输出 `worm` 单特征：

- 齿线半径 `wire_r=max(0.5, min((D-d)/4, L/6))`；中心线半径 `thread_r=D/2-wire_r`。
- 轴身半径 `min(d/2, thread_r-wire_r)`，高度 `L`，中心 `[0,0,-L/2]`。
- 圈数 `max(2, min(20, L/max(1, 0.8d)))`；螺旋高度 `max(1, L-4wire_r)`，中心 `[0,0,2wire_r-L/2]`。
- 轴身 48 段，螺旋路径每圈 16 段、线截面 8 段，沿 Z 轴正向螺旋。
- 旧零件库给缺失的 `d` 使用典型值 32 mm。D 与 L 不齐时，旧 parser 可能退化成普通圆柱或不生成特征。

冷启动 Python 旧入口实测：

| 输入 | 旧特征关键参数 | 包围盒 | 网格统计 |
|---|---|---|---|
| `蜗杆 分度圆直径40 外径50 长度80` | radius=20、thread_r=22.5、wire_r=2.5、height2=70、turns=2.5 | 50×50×80 mm | 386 面、844 三角形；旧 signed-volume 133951.3345 mm³ |
| `蜗杆 外径50 长度80` | 缺 d 默认 32；radius=16、thread_r=20.5、wire_r=4.5、height2=62、turns=3.125 | 50×50×80 mm | 已固定参数与包围盒，未将旧拼接网格体积当作实体体积 |

旧网格把轴身和螺旋面直接拼接，保留相交的内部面；其体积统计不是可直接对照的有效实体质量。Rust 调用已有 `native_worm`：将采样螺旋缝合为 facet-BREP，再与轴身融合，并要求最终为单一有效闭合实体。外形、参数和可见螺旋位置按旧公式对照；面数与体积允许因几何表达方式不同而改变。CATIA 仍不支持该本地螺旋齿特征。

## Rust Quick 行为与差异

- 迁移 `蜗杆` 的 d/D/L 参数、旧 d=32 mm 默认、中心通孔附加切除、来源标记和旧采样参数。
- 缺外径或长度时返回澄清；旧 Python 在缺 D 的样例中会回退为普通圆柱，Rust 不沿用这个静默错误。
- 显式 cm/dm/in/m 按单位换算为 mm；旧 Python 保留原始数值，例如 4/5/8 cm 会错误生成 4/5/8 mm。Rust 返回差异 warning。
- 左旋、指定螺距/导程/头数、蜗轮及非中心孔等未迁移结构明确拒绝；旧 Python 会忽略部分要求并仍输出固定方向蜗杆。
- 原生 OCCT 构造器要求螺旋与轴身相连、无轴向间隙且完成单实体融合；不满足时以几何校验结果阻止候选。

## 验收

- `quick_legacy_worm_contract.json` 固定 Python 参数、默认、旧网格统计、Rust 单位修正、澄清与拒绝边界。
- `f5_49_legacy_worm_contract_tests` 对拍解析字段、参数来源、预检及几何能力。
- `f5_49_legacy_worms_build_measure_reopen_and_export` 通过真实 OCCT 构建三个样例，核对有效闭合实体、外形、蜗杆支持细节、可选中心孔、AIMODEL 重载及 GLB/STL/OBJ 输出。运行需要设置 `AIMODELER_OCCT_MANIFEST`。

本项只覆盖旧版单根固定公式蜗杆，不表示蜗轮副、左旋或自定义导程、解析螺旋曲面及 CATIA 原生蜗杆特征已迁移。
