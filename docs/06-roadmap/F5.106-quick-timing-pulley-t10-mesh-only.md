# F5.106：T10 同步带轮旧 Quick mesh-only 兼容

## 固定范围

输入：`同步带轮 T10 节圆直径95.493 齿数30 宽度16 内孔10`

旧 Python `Parser.parse()` 接受该输入；`Document.build()` 生成 1,592 个 raw STL 三角面。单独尝试 `Document.build_brep()` 得到的候选是 31 个闭合 shell/solid 的 compound，self-intersection 检查失败，因此不作为 B-Rep oracle，也不能将其称为有效单实体。

Rust Quick 对单个、有效 CADPlan 且旧 T10 网格生成器可构造的 timing pulley 使用 mesh-only 路由，范围由旧 raw 网格生成参数合同决定。源码中 T10 `tooth_height=2.5`，而 native preflight 的固定可用性条件拒绝 `tooth_height*0.55 > 1.0`，故所有 T10 参数均不会进入 B-Rep 路径。新增 `D=200, z=6, w=10, bore=10` fixture 扩展合法参数矩阵；它的 native preflight 仍按上述条件拒绝。Parser 与 mesh-only gate 使用同一个参数可构造判定；超出旧网格范围的 T10 会要求澄清，不会报 `ready` 后被 gate 拒绝。齿数必须为 6..=512，节径/宽度为正，内孔非负且小于有效根径，生成预算不超过 200,000 三角面。多特征/复合请求继续拒绝。MXL、XL、T2.5、T5、3M 仍走原来的 native B-Rep 路径；其他未支持齿型仍被拒绝。T10 的 CADPlan parser 状态为 `ready`，表示该 mesh-only Quick 路由可执行，不代表存在 B-Rep。

Parser 独立保留旧 `partlib._timing_pulley` 齿顶重叠告警：按 `gap_tip=2π×(D/2+0.45×tooth_height)/max(6,z)` 与标准齿顶宽比较；gap 小于 tooth tip 时，在 parser warnings 和 Quick document warnings 写入 `legacy_timing_pulley_tooth_tip_overlap`。该 warning 不改变 mesh-only gate，也不冒充 B-Rep 几何检查。合同 fixture 含正常 D80/z24 不告警与 D95.493/z80 告警两例。

## 旧网格复刻

Rust 网格生成器按旧 `make_timing_pulley` 的顺序复刻：

- 4 点环形盘体轮廓按 Z 轴 64 段回转；每条轮廓边每段扇形三角化为 2 面，共 512 面。
- 30 个六点齿形轮廓逐齿旋转。旧 `make_twisted_prism(..., segments=1)` 将拉伸段数钳制为 2；每齿按旧 `make_loft` 侧面和两端盖三角化为 36 面，共 1,080 面。
- 总数为 1,592 面。输出保持 Quick `mesh_only` 标签：`valid=null`、`solid_count=null`、`closed_solid_count=null`、`brep_available=false`、`catpart_available=false`。mesh-only 的 `stats.volume` 为 null，UI 显示 `—`；`mesh_signed_volume_diagnostic_mm3` 仅作诊断。T10 AIMODEL 带版本化 marker（kind + CADPlan fingerprint，不含绝对网格路径）；“打开工程”导入仅在 marker、fingerprint、单特征 mesh-only CADPlan 与 features 的 kind/op/params/enabled 行均一致时重建同一 legacy mesh，写入 GLB/STL/OBJ/report 并提交 active record。unknown marker、fingerprint/row 不符、多特征或无 marker 的 T10 均 fail-closed；普通未标记工程保持原 OCCT 导入流程。STL、OBJ、GLB 可导出；共享 CATPart guard 在调用 adapter 前拒绝 mesh-only 文档。

## 比较证据

固定旧输入和 Rust 输出分别保存在本目录。Rust STL 由 `native_quick::tests::legacy_t10_quick_raw_mesh_is_mesh_only_and_roundtrips_exports` 实际 Quick 测试通过 `F5_106_RUST_STL` 写出。复跑 surface comparison：

如当前 Windows 测试进程只绑定到系统 Common-Controls 5.82，Rust 测试 exe 会在载入测试前以 `STATUS_ENTRYPOINT_NOT_FOUND` 退出（缺 `TaskDialogIndirect`）。已验证这台机器存在 WinSxS Common-Controls 6.0；在生成的 `target/debug/deps/ai_modeler_ui_lib-*.exe` 旁临时放置声明 `Microsoft.Windows.Common-Controls` v6 的 `.exe.manifest` 后，可复用已编译测试 exe 执行同一过滤测试。该 sidecar 仅在 `target/` 内，测试后移除；不改产品配置或系统环境。

本次结果：两边均 1,592 triangles；weld tolerance `1e-5 mm` 下，两边拓扑记录相同（856 welded vertices、2,388 edges、0 boundary/nonmanifold edges、558 orientation conflicts、31 connected components）。包围盒完全相同：`[-48.8714981,-48.8807755,-8]` 至 `[48.8714981,48.8807755,8]` mm。共比较每侧 6,368 个确定性采样点；双向 sampled RMS 约 `3.7042e-13 mm`，双向 sampled max `7.8166e-12 mm`，三个投影分辨率 `64/128/256` 的 XOR 像素均为 0。

二进制 STL 的逐面记录诊断显示 triangle 数和顺序一致；24/1,592 facets 的顶点坐标有浮点三角函数舍入差，最大 `2.11498e-14 mm`；368 facets 的存储法线不同。由于这些微小值和法线会影响二进制文件哈希，两个 STL SHA-256 不同；面级采样与拓扑比较通过，未用扩大阈值来隐藏差异。有限固定采样是表面近似证据，不是连续 Hausdorff 上界。

报告显式写 `volume_status=not_comparable_raw_mesh`、`volume_comparable_as_oriented_solid=false`；raw 网格签名体积只作诊断，旧 `Document.build()` mesh volume 不是有效实体体积，本次没有 B-Rep 体积 parity 判据。CATIA 和桌面 UI 未验。

参数矩阵另比较 3 组旧 raw STL：24 齿/80 mm 节径/12 mm 宽/8 mm 孔，40 齿/127.324 mm 节径/25 mm 宽/18 mm 孔，以及基准尺寸但中心平移 `[12,-4,7]`。三组三角数、拓扑记录、包围盒相同；二进制面记录最大顶点残差分别为 `1.4803e-16`、`1.4211e-14`、`2.1150e-14 mm`，双向 sampled max 分别为 `8.7523e-12`、`9.3796e-12`、`7.8166e-12 mm`。报告在 `surface_comparison_matrix.json`，包括来源网格 SHA-256。固定采样近似连续表面距离，不是连续 Hausdorff 上界。
