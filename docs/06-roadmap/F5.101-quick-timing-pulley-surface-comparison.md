# F5.101：同步带轮旧 Quick 与 Rust Quick 几何级比较

## 结论

当前 Rust 基线为 `2412ebbeb5971decaeb4d8d0de2dbddc2bf33ff8`。复用旧 oracle 工件（manifest 标记生成基线 `2641369`），并复用 F5.98/F5.99 构建的 Rust headless binary；没有再次运行 Cargo。固定输入 `同步带轮 内径20 节圆直径80 宽度30` 的旧 Python Parser、raw mesh、BREP 均成功，Rust Quick 输出 `complete`、有效单闭合实体。

结论按 oracle 类型分开：**旧有效 BREP → Rust native Quick：pass**，在共同坐标下双向最大采样距离 `0.047331 mm`（阈值 `0.08 mm`），bbox 完全相同，双方 STL 均为一个闭合定向组件；网格 signed-volume 差 `125.466 mm³`，在比较器的面积 allowance 内。**旧 `Document.build()` raw STL → Rust：not equivalent**，最大采样距离 `1.3123 mm`；旧 raw 网格虽无边界边，但有 94 条绕向冲突边、50 个组件，其 signed volume 不能当作融合实体体积。旧 raw 与其 BREP 面之间也存在 `1.3123 mm` 的单向差异，说明 raw path 中包含不属于最终融合边界的额外面/重叠几何。

因此本项只在“经旧 `Document.build_brep()` 生成且验证为闭合实体的 BREP 表面”这一明确路径上通过，不把该结果扩展成旧 raw 三角网格完全一致。旧 BREP 与 Rust 的几何支持仍为近似同步带齿形，不是标准件认证或 CATIA 验收。

## 固定输入、参数与来源

- 原句：`同步带轮 内径20 节圆直径80 宽度30`
- 单位：长度 `mm`；角度 `deg`。
- 旧 parser 输出 1 条 `timing_pulley` add 特征：`pitch_d=80`、`teeth=49`、`height=30`、`tooth_type=XL`、`bore_d=20`、`center=[0,0,0]`。parser warning 是缺少 `t`，按零件库典型值代入；无 questions。旧 `explain` 记录 XL 节距 `5.08 mm`、齿高 `1.27 mm`、齿顶宽 `2.57 mm`、齿根宽 `2.51 mm`。
- 注意输入中的 `宽度30` 实际绑定到旧/Rust 参数 `height=30 mm`（Z 向轴向厚度）；不是单独的 `width` 字段。旧解释文本另含“未给宽度时按 9.5 mm”说明，与本例实际解析出的 `height=30` 并不完全一致。本报告以 ParseResult 实际参数和输出 bbox 为准，不把解释文案当作测量。
- Rust CADPlan 将 `pitch_d=80`、`height=30`、`bore_d=20` 标 `user`；`teeth=49` 按 `round(D×π/p)`、`tooth_type=XL` 为历史默认、`center=[0,0,0]` 标 `derived`。effective 几何为 49 个 XL 梯形齿、中心孔半径 10 mm、整体沿 Z 轴厚 30 mm。

## 表面、拓扑与体积结果

比较使用共同毫米世界坐标，不进行归一化或配准。每个三角面取 4 个固定面积加权重心采样点，使用 AABB BVH 计算点到三角面的距离。表面阈值 `0.08 mm`，拓扑焊接容差 `1e-5 mm`；投影使用共同包围框，平面 XY/XZ/YZ，分辨率 64²、128²、256²。固定采样最大值是估计值，不是连续 Hausdorff 上界。

| 路径/比较 | 三角面 | bbox (mm) | 网格 signed volume (mm³) | 拓扑/表面结果 |
|---|---:|---|---:|---|
| 旧 raw | 2,276 | `[-40.57047,-40.59184,-15]` 至 `[40.57150,40.59184,15]` | `151,437.689` | 0 边界边；94 绕向冲突边；50 个组件；非 closed-oriented |
| 旧 BREP→0.08 STL | 4,296 | 同上 | `141,282.482` | 0 边界/非流形/绕向冲突；1 个闭合定向组件 |
| Rust STL | 2,508 | 同上 | `141,407.948` | 0 边界/非流形/绕向冲突；1 个闭合定向组件 |
| 旧 raw ↔ Rust | — | bbox 最大差 `0` | raw 的绕向和多组件使体积不可比较 | raw→Rust 最大 `1.3123 mm`；Rust→raw 最大 `0.04680 mm`，不通过 |
| 旧 BREP→Rust | — | bbox 最大差 `0` | signed-volume 差 `125.466 mm³`，在 allowance 内 | 双向最大 `0.047331 mm`，通过 `0.08 mm` |
| 旧 raw→旧 BREP | — | bbox 最大差 `0` | raw volume 不作为实体体积 | raw→BREP 最大 `1.3123 mm`；BREP→raw 最大约 `0.000003 mm` |

旧 BREP→Rust 的加权 P95 为 `0.03986 / 0.04040 mm`（旧→Rust / Rust→旧）。256² 投影 IoU 为 XY=`0.99888`、XZ=`1.00000`、YZ=`1.00000`。旧 BREP 几何报告实体体积 `141,282.482 mm³`；Rust headless 几何报告 `141,363.238 mm³`，差 `80.755 mm³`（约 `0.057%`）；Rust STL signed volume `141,407.948 mm³` 与 BREP report 值的差 `125.466 mm³`，也低于比较器的 volume allowance `1,765.809 mm³`。

旧 raw `Document.stats()` 体积为 `151,437.691 mm³`，且 raw 三角网格有 94 条绕向冲突边/50 个组件；比较器将 raw volume 标为不可比较。旧 raw 与最终 BREP 的单向采样差异显示，raw 多面片并不能视作闭合融合实体的边界。此体积差不会推翻 BREP→Rust 的独立表面通过结果。

## 源码对应与边界

- 旧同步带轮三角面配方在 [`kernel.py`](../../src/legacy/ai_modeler/core/geometry/kernel.py) 的 `make_timing_pulley`（约 1168 行）：回转盘体加 49 个沿 Z 拉伸并环形布置的齿柱。旧 BREP 是这些 facet 形状融合后的闭合实体。
- Rust [`native_timing_pulley.rs`](../../src/apps/desktop/src-tauri/src/native_timing_pulley.rs) 的 `build` 路径生成相同齿数/标准梯形齿，使用解析回转 annular blank 并 fuse。其输出明确警告：盘体从旧分段 facet-BREP 换为连续回转，因此体积会有限变化。
- pass 只覆盖保存的旧 BREP 与本次 Rust native Quick STL 的固定采样比较。旧 raw 网格不满足同一表面判定；CATIA、视觉、传动功能和标准件制造精度均未验证。
