# F5.53：Rust Quick 迁移旧 Python 气门配方

## 旧入口对照

本项对照 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.handle`、`partlib.build_features_ex()` 与 `src/legacy/ai_modeler/parts/library/partlib.py::_valve`，并在当前 Python 环境直接运行旧入口。

| 输入 | 旧 Quick 实际行为 |
|---|---|
| `气门 杆径8 盘径34 总长105` | 识别成两根同轴、同中心的圆柱：杆半径4、高105、32分段；阀头半径17、高12.6、48分段。旧网格外形34×34×105 mm、198面、484三角形、体积16021.898346 mm³。 |
| `气门 盘径34 总长105` | 仅杆径缺失时会从典型值默认 d=8 mm，并留下提示；其他尺寸仍必须给出。 |
| `气门` | 旧 `model_params` 只填 d=8，之后 `_valve` 因缺 D 抛 `KeyError`，外层解析未建模。 |
| `气门 杆径8 总长105` / `气门 杆径8 盘径34` | 分别因缺 D / L 而未建模。尽管 `TYPICAL` 表包含这些值，旧入口没有将其实际补进特征。 |
| `发动机气门 杆部直径0.8cm 头部直径3.4cm 长度10.5cm` | 旧 Python 忽略长度单位，生成0.8、3.4、10.5 mm 尺寸。 |

旧配方把短阀头圆柱放在杆的中点，实际结果是头部圆盘与长杆在中部重叠。Rust 保留该行为，因为这是旧 Quick 的实际几何；不擅自把头部移到杆端。

## Rust Quick 行为

- 新增“气门 / 发动机气门”解析，生成两个 `cylinder` add 特征，均以原点为中点、沿 Z 轴；二者按旧配方做布尔并集。
- D（阀头直径）和 L（总长）仍要求用户明确给出；缺少时返回 `needs_clarification`。只有杆径 d 缺少时沿用旧实际默认 d=8 mm，并标为 `derived`、附带警告。
- 阀头圆柱高度按旧公式 `max(1 mm, 0.12×L)` 推导；杆与阀头圆周分段分别保留 32 和 48。
- 显式 cm 等单位会换算为 mm，提示旧 Python Quick 的单位错误已修正。
- 阀座、锥面密封、弹簧、孔槽、螺纹和边缘修饰显式返回未迁移状态；不会悄悄忽略这些请求。

## 验收

- `src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_valve_contract.json` 固定旧解析边界、两圆柱参数、杆径缺省、单位差异、来源和未迁移项。
- `f5_53_legacy_valve_contract_tests` 覆盖解析、来源、CADPlan 和 Quick 几何预检；`f5_53_legacy_valves_build_measure_reopen_and_export` 覆盖 OCCT 有效闭合实体、包围盒、AIMODEL 重载与 GLB/STL/OBJ 文件。
- `cargo check --tests` 通过。
- 使用生产 `ai-modeler-headless-smoke.exe` 实际构建并 AIMODEL 重载：显式参数、旧杆径默认、cm 修正、短总长边界四种情况均为有效单闭合实体。前三种外形34×34×105 mm、B-Rep 体积16084.326068 mm³；短总长外形34×34×5 mm，阀头高度按公式下限取1 mm。
- Rust 本地内核使用解析圆柱 B-Rep；旧 Quick 使用 32/48 边圆柱网格做 BSP 合并。两者外形包围盒和两段布置一致，体积分别是连续 B-Rep 测量值与旧面片近似值，不能把这两个数当成同一离散表示下的体积误差指标。
- 生产入口还确认 D/L 缺失分别返回 `legacy_valve_head_d_required` / `legacy_valve_length_required`。若提及气门弹簧则返回 `legacy_valve_modifier_not_migrated`。
- CATIA 未执行；此项只验证本地 Quick/OCCT 路径。

本项迁移的是旧气门两圆柱简化配方，不是工程意义上的完整发动机气门；阀座、端部锥面、气门杆槽、弹簧和发动机装配关系仍不在已支持范围内。
