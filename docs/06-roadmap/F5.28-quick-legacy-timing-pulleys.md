# F5.28：Quick 旧版同步带轮配方迁移

更新时间：2026-10-07

## 范围

将旧 Python Quick 的单件 `timing_pulley/add` 路径接入 Rust Quick，并复用已有的原生 OCCT 几何构造器。支持 Rust 原生预检通过的 XL、MXL、T2.5、T5、3M 齿型。其余旧版齿型、V 带轮和主体上的附加孔槽/修饰明确返回 unsupported，不会被误解析成可执行模型。

该迁移只覆盖同步带轮主体，不包含配对同步带、键槽、螺栓孔、法兰或 CATIA 特征映射。

## Python Quick 基准

使用真实入口 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.parse()` 对拍：

- `同步带轮 XL型 节圆直径48.5104 齿数30 宽度10 内径12`：旧 parser 返回一个 `timing_pulley/add`，参数为 `pitch_d=48.5104`、`teeth=30`、`height=10`、`tooth_type=XL`、`bore_d=12`、`center=[0,0,0]`；无默认 warning。
- `同步轮 T5 节圆直径50 齿数30 宽度12 内径10`：同样返回一个特征，参数为 `50/30/12/T5/10`，无默认 warning。
- `同步带轮 外径80 齿数20 宽度10 内孔8`：旧 parser 将未指定齿型回退到 XL，并返回 warning。
- 单独输入 `同步带轮`：旧 parser 的实际结果为 `pitch_d=80`、`teeth=49`、`height=30`、`tooth_type=XL`、`bore_d=20`、原点中心，并提示 `t/d/B` 使用典型值。Rust 继续提供这些旧默认值，但逐字段标记为 `derived`。
- 旧版可以把同步带轮和附加孔一起解析，但示例 `中心打直径6通孔` 实际生成的孔直径是 10 mm，而不是输入的 6 mm。Rust 不复刻该错误；含额外孔槽或修饰时明确拒绝复合请求。
- `V带轮 基准直径100 槽数3 槽型A 内孔25 宽度50` 在旧 parser 中是独立的 `vbelt_pulley`，不会归到 `timing_pulley`。V 带轮仍未迁移。

具体旧版参数、来源类型、默认值、支持边界和失败样例固定在 [`quick_legacy_timing_pulley_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_timing_pulley_contract.json)。

## Rust 解析和几何边界

- Rust Quick 按旧版默认值恢复节圆直径 80 mm、XL 型、轮宽 30 mm 和内孔 20 mm；每个默认值在 CADPlan 的 `sources` 中标为 `derived` 并附说明。缺齿数时沿用旧公式 `round(D × 3.14159 / 齿距)`，至少 10 齿。
- 显式未知齿型、冲突的齿型/尺寸、非法齿数以及原生几何预检失败均不能返回 ready。
- 目前 Rust 原生构造仅接受 MXL、XL、T2.5、T5、3M。其他旧 Python 标准齿型尚未迁移，V 带轮也不属于本项范围。
- 旧 parser 的 `explain` 是解释性文字，不作为 CADPlan 几何参数搬运。几何和参数来源仍由可验证的尺寸字段表达。
- `native_timing_pulley` 使用解析环形盘体与梯形齿柱融合。它不是精确皮带齿形曲面；本地结果保持 `approximate` 状态，尺寸和体积会与旧分段 facet-BREP 有限差异。
