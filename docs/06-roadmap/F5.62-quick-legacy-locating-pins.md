# F5.62 Quick 旧定位销配方迁移

## 范围

将旧 Python Quick 公共解析入口的定位销行为迁移到 Rust Quick。迁移范围依据 `Parser.parse` 的实际输出，不按零件库中未被公共入口采用的通用 `_locating_pin` 公式推测。

旧入口与数据来源：

- `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.parse/Parser.handle`
- `src/legacy/ai_modeler/parts/measured/realparts.py::build_locator_pin_real`
- `src/legacy/ai_modeler/parts/measured/realholes.py` 的轴向归一化
- `src/legacy/ai_modeler/core/model/docmodel.py::Document.stats`
- 实测 KMS-M01 型号的原始圆柱分段由旧公共解析器输出采集，随 Rust 代码保存在 `native_quick_locator_pin_catalog.json`。

## 旧解析行为

- 裸输入“定位销”实际生成两段同轴圆柱：上段 Ø22 mm、下段 Ø10 mm；默认总长 60 mm，均分为 30 mm + 30 mm。
- 输入总长会按一半切分两段。例如“定位销 直径10 长40”仍生成 Ø22/Ø10 两段，各长 20 mm。旧公共入口解析到销径后没有把它传给构造器，所以输入的直径不改变结果。
- 台阶直径 `D` 和台阶高度 `h` 同样不会改变这个回退形状。Rust 结果通过警告说明被忽略的输入，避免把它们误认为生效参数。
- 单独的短型号“P097-A20”并不匹配旧公共入口的实测目录，仍走 Ø22/Ø10、60 mm 回退。只有完整 `KMS-M01-...` 目录型号进入实测分段。
- 完整目录包括 22 个型号、87 条旧圆柱分段记录。Rust 保留各段直径、归一化 Z 区间和旧特征名称；型号目录尺寸优先，附加文字尺寸按旧行为忽略并发出警告。

## 单闭合实体兼容处理

旧目录的相邻实测圆柱区间有轴向间隙。直接按这些区间创建实体，会留下彼此分离的圆柱，不能满足当前 Quick 单一闭合 B-Rep 的建模约束。Rust 在每处间隙内增加一个同轴连接芯，并让连接芯与两端略微重叠。连接芯半径取相邻台阶中较小者的一半以内，因此不会超出实测外形包络；结果会以 `legacy_locator_pin_native_gap_bridge` 警告标记。

这项拓扑修正保留包围盒和外部轮廓，但不是旧目录中存在的真实特征，内部体积会有小幅增加。不能将连接芯表述为原件的已知内部结构。

## 旧 Python 基准与 Rust 命令行验收

旧公共解析结果与网格基准保存在 `src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_locator_pin_contract.json`。Rust Quick 通过正式 headless 命令行和随包 OCCT runtime 对 26 个输入进行建模：4 个回退样例以及 22 个完整 KMS-M01 型号。

- 26/26 返回 `complete`，生成 AIMODEL、GLB、STL、OBJ；AIMODEL 可重新载入。
- 所有结果为一个有效闭合实体，外形包围盒与旧 Python 网格基准一致。
- 回退样例体积相对旧网格约增加 0.286%，来自旧 Python 多边形网格和 OCCT 解析圆柱的表示差异。
- 22 个完整型号的体积差异最大为 0.722%，包含连接芯增加的内部体积；所有样例均低于 fixture 中的 2% 验收阈值。
- 旧实测目录原始特征数为 3 或 4；具有断口的结果会多一个内部连接芯，故 Rust 特征数不总是等于旧目录特征数。

此项只验证本地 Rust/OCCT Quick 建模和文件往返，未运行 CATIA COM，也不代表所有 Quick 配方迁移完成。

## 预览截图问题的关联边界
