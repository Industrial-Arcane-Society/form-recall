旧 Python 的 `provenance` 对部分显式直径映射标为 `radius: explicit`，但 CADPlan 的 `radius` 是由直径换算出的值；Rust 结果应保留输入直径作为证据，并将派生的 radius 与缺失尺寸默认值标为 `derived`。锥体顶端 `radius2=0` 是锥体定义产生的派生值。单位、中心、轴向、`base=true` 和圆周分段数也沿用旧默认值，须标 derived，不能冒充用户输入。

## 边界与兼容陷阱

- 复合输入 `底板上做一个圆凸台直径20` 和 `底板上做一个凸台直径20` 不改写。旧 Python 本身只产出一个 `20×60×20` 的长方体，没有建出凸台；本模块不能因看到前置名就再插入圆柱。
- 顶层独立输入 `凸台` 和 `凸台直径20` 在旧 Python Quick 中实际分别生成默认圆柱 `R25×H50` 与 `R10×H50`，因此 helper 将顶层词位的 `凸台` 作为基础体别名；“请帮我做一个”前缀也会保留并通过该规则。
- 复合输入 `底板上做一个凸台直径20` 则由旧 Python 只生成一个 `20×60×20 mm` 的长方体，没有生成凸台。helper 仍拒绝在完整输入中间改写“凸台”，以保留旧路由，不将二级特征误建成独立圆柱。
- `圆钢管直径20` 走旧圆管模板，得到 H80 圆柱管体和 Ø12 中心孔；不能匹配成实心圆钢。
- 完整尺寸 `圆钢直径20高30` 留给完整圆形别名流程。
- 圆锥存在历史优先级陷阱：当输入同时有直径/半径与高度时，旧 `_looks_like_plain_cylinder` 快捷路径先执行。例如 `锥体底径20高30` 旧输出是 `radius2=null` 的普通圆柱；裸 `锥体` 则是 `radius2=0` 的尖锥；`锥形直径20` 又按最后一个裸尺寸把 H 设为 20。单尺寸规范文本不能补上合成高度，否则会把尖锥误路由成圆柱。
- 畸形 `圆钢直径` 在旧 Python 中会静默回退到 R25、H50。本模块拒绝这个不完整尺寸标签，避免把损坏输入伪装成有效默认值。
