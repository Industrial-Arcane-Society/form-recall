# F5.23 Quick 四角沉孔

日期：2026-10-06

状态：已实现并通过本地 OCCT 验收；不代表 CATIA 验收。

## 范围

Rust Quick 现在接受同一子句中的四角通孔加沉孔，也接受先描述四角通孔、再用后续子句描述沉孔。缺少先导孔、沉孔深度不明确、沉孔直径不大于先导孔，以及边距冲突时会请求补充或澄清。

Python Quick 解析输出保存在 [`quick_corner_counterbore_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_corner_counterbore_contract.json)。夹具同时记录 Rust 的预期特征参数，避免把旧参数误当成正确的孔心位置。

## 几何规则与兼容差异

旧 Python 解析器为不同直径的四角孔重复使用同一个边距。几何内核按“边距 + 半径”定位孔心，因此先导孔与沉孔会偏心：直径 6 mm 和 12 mm 同边距时，各方向中心线偏移 3 mm；先导孔边距 10 mm、沉孔边距默认为 0 mm 时，各方向偏移 7 mm。

Rust 将输入边距解释为沉孔外缘到零件边的间隙，并为保持同心推导先导孔边距：

```text
先导孔边距 = 沉孔边距 + (沉孔直径 - 先导孔直径) / 2
```

例如直径 6/12 mm、沉孔边距 10 mm 时，先导孔边距为 13 mm。未提供边距时，旧 Quick 默认值 0 mm 作为沉孔外缘间隙；先导孔按直径差推导。Rust 会返回说明警告，因此这里是**接受旧输入语法并修正几何位置**，不是逐字段复刻旧 Python 的偏心参数。

零边距孔会与零件边相切。B-Rep 外侧射线核验现在跳过本来就没有材料的采样点，同时要求至少一半的外侧采样点有材料，并要求所有有材料的点都保持未切除；这避免把合法的边界相切孔误报为失败，也仍能发现外侧过切。
