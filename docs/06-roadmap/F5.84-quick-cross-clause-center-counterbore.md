# F5.84 Quick 分句中心沉孔兼容

## 范围

仅补齐旧 Python Quick 已成功处理的顺序语法：`长方体长100宽80高20，中心通孔直径6，然后加直径11沉孔深5`。先前特征必须是紧邻的、明确写出中心位置的贯穿孔；沉孔必须显式给出大于先导孔的直径和正深度。沉孔省略位置时，才继承先导孔中心；省略轴向时继承先导孔轴向（旧路径未指定轴时为 Z）。重复写出“中心”与继承等价。

不得从当前任务之外继承孔位置；不得推断缺失直径或沉孔深度；显式坐标、四角、PCD/阵列、边距、偏心或表面位置冲突均拒绝；新旧轴向不一致则要求澄清。裸尺寸、其它沉孔类型、阵列缺省值均不属于 F5.84。

## 根因与实现位置

当前 `native_quick_parser.rs` 的沉孔分派位于 `parse()` 的 `if is_hole { if clause.contains("沉孔") { ... } }` 分支。中心沉孔分派依赖当前子句含“中心孔/中心通孔”，而多子句保护条件 `(!corner_counterbore && modifier_clauses.len() != 1)` 直接拒绝第二个中心沉孔子句。独立的 `build_center_counterbore()` 还要求同一子句恰好一个“带”分隔符，因此不能消费前一轮已经建立的中心贯穿孔。

实现仅在当前第二孔特征与上一特征相邻时检查显式 `sources.pos.type == user`、`pos == center`、`through == true`。新 helper 只生成沉孔自身，不重复创建先导孔。它将位置/轴来源记为 `derived`，除非用户在沉孔子句显式重复中心或匹配轴向；沉孔直径和深度来源仍是 `user`。冲突位置被拒绝，冲突轴向产生澄清项。新的 parser fixture 和 ignored OCCT 几何测试相互独立于现有 F5.12 五项 fixture。

### F5.86 阵列交互保护

静态审查发现 F5.86 在线性/圆周阵列构造结束前会用 `features.last()` 作为 pattern source。F5.84 若先追加分句沉孔，组合请求可能把阵列错误绑定到沉孔。解析第二孔时若检测到已构建的明确中心贯穿先导孔、跨句沉孔和同一请求中的线性或圆周阵列，则立即返回 `needs_clarification`、`plan: null`；该返回发生在沉孔创建及 F5.86 pattern 构造之前。独立 F5.84、独立 F5.86 线性/圆周请求仍走原路径。

新增 parser contract 覆盖三类行为：F5.84 独立沉孔保留有效 CADPlan 与来源；F5.86 线性/圆周请求的 `pattern_source` 仍指向预期特征；两种组合请求都在建模前明确要求拆分，不能产生错绑的 plan。
