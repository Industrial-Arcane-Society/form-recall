# F5.29：Quick 旧版 V 带轮配方迁移

## 范围

将旧 Python Quick 的 V 带轮单件配方迁入 Rust Quick，走现有 Vue → Tauri `quick_build` → Rust 解析器/CADPlan → OCCT 原生回转几何路径。旧 Python 解析器和桌面流程不变。

输入识别覆盖 V 带轮、皮带轮、多槽/多楔带轮及带明确槽数、槽型的带轮描述；可读取基准直径、槽数、槽型、轮宽和中心孔，支持 `D/n/t/d/B` 简写。支持 Y、Z、A、B、C、D、E 槽型，窄 V/SPZ、SPA、SPB、SPC 映射到相应标准系列。

## 与旧 Python Quick 对照

固定 oracle 位于 [`quick_legacy_vbelt_pulley_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_vbelt_pulley_contract.json)，记录 Python `Parser().parse()` 与 Rust CADPlan 的参数、来源、警告及几何样例。

- 旧规则默认值按旧 Python 结果恢复，并逐项标记 `derived`：基准直径 100 mm、3 槽、A 型推荐值、中心孔 ⌀25 mm、轮宽 30 mm 起算。
- Z/A/B 的旧标准基准直径系列吸附和外径值来自 `src/legacy/kb/pulley_std.json`；例如 B 型请求基准直径 120 mm 会按旧规则吸附至 118 mm，标准外径为 123.5 mm。
- 旧 Python 会把过大的中心孔静默缩小，并允许部分含糊或自定义组合继续解析。Rust 对冲突槽型、无效槽数、超限孔径及复合孔/键槽请求明确返回待澄清或不支持，不复刻静默改参。
- **F5.79 兼容修正**：Quick 必须重现旧 Python 的实际参数和剖面，不能在解析之后另加 OCCT 专用宽度。A 型 3 槽、请求宽度 30 mm 时，旧解析与 Rust Quick 均使用 46.3197138574 mm；旧剖面的有效槽中心为 −14.7998569287、0、+14.7998569287 mm（名义槽距 15 mm，受旧版端部余量规则略微压缩）。旧轮廓在受限宽度下会让相邻槽根区间重叠。Rust 不再通过增加到 50.4591415721 mm 并移动槽中心来隐藏这一差异。
- 重现上述 Quick 轮廓与保证单个有效 OCCT 实体是两个独立验收项。若 OCCT 拒绝旧版相交/重叠轮廓，必须明确报告几何构建失败或提出经用户接受的近似方案；不得自动扩大轮宽、改槽距或把近似结果记为 legacy 等价。
- 较大规格旧配方可能生成辐条。本项只迁移可由标准轴对称回转剖面表达的无辐条类型；需要辐条的规格明确返回不支持。

## 几何实现与边界

- 原生特征类型为 `vbelt_pulley`，由标准 V 槽剖面和轮毂截面构成闭合轴对称回转实体；外径系列只接受相应标准表值或由槽型参数推导的外径。
- 轮槽按 GB/T fallback 剖面构造，属于本地近似；没有迁移供应商/完整标准细节，也没有 CATIA 原生槽特征映射。
- Quick 兼容剖面沿用旧 Python `std_pulley.profile` 的点序和有效槽中心；旧 Python 网格本身不提供 OCCT BREP 有效性保证。OCCT 体积与 legacy 网格有向体积不能据此直接作为相同口径的 parity 指标。
- F5.79 Quick 专用兼容路径已实现：当单特征旧 Quick `vbelt_pulley` 计划命中旧自交轮廓时，Rust 按旧 Python `make_revolve` 的 profile edge × 64 段生成三角网格，并直接写 Quick 预览、STL、OBJ、GLB 与 AIMODEL。路径不会放宽共享 CADPlan validator，也不会把无效 B-Rep 标为有效实体。
- 网格结果明确标记 `mesh_only`、`brep_available=false`、`catpart_available=false`，闭合实体计数为 null；主动 CATIA 推送和显式 CATPart 导出会被拒绝并说明原因。此路径只覆盖单一符合条件的 Quick V 带轮，不改变其他 CADPlan 或 Quick 特征路由。
- legacy Python STL 与 Rust Quick STL 的定向比较通过：两者均为 3072 三角面，包围盒均为 105.5 × 105.5 × 46.3197135925 mm，有向网格体积均为 584036.173759 mm³，三角面集合完全相同，128² XY/XZ/YZ 投影 mask 均 XOR=0、IoU=1.0。STL 文件哈希不同仅因导出头部等文件级数据不同。
- 可复现命令：`python tools/compare_legacy_quick_stl.py <legacy.stl> <rust.stl> --projection-size 128`。legacy STL 由旧 Python public `Parser().parse()` → `Document.build()` → `exporters.export_stl()` 导出；Rust Quick 路径可用 `cargo run --example native_legacy_vbelt_mesh_probe -- <fresh-output-root>` 复现。
- 复合额外孔、盲孔、键槽、圆角/倒角、沉孔和阵列尚未迁移；自定义槽剖面尚未迁移；最多支持 64 槽。
- 仅验证 Rust 原生几何和本地文件导出，不代表 CATIA 打开、桌面 UI 可见预览或工程制造精度已验收。
