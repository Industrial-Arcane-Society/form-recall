# F5.29：Quick 旧版 V 带轮配方迁移

## 范围

将旧 Python Quick 的 V 带轮单件配方迁入 Rust Quick，走现有 Vue → Tauri `quick_build` → Rust 解析器/CADPlan → OCCT 原生回转几何路径。旧 Python 解析器和桌面流程不变。

输入识别覆盖 V 带轮、皮带轮、多槽/多楔带轮及带明确槽数、槽型的带轮描述；可读取基准直径、槽数、槽型、轮宽和中心孔，支持 `D/n/t/d/B` 简写。支持 Y、Z、A、B、C、D、E 槽型，窄 V/SPZ、SPA、SPB、SPC 映射到相应标准系列。

## 与旧 Python Quick 对照

固定 oracle 位于 [`quick_legacy_vbelt_pulley_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_vbelt_pulley_contract.json)，记录 Python `Parser().parse()` 与 Rust CADPlan 的参数、来源、警告及几何样例。

- 旧规则默认值按旧 Python 结果恢复，并逐项标记 `derived`：基准直径 100 mm、3 槽、A 型推荐值、中心孔 ⌀25 mm、轮宽 30 mm 起算。
- Z/A/B 的旧标准基准直径系列吸附和外径值来自 `src/legacy/kb/pulley_std.json`；例如 B 型请求基准直径 120 mm 会按旧规则吸附至 118 mm，标准外径为 123.5 mm。
- 旧 Python 会把过大的中心孔静默缩小，并允许部分含糊或自定义组合继续解析。Rust 对冲突槽型、无效槽数、超限孔径及复合孔/键槽请求明确返回待澄清或不支持，不复刻静默改参。
- **F5.79/F5.105 兼容修正**：Quick 必须重现旧 Python 的实际参数和剖面，不能在解析之后另加 OCCT 专用宽度。A 型 3 槽、请求宽度 30 mm 时，旧解析与 Rust Quick 均使用 46.3197138574 mm；F5.105 对实际 `std_pulley.profile()` 点列捕获的有效槽中心是 −14.8、0、+14.8 mm（名义槽距 15 mm），旧槽根区间各重叠 1.5197138574 mm。参考 [F5.105 旧 Python 实测基线](../../artifacts/f5.105-vbelt-a100-overlap/legacy_raw_baseline.json)。Rust 不再通过增加到 50.4591415721 mm 并移动槽中心来隐藏这一差异。
- 重现上述 Quick 网格与保证单个有效 OCCT 实体是两个独立验收项。对槽根重叠且旧 Quick 只输出自交逐边网格的固定输入，可以按旧 `Document.build()` 逐面生成 `mesh_only` 结果；必须明确不提供 B-Rep/CATPart，也不得自动扩大轮宽、改槽距或把受限 B-Rep 映射记为 legacy raw 等价。
- 较大规格旧配方可能生成辐条。F5.29 固定旧成功样例 `V带轮 基准直径300 槽数3 槽型C 内孔20 宽度180` 已接入 Quick 网格兼容路由：解析、CADPlan provenance、预览/网格导出均可用。旧剖面仍保留槽根重叠，且旧 Document 网格把五根箱体辐条直接追加到回转网格；本例因此明确为 `mesh_only`，不能据此声称闭合 B-Rep、CATPart 或 CATIA 支持。

## 几何实现与边界

- 原生特征类型为 `vbelt_pulley`，由标准 V 槽剖面和轮毂截面构成闭合轴对称回转实体；外径系列只接受相应标准表值或由槽型参数推导的外径。
- 轮槽按 GB/T fallback 剖面构造，属于本地近似；没有迁移供应商/完整标准细节，也没有 CATIA 原生槽特征映射。
- Quick 兼容剖面沿用旧 Python `std_pulley.profile` 的点序和有效槽中心；旧 Python 网格本身不提供 OCCT BREP 有效性保证。OCCT 体积与 legacy 网格有向体积不能据此直接作为相同口径的 parity 指标。
- F5.79 Quick 专用兼容路径已实现：当单特征旧 Quick `vbelt_pulley` 计划命中旧自交轮廓时，Rust 按旧 Python `make_revolve` 的 profile edge × 64 段生成三角网格，并直接写 Quick 预览、STL、OBJ、GLB 与 AIMODEL。F5.29 又补上旧 `Document.build()` 对辐条箱体面的追加和绕 Z 轴旋转；C300 样例的辐条仍为 5 个 135.3 × 37.884 × 15.3 mm 箱体，轴向 z=67.05..82.35 mm，角度 0/72/144/216/288°。路径不会放宽共享 CADPlan validator，也不会把无效 B-Rep 标为有效实体。
- 网格结果明确标记 `mesh_only`、`brep_available=false`、`catpart_available=false`，闭合实体计数为 null；主动 CATIA 推送和显式 CATPart 导出会被拒绝并说明原因。此路径只覆盖单一符合条件的 Quick V 带轮，不改变其他 CADPlan 或 Quick 特征路由。
- F5.29 固定旧 Python Parser → `Document.build()` → 二进制 STL oracle 保存在 [`f5.29-vbelt-spokes`](../../artifacts/f5.29-vbelt-spokes/)；旧网格 SHA-256 为 `0dfb2636da37eb4c8cc0dc6c1704a7c4974efede610ab6f2678359fd4d10f574`，Parser 无警告，Document 参数与 explicit/derived provenance 见 `legacy_oracle.json`。Rust native Quick 导出的 STL SHA-256 为 `b513e81ab7eaa1837c687f3c26f69830527ebe7d91a6f309fb70910c8c7fcf7d`。对拍记录 `raw_mesh_comparison.json`：两者各 3132 三角面、包围盒最大差 0、网格有向体积差 0、三角面多重集合完全一致，128² XY/XZ/YZ 投影均 XOR=0、IoU=1.0。该证据证明本固定样例的 Quick 网格复刻，不证明 B-Rep 等价。
- C300 三槽样例因槽根重叠由 Quick overlap gate 在 B-Rep 构建前路由到 `mesh_only`；本轮验收没有执行该输入的 B-Rep 构建，因此不对其可能产生的 B-Rep solid 数量作结论。mesh-only 报告明确为 `brep_available=false`、`catpart_available=false`、`solid_count=null`；不改变其他可形成单体的无辐条回转样例路由。
- C300 单槽固定输入 `V带轮 基准直径300 槽数1 槽型C 内孔20 宽度180` 没有相邻槽根，报告 `groove_root_overlap_mm=0`、`legacy_profile_self_intersecting=false`，因此走原生辐条 B-Rep 路径。Rust native Quick 定向验收要求一个有效闭合实体，并核对 bbox、槽根宽 28.8477697401 mm、节距 25.5 mm、轮毂 ⌀39 × 36 mm、轮缘内径 ⌀261.85 mm、辐板厚 15.3 mm、辐条 5 根及其位置。旧 `Document.build_brep()` 对同输入明确失败，故 Rust 产物是受限几何映射，不是旧 B-Rep parity；旧 raw STL 与融合 B-Rep 的内部隐藏拼接面也不用于外表面等价结论。旧 Parser、参数/provenance 和 2108 三角面 raw oracle 见 [`single_groove_legacy_oracle.json`](../../artifacts/f5.29-vbelt-spokes/single_groove_legacy_oracle.json) 与 [`legacy_document_build_raw_single_groove.stl`](../../artifacts/f5.29-vbelt-spokes/legacy_document_build_raw_single_groove.stl)。
- A100 3 槽窄宽输入 `V带轮 基准直径100 槽数3 槽型A 内孔25 宽度30` 在旧 Parser 中成功并把宽度派生为 46.3197138574 mm，旧 Document 网格为 3072 三角面。Rust 保留该计划宽度；mesh-only gate 限于 schema 1.0/1.1、mm/deg 单位、单一且 `enabled` 不为 false、无关系的标准 V 带轮 `add` 计划，CADPlan 校验通过或唯一错误为 `vbelt_width_below_profile_minimum`，native 预检通过且实际槽根区间重叠。C300 三槽样例属于校验通过但槽根重叠的分支；A100 则属于唯一宽度错误分支。该路径不篡改共享 validator 结果，也不把宽度放大到 50.4591 mm。Rust STL 与 [F5.105 旧网格 oracle](../../artifacts/f5.105-vbelt-a100-overlap/legacy_document_build_raw.stl) 已通过三角面多重集合、包围盒、有向体积及 128² 三向投影精确对拍，见 [`raw_mesh_comparison.json`](../../artifacts/f5.105-vbelt-a100-overlap/raw_mesh_comparison.json)。
- 可复跑验收：在 `src/apps/desktop/src-tauri` 设置 `CARGO_BUILD_JOBS=1`，`AIMODELER_OCCT_MANIFEST=target/debug/occt-runtime/runtime-manifest.json`，并将 `F5_29_RUST_STL`、`F5_29_RUST_GEOMETRY_REPORT`、`F5_29_SINGLE_SLOT_RUST_STL`、`F5_29_SINGLE_SLOT_RUST_REPORT`、`F5_105_RUST_STL`、`F5_105_RUST_GEOMETRY_REPORT` 分别设为仓库根目录下对应 artifact 输出的绝对路径。运行 `scripts/test-lib.ps1 -Filter 'native_quick::acceptance_tests::legacy_vbelt_pulleys_build_reopen_and_export_through_native_quick' -Ignored -NoCapture`；脚本临时为测试 exe 提供 Common-Controls v6 sidecar。再从仓库根目录运行以下两条 raw 网格比较：

  ```powershell
  python -B tools/compare_legacy_quick_stl.py artifacts/f5.29-vbelt-spokes/legacy_document_build_raw.stl artifacts/f5.29-vbelt-spokes/rust_native_quick.stl --projection-size 128
  python -B tools/compare_legacy_quick_stl.py artifacts/f5.105-vbelt-a100-overlap/legacy_document_build_raw.stl artifacts/f5.105-vbelt-a100-overlap/rust_native_quick.stl --projection-size 128
  ```

  Oracle 使用旧 public `Parser().parse()` → `Document.build()` → `exporters.export_stl(binary=True)` 生成。单槽 B-Rep artifact 是受限几何映射，验收单闭合实体和几何报告，不作为旧 raw STL parity 样例。
- 复合额外孔、盲孔、键槽、圆角/倒角、沉孔和阵列尚未迁移；自定义槽剖面尚未迁移；最多支持 64 槽。
- 仅验证 Rust 原生几何和本地文件导出，不代表 CATIA 打开、桌面 UI 可见预览或工程制造精度已验收。

## 验收

- Python oracle 对拍覆盖明确 A/B/Y 槽型、简写输入、默认值、直径吸附、宽度安全调整，以及拒绝/待澄清边界。
- 最新定向 ignored acceptance 通过 7/7 样例：4 组已有标准实体样例、C300 三槽 mesh-only、A100 三槽宽度重叠 mesh-only、C300 单槽有效闭合 B-Rep。七组均经 native Quick 构建并重载 AIMODEL，生成 GLB、STL、OBJ。单槽 B-Rep 的旧 `Document.build_brep()` 本身失败，因此该项仅验收 Rust 受限几何映射，不声称 legacy B-Rep 或旧 raw 网格 parity。
- A100 parser/CADPlan fixture、旧宽度保留、唯一 validator 错误及 mesh-only 准入测试通过；旧入口 raw 与 Rust raw 两者均为 3072 三角面，包围盒和有向体积差为 0，三角面多重集合完全一致，128² XY/XZ/YZ 投影 XOR 均为 0、IoU 均为 1.0。
- 单槽 C300 的 Rust B-Rep 为一个有效闭合实体，尺寸 309.6 × 309.6 × 180 mm，4404 三角面；几何报告核对 16 点轮廓、槽根/节距、轮毂、轮缘、辐板及五根辐条位置。Rust STL SHA-256 为 `9467050b8d5ff36bc3f53e5d63248ef20561fdce9de1e77c0065555ad4abbe34`；它只作为映射产物保存，不与旧 raw 拼接网格作表面等价宣称。
- 本轮使用的两组 mesh-only 样例均有旧 raw exact comparator：C300 三槽为 3132 三角面，A100 为 3072 三角面；两组的 bbox/有向体积差为 0、exact triangle multiset=true，三向投影 XOR=0、IoU=1.0。A100 Rust STL SHA-256 为 `8358b60e1428a51cd6b17c0ec2ae94e054ff13d2098c50a1484464a87766cc5d`。
- 本轮未运行 CATIA、桌面 UI 或安装包验收。Quick mesh-only acceptance 证明 native Quick 可导出该固定输入；真实可见 UI 预览仍未验证。
- 本次未运行 CATIA、桌面 UI 或安装包验收。
