# F6.2 Native desktop bootstrap acceptance

Date: 2026-10-03
Worktree: `feat/rust-dsh-acp-host`
Scope: Rust resource/bootstrap commands and Vue startup path; no CATIA adapter or F6.4 diagnostics migration.

## Result

Desktop initialization now reads packaged static resources, independent runtime readiness, native settings, and the native active CAD model. If no active model exists, the UI creates a native `Part1`. This startup path does not call `system.handshake` or `system.initialize`, and does not require Python. The Agent resource root is resolved from app static assets rather than `project_root()`; Quick uses that same resource root to resolve OCCT.

First-run setup now installs only the app-private DSH runtime. A missing DSH runtime does not block the desktop, native active model, or Quick mode; the Agent action opens setup when DSH is missing. Python is optional for bootstrap. OCCT and CATIA remain independent capabilities, reported as `ready`/`missing` and `com_registered`/`not_registered`/`not_checked` respectively. The shared native active model continues to be the source for native Quick and Agent operations.

Resource-root validation checks the native Agent scripts, DSH manifests, prompt, and `kb` directory. It deliberately does not check `ai_modeler/__main__.py`. An invalid existing packaged resource root fails closed rather than falling back to development files.

## Verification

- `cargo test native_bootstrap --manifest-path src/apps/desktop/src-tauri/Cargo.toml` — passed, 3 tests. Covers resource discovery with no Python source, fail-closed packaged resources, and distinct Python/DSH/OCCT/CATIA readiness.
- `node --test src/nativeBootstrap.test.mjs` from `src/apps/desktop` — passed, 2 tests. Covers native-only startup wiring, common active-model snapshot/new commands, and DSH-only first-run installation.
- `npm run build` from `src/apps/desktop` — passed (`vue-tsc -b` and Vite production build). Existing warning: `CadViewport` chunk exceeds 500 kB.

No desktop GUI or installed-package cold-start was performed. These tests establish the code wiring and pure bootstrap behavior; they do not demonstrate a physical machine boot with Python absent, DSH installed, OCCT available, or CATIA registered. G6.7 packaging cold-start evidence remains separate.
