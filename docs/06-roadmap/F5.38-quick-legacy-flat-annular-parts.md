# F5.38：Quick 旧 Python 简化环形零件

## 迁移依据

旧 Quick 入口为 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.parse`。本项迁移四个共享平环构造的零件库配方：链轮与油封使用 `_ring`，碟形弹簧使用 `_ring`，离合器摩擦片使用 `_washer`。旧输出实际都只有 64 段居中圆柱和一个 48 段中心贯穿孔；名称对应的复杂结构并未生成。

样例、Python mesh 统计、默认值及差异合同见 [`quick_legacy_flat_annular_parts_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_flat_annular_parts_contract.json)。旧参数表的内径默认分别为链轮 ⌀20、油封 ⌀30、碟形弹簧 ⌀20、离合器摩擦片 ⌀120 mm。轴向尺寸默认分别是链轮 20 mm、油封 7 mm、碟形弹簧 3 mm、离合器摩擦片 2 mm；离合器摩擦片的旧 `_washer` 构造器用 2 mm fallback，即使参数表列有 8 mm 典型厚度，Python Quick 实际输出仍为 2 mm。

旧解析器还会静默忽略链齿、油封唇口和碟簧曲面。离合器摩擦片附加“孔数6”时，旧通用 Parser 额外生成了一个中心位置、直径为 6 mm 的孔切除；它落在已有中心孔空腔中，不会得到用户期望的螺栓孔阵列。Rust 对这些组合请求返回 `unsupported`，避免将缺失结构误报为已建成。

## Rust Quick 行为

- 支持链轮、油封/骨架油封、碟形/蝶形弹簧、离合器摩擦片/离合器片/摩擦片的旧独立环形配方。
- 复现各旧别名、居中 Z 轴圆柱、中心贯穿孔、64/48 段数和上述实际构造默认值；Rust 会把内径和轴向尺寸来源明确标为用户输入或派生默认。
- 缺少外径、非正数、内径不小于外径时请求澄清。旧 Python 在内外径相等时最终可能丢失孔并退化为实心圆柱；Rust 不保留这个误建结果。
- 对链齿、油封唇口、碟簧曲面、摩擦结构、附加孔槽等未迁移内容明确返回 `unsupported`。
- 每个正常结果附带具体形状限制说明：这些是旧程序输出的平环近似，不是真实链轮、骨架油封、碟形弹簧或摩擦片结构。

## 几何验收

解析合同测试 `native_quick_parser::tests::legacy_flat_annular_parts_match_python_oracle_and_provenance` 通过，覆盖四类名称、默认值与参数来源、旧静默忽略差异、无效尺寸拒绝，以及 CADPlan 校验和几何 preflight。

OCCT 测试 `native_quick::acceptance_tests::f5_38_legacy_flat_annular_parts_build_measure_reopen_and_export` 对每类显式输入和每类典型默认输入共 8 组完成测量：

- 包围盒分别为 `100×100×10`、`50×50×8`、`40×40×2`、`180×180×4 mm`，另覆盖各自默认厚度/内径。
- 每个样例均生成 1 个有效闭合实体，中心贯穿孔经最终 B-Rep 测量为 `verified_open`；analytic volume 与旧 Python 网格体积差约 `0.061%–0.156%`。
- 每个样例均保存并重新载入 AIMODEL，并生成 GLB、STL、OBJ。

本验收证明 Rust/OCCT 复现的是当前 Python Quick 的简化平环结果；它不证明真实机械零件应采用该形状，也不包含 CATIA COM 验收。
