# F5.44：Quick 旧 Python 凸轮轴

## 迁移依据

旧 Quick 入口为 `src/legacy/ai_modeler/core/parsing/nlparser.py::Parser.parse`，零件库配方为 `src/legacy/ai_modeler/parts/library/partlib.py::_camshaft`，网格由 `src/legacy/ai_modeler/core/geometry/kernel.py::make_camshaft` 生成。参数合同、Python 解析结果、旧包围盒和网格统计保存在 [`quick_legacy_camshaft_contract.json`](../../src/apps/desktop/src-tauri/tests/fixtures/quick_legacy_camshaft_contract.json)。

旧配方要求基圆直径 `d`、升程 `h`、总长 `L`；未写凸轮数时构建器使用 4。零件库可写「轴颈」，未写时几何内核按 `max(2 mm, 0.55×基圆直径)` 推导轴颈直径；轴颈超过凸轮最大直径时会静默钳制到该上限。轴线沿全局 X，凸轮沿轴向等距布置，凸轮相位均分 360°。轮廓固定为 48 点、120° 简谐升程，不是任意升程曲线。

## Rust Quick 行为

- 识别「凸轮轴」及 `d/h/L/n` 简写。基圆直径、升程和总长缺失时逐项询问，不使用零件库的全尺寸样例替代。凸轮数缺省沿用旧值 4；轴颈缺省沿用旧公式；默认值和来源写入 warning 与 CADPlan provenance。
- 轴颈超过凸轮最大外径时依旧按旧几何公式钳制，并明确报告调整后的值。旧 Python 解析会丢弃显式的「凸轮数0」并回退为 4，Rust 保留这个可观测结果；超出 512 凸轮的请求因原生资源边界返回 unsupported。
- 负升程、过小基圆直径和过短轴长沿用旧几何内核下限，并通过 warning 标明。未写单位时按 mm 解释；带「厘米/cm」的值由 Rust 正确换算成 mm。旧零件库解析器曾把示例中的 cm 数值原样保留，因此厘米输入的结果会与旧版有意不同，已在 fixture 中作为已知差异记录。
- 自定义相位、孔槽、键槽、螺纹、边缘修饰和附加特征尚未迁移，明确返回 unsupported。相位固定为旧配方的 0°，并作为带来源的 `lobe_deg` 写入计划。
- Rust 使用解析采样轮廓构建凸轮，与解析圆柱轴融合成一个本地闭合 B-Rep。旧 Python 输出的是未融合多边形片，旧网格的体积包含重叠壳体贡献，不能与融合后的 B-Rep 体积直接比较。该特征在几何支持报告中标记为近似；CATIA 映射仍是近似，不表示原生 CATIA 凸轮特征已迁移。

## 验收

`native_quick_parser::f5_44_legacy_camshaft_contract_tests::legacy_camshafts_match_python_oracle_defaults_and_boundaries` 对照 Python oracle，覆盖完整参数、缺省凸轮数/轴颈、简写、零凸轮数回退、厘米单位差异、过大轴颈钳制、小轴颈、缺失尺寸、重复冲突、孔类附加结构及 512 上限。生成的计划均通过 CADPlan 校验和原生几何 preflight。

`native_quick::acceptance_tests::f5_44_legacy_camshafts_build_measure_reopen_and_export` 实际构建 7 个样例，全部通过本地几何报告并为一个有效闭合实体；包围盒均为 `320×46×46 mm`。指定轴颈 26 mm 的 B-Rep 体积为 `292828.6254429548 mm³`；默认轴颈 16.5 mm 的体积为 `247729.3175714212 mm³`；被钳制到 46 mm 的样例为 `531808.8043996801 mm³`；显式 0.5 mm 轴颈的体积为 `217346.6259527041 mm³`。七例均通过 AIMODEL 重载和 GLB、STL、OBJ 文件生成。体积数字用于锁定当前 OCCT 构建回归，不作为与旧未融合网格的等体积断言。
