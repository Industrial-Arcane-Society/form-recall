## 四、与文档方案的差异说明（本程序的增强）

文档描述的是「AI 客户端 → MCP → CATIA」链路，其中 CATIA 是必需环节。
本程序在此基础上做了两点增强，使其在**没有安装 CATIA 的电脑上也能完整工作**：

1. **内置几何内核**：`kernel.py` 自行实现了 BSP 树 CSG 布尔运算（并 / 交 / 差）
   与基础特征构造，因此建模、三维预览、几何统计、STL 导出全部可离线完成。
2. **双通道输出**：
   - **通道 A（本机）**：内置内核建模 → 三维预览 → 导出 STL / OBJ / 工程文件
   - **通道 B（有 CATIA 时）**：导出 CATIA 自动化脚本 → 在 CATIA 中重建相同的特征树并保存为 `.CATPart`
