# 研究目标、问题与证据规则

## 研究目标

研究一个桌面建模系统如何把自然语言和一张或多张参考图片转换成可编辑 CAD 模型，并在本地几何验证和视觉证据之间建立可复现的修正闭环。系统支持快速模式和 Agent 创造模式；两者可以共享模型数据格式和几何能力，但由不同的流程负责。

## 研究问题

1. **Agent 控制权**：DSH 能否直接决定下一步工具、检查与修正动作，而不是由宿主代码固定执行一组阶段？
2. **图像证据**：模型能否区分视角、可见结构、遮挡和比例估计，并保留证据到 CAD 特征的映射？
3. **模型表达**：Rust 拥有 CADPlan 和特征状态后，能否以稳定的几何内核构建可编辑模型？
4. **自审查**：由原始图片、多视图渲染、几何量测和拓扑检查组成的证据能否定位差异并在新版本中关闭？
5. **桌面可靠性**：桌面安装包能否固定并校验 DSH、Node、插件及几何运行时，在无预装开发环境的 Windows 机器上启动和回收？

这些是待检验的问题，不能把目标架构或一份计划写成实验结论。

## 假设与可反驳条件

| 假设 | 可观察指标 | 反驳条件 |
|---|---|---|
| DSH 直接拥有 Agent 决策可减少固定流程造成的无效调用 | 实际工具序列、重复动作、无效轮次、完成时间 | 在同一任务集和模型设置下，固定流程的失败率/延迟显著更低 |
| 增量 CAD 工具比每轮重写整份计划更稳 | 未修改特征保留率、工具参数错误、回滚次数 | 增量状态产生更多结构损坏或更难复现的版本漂移 |
| 几何审查和多模态审查应分开记分 | 几何合法率、尺寸误差、视图差异项关闭率 | 两类指标无法提供独立诊断或共同指标更能预测用户接受度 |
| 原图与分开的单视图对照能降低视觉审查混淆 | 视角定位正确率、具体差异召回率、误报率 | 在盲测中不优于堆叠视图，或成本显著增加且不改善修正结果 |

## 证据分层

- **来源证据**：用户尺寸、图纸标注、图像视角和图像比例估算；逐项记录来源，估算值明确标记 `image_estimate`。
- **代码证据**：当前提交中的入口、参数和数据流。它证明“代码定义了什么”，不能单独证明运行行为。
- **运行证据**：实际版本、操作输入、完整日志、工具返回、耗时与输出路径。provider 和模型能力必须从真实请求记录核对。
- **几何证据**：包围盒、实体数、拓扑有效性、孔位和网格检查；不等同于视觉相似。
- **视觉证据**：原图与模型多视图对照，记录视角、差异位置、受影响特征和修正后的新版本。
- **CATIA 证据**：真实 CATPart 的打开、特征树、几何尺寸及宏执行记录；本地 STL 或预览不替代 CATIA 验证。

## 研究记录格式

每项实验记录输入与 SHA-256、软件/模型/runtime 版本、设备与配置、控制变量、步骤、原始结果、量化指标、失败和局限。保留失败样例；改动后的成功样例不能覆盖旧结果。
