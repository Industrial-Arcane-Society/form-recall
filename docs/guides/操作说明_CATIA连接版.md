## 二、先启动装配好的两个程序

### 1) 启动 AI 自动建模助手

- 双击桌面 **「AI 自动建模助手」** 快捷方式；
- 或双击插件目录里的 `启动 AI自动建模助手.vbs`；
- 出问题想看报错，就用 `启动 AI自动建模助手(带控制台).bat`。

启动后界面左上角输入中文，例如：

```
法兰 外径 160 厚 20 内径 60, 均布 6 个直径 12 的螺栓孔, 分度圆 120
```

点 **「⚡ 生成模型」**（或 `Ctrl+Enter`）→ 中间出现三维预览 → 「文件」菜单可导出 STL / OBJ / 建模报告 / CATIA 脚本。

### 2) 启动 CATIA 2023

- 双击桌面/开始菜单里的 **CATIA P3 V5-6R2023** 图标（安装器已建好）；
- 或手动运行（图标丢了就用这条）：

```
"D:\catia\win_b64\code\bin\CATSTART.exe" -run "CNEXT.exe" -env CATIA_P3.V5-6R2023.B33 -direnv "D:\catia" -nowindow
```

> 注：老版本 **V5-6R2016 (B26) 已彻底卸载**（程序目录 4.72 GB、环境文件、注册表卸载项均已清除），

## 四、在 CATIA 里用中文建模（日常用法）

1. 在 CATIA 里 **新建或打开一个 CATPart**（宏会往当前文档的 PartBody 里加特征；
   如果没有任何文档，宏会自动新建一个 Part）。
2. **工具 → 宏 → 宏... → 运行 `AI自动建模助手.CATScript`**。
3. 在弹出的输入框里写一句中文，例如：

   ```
   画一个 120×80×15 的长方体, 四角圆角 R8, 中心打一个直径 20 的通孔
   ```

4. 点确定，等 5～40 秒（后端解析 + CATIA 重建）。
5. 完成后会弹提示：**成功 N / 总数 M 个操作**，特征树里就能看到 `Pad`、`Pocket`、`Shaft` 等特征。
6. **文件 → 保存**，另存为 `.CATPart`（宏不会自动保存）。

> 识别不了的说法，助手会联网检索后给你**一条建议描述**，你确认后再建模；
> 也可以直接用助手界面里的示例下拉框。

## 八、常见问题

**Q1：运行宏后提示"Python 后端没有返回结果"？**
宏的提示框里会给出它执行的完整命令，复制到命令行跑一次看报错。常见原因是 Python 路径变了——
重跑一次 `连接CATIA.bat` 会按当前 Python 重新生成宏。检查命令：

```bat
python -m ai_modeler --catia-info
python tools\test_catia_bridge.py
```

**Q1b：宏报错时怎么查？**
现在宏会写一份日志：`%TEMP%\ai_modeler_macro.log`（宏侧步骤）与
`%TEMP%\ai_modeler_push_*.log`（建模过程，逐步记录每个特征）。把这两份发我即可定位。

**Q2：提示"特征表为空"？**
说明那句中文里没有可识别的建模指令。参考本文第四章与 `README.md` 的词汇表（基本体 / 草图拉伸 / 切除 / 圆角倒角 / 阵列 / 复合模板）。

**Q3：助手界面/自检显示"未接入 CATIA"？**
跑一次 `连接CATIA.bat`；若仍不行，用 `--exe` 直接指定 `CNEXT.exe` 路径。

**Q4：部分特征在 CATIA 里失败？**
切除方向现在由"更新报错自动翻转"处理；复杂特征仍可能失败，完成提示里会列出是哪几条，手动补一下即可。
也可以改用 **文件 → 导出 CATIA 自动化脚本**（生成 `.py`，需要 `pywin32`）。

**Q5：为什么"推送到 CATIA V5"用不了？**
那条通道需要 `pywin32`（当前未安装）。宏插件通道**不需要**它，推荐用宏。
想启用 COM 直推：`pip install pywin32`，然后 `python -m ai_modeler --selftest` 复查。

**Q6：以前装了两套 CATIA，现在怎么切换？**
老版本 V5-6R2016 (B26) 已按要求彻底卸载（见第十一章），本机现在只剩 2023/B33，助手自动识别它。
以后若又装了别的版本，重跑 `连接CATIA.bat`（或 `--level Bxx`）即可切换。

**Q7：模型库搜不到想要的东西？**
先 `--rebuild` 重建索引；确认检索词命中分类（中文别名表见第五章）；库内条目名为英文，
例如"滚筒"要搜 `Roller` 或中文"输送线"。

**Q8：CATIA 2023 桌面图标没了怎么办？**
按第二章第 2 条的命令手动启动；或到 `C:\ProgramData\Microsoft\Windows\Start Menu\Programs\CATIA P3` 找。

**Q9：宏还是报「无效字符 / ScriptingERR_1002」？**
那是**旧版 UTF-16 宏**的毛病，本次已改为纯 ASCII。如果仍看到它，说明 CATIA 里打开的/记住的是旧文件：
重跑一次 `连接CATIA.bat` 重新生成宏，然后在 CATIA 里重新选一次
`catia_plugin\AI自动建模助手.CATScript`（并关掉可能还开着的"宏编辑器"窗口）。

**Q11：建出来的零件少了中心孔（或者整个零件不见了）？**
这是解析器的一个已修复的 bug：**同一句里，零件库模板匹配成功后就直接结束了**，
把后面附带的"中心孔直径15"整段吞掉（空格分隔时最容易触发；逗号分隔会被切成两句所以没事）。
另一种表现是模板要求参数齐全，少一个"齿宽"就整个不认，于是只剩一个孔。

现在这些情况都修好了：

- 模板匹配成功后，**同句里模板不负责的切除/修饰要求**（中心孔、圆角、凹槽…）会逐段摘出来交给通用规则；
  摘取时**只取那一小段**（例如"中心孔直径15"），不会把前面的"轮毂外径36"也带进去当成孔径；
- **参数没写全时按零件库典型值代入**，并在提示里说明（例如「b=20，可在右侧参数页改」），不再整个不认。

推荐写法（**逗号分隔更稳**）：

```
直齿圆柱齿轮 模数2 齿数30 齿宽20, 中心孔直径15
```

> ⚠️ **常驻对话框会一直跑旧代码**：对话框是个常驻进程，如果它是在你更新助手程序**之前**打开的，
> 它内部还是旧代码 —— 这时你会觉得"改了怎么没用"。遇到这种情况：
> **点「关闭」把窗口关掉，再在 CATIA 里重新运行一次宏**（窗口现在会自动检测并提示这一点）。

**Q12：中心孔切出来了，但位置好像不在正中间？**
转子的中心孔曾经**偏轴 5.3 mm**，原因不是 CATIA，而是导出器把"零件轴心"当成了**包围盒中心**
（Reuleaux 三角形/凸轮的包围盒不对称，包围盒中心不等于轴心）。现已修好：轴心取零件自身的
`center`，孔、轮毂、回转体都按轴心放置。判断方法见第十一章的几何校验（`tools\check_catia_solid.py`
会打印每个孔的圆心和孔壁顶点数）。

**Q13：凹槽/键槽写了没反应？**
之前空格连写的句子里 `凹槽/键槽` 不在切分标记表里，于是整段被当成零件名的一部分丢掉了。
现已修好，下面三种写法等价（都能切出 30×20 深5 的槽）：

```
长方体 100×60×20 顶面凹槽 30×20 深5
长方体 100×60×20 凹槽 30×20 深5
长方体 100×60×20, 顶面凹槽 30×20, 深 5
```

## 十一、两种建模方式（含本次真机联调修复）

### 方式 A（推荐）：在助手里输入 → 一键建到 CATIA

1. 打开 CATIA（不开也行，助手会自动启动，首次约 30–60 秒）；
2. 打开助手，输入中文描述 → 点「⚡ 生成模型」看到三维预览；
3. 点工具栏 **「推送 CATIA」**（或菜单 **工具 → 推送到 CATIA V5…**）；
4. 弹窗里选：
   - **是(Y)** = 建好后另存为 `.CATPart`（接着让你选保存位置）
   - **否(N)** = 只建模，不保存（之后自己在 CATIA 里存）
5. 助手会在 CATIA 里新建 Part 文档并逐条重建特征，完成后提示「成功 N / 总数 M」。

命令行等价写法：

```bat
python -m ai_modeler --push "法兰 外径 160 厚 20 内径 60, 均布 6 个直径 12 的螺栓孔, 分度圆 120" --save 法兰.CATPart
```

> 这条通道走 Windows 自带的 `cscript` + COM（`GetObject(,"CATIA.Application")`），**不需要 pywin32**；
> 每次推送还会写一份过程日志（`%TEMP%\ai_modeler_push_*.log`），万一卡住能直接看出停在哪一步。
>
> **CATIA 里那个宏（方式 B）现在也走这条通道**：宏本身只是个"瘦启动器"——它调 Python 弹中文对话框、
> 做解析，再由 Python 用 cscript+COM 建模，最后把结果回显到宏的提示框。
> 这样宏侧不碰任何混合造型(GSD) API，稳定性与助手的「推送 CATIA」按钮完全一致。

### 方式 B：在 CATIA 里运行宏 → 弹中文框输入

### 本次真机联调修掉的 4 个兼容问题

原插件作者在 README 里注明"未在真实 CATIA 上运行过"。这次在 **CATIA V5-6R2023 (B33)** 上实测，
发现并修复了下面这些坑（这就是你之前看到报错的原因）：

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | 宏一运行就报 `ScriptingERR_1002 / 无效字符 / 直线 1` | 宏文件存成了 UTF-16，而 CATIA 的 CATScript 加载器不认 BOM —— 整个脚本在它眼里只剩 1 个 `?` | 宏改成**纯 ASCII + CRLF**；路径里的中文用 `ChrW()` 动态拼接；中文输入框改由 Python 弹 |

### 第三批真机问题：孔全都没切出来（"建出来没有中心孔"）

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 10 | 齿轮/法兰等**所有孔都是空的**：日志 `2/2 操作`、`8/8 操作` 全成功，模型上看不到孔 | **CATIA 里凸台朝 +Z 长，而凹槽朝 −Z 切（方向相反！）**；导出器一直把切割草图放在材料**下方**，于是每个孔都在空切 —— 不报错、操作数也对、几何却没有变化 | 所有切除的草图改放到材料**上方**（从顶面之上往下切），凸台仍从底面往上长 |

**为什么之前没发现**：这类问题**不会报错** —— 空切在 CATIA 里是合法操作。
只看"成功/失败"永远抓不到，必须**量几何**。这次的办法（已固化成工具）：

1. 让 CATIA 把零件导出成 STL（`Document.ExportData path, "stl"`）；
2. 在 Python 里解析网格，**逐个孔检查"孔壁"**：存在一圈**绕该孔中心、半径≈孔径、沿 z 有实际高度**的顶点，才算真切出来了。

```bat

python tools\check_catia_solid.py "法兰 外径160 厚20 内径60, 均布6个直径12的螺栓孔, 分度圆120"
python tools\check_catia_solid.py "三角转子 外接圆半径60 厚度40 中心孔24" --zrange -20 20
python tools\check_catia_solid.py "长方体 100×60×20 顶面凹槽 30×20 深5"    凹槽查的是"槽底"
```

> **判据本身也踩过两次坑（记在这里，免得以后又量错）**：
> 1. 一开始用"离回转轴最近的顶点距离 ≈ 孔半径"。**凹面零件（三角转子）**的端面三角化会在孔
>    内部留下内部点，于是"最近"远小于孔半径 —— 明明切好了却判成没切。
> 2. 改成"孔壁环"后，又用了**原点当回转轴**。可零件的绘制中心不一定在原点：三角转子的
>    真实几何中心（质心）在原点，但它的**包围盒中心在 (0, 5.32)**（Reuleaux 三角形的包围盒
>    本来就不对称）。按原点量，切好的孔又量不到。
> 现在校验器直接读**导出器自己的切除记录 (cx, cy, r)** 当基准，逐个孔验证，不再靠"猜轴"。

## 十二、CATIA 视角操作速查（怎么自由转视角）
> CATIA 的鼠标约定和大多数三维软件**不一样**：它不是"左键拖动旋转"，而是用**中键组合**。
> 这一章把自由移动视角的所有方式列全，挑一种顺手的记住就行。

### 12.1 鼠标三键操作（最常用）

| 操作 | 效果 |
|---|---|
| **按住中键（滚轮）拖动** | **平移**视图（画面上下左右移动） |
| **按住中键 → 再按住右键拖动** | **自由旋转视角**（最常用，想怎么看就怎么看） |
| **按住中键 → 再按住左键拖动** | **缩放**（上下拖动） |
| **滚轮**上下滚 | 缩放 |
| **右键单击**（不拖动） | 弹出上下文菜单（**不是旋转**，别按错） |

> 三键鼠标是 CATIA 的刚需（30 元级别即可）。两键鼠标/触摸板配合 12.2、12.3 的办法也能用，
> 但会很别扭 —— 能换鼠标就换。

### 12.2 视图工具栏按钮（鼠标不好用时）

在工具栏上找「视图(View)」工具栏（或点 **视图 → 工具栏 → 视图** 调出来），里面是：

| 按钮 | 作用 |
|---|---|
| 平移 (Pan) | 按住左键拖动 = 平移 |
| 旋转 (Rotate) | 按住左键拖动 = 旋转（等价于中键+右键） |
| 缩放 (Zoom In / Out) | 点一下放大/缩小一级 |
| **适应全部 (Fit All In)** | 一键把整个模型调到最佳视角 —— **模型转丢了就点它** |
| 命名视图 (Named Views) | 等轴测 / 前 / 后 / 左 / 右 / 俯 / 仰 |

**菜单里也一样**：视图 → 命名视图 → 等轴测视图 / 前视图 / …（等价于助手界面里的视图菜单）。

### 12.3 罗盘（右上角那个三圆弧的小控件）

| 操作 | 效果 |
|---|---|
| 拖动罗盘上的**弧线/箭头** | 绕对应坐标轴旋转视角 |
| 拖动罗盘**中心的方块** | 三轴自由旋转（比鼠标更细腻） |
| 把罗盘**拖到零件上**再拖动 | **移动/旋转零件本身**（注意：这改的是模型，不是视角） |
| 把罗盘**拖回右上角原位** | 复位 |

### 12.4 让"转起来好看一点"的两个设置

- **旋转时模型变成线框/方块？** 这是"快速查看(Quick View)"在提速。
  关掉：**工具 → 选项 → 常规 → 显示 → 导航** → 取消勾选与「快速查看 / Quick View」有关的选项，
  之后旋转时就是真实着色。
- **想要透视感**：**视图 → 透视**（再点一次切回平行投影）。做工程图/看尺寸时用平行投影更准。

### 12.5 给自己设快捷键（很值）

CATIA 默认没给"适应全部""等轴测"这些常用视角配快捷键，可以自己设：

```
工具 → 自定义(Customize) → 命令(Commands) → 类别选「视图(View)」
→ 在右边列表里选中命令（如 适应全部 / 等轴测视图 / 前视图）
→ 点「显示属性(Show Properties)」→ 在「加速键(Accelerator)」框里按下你想用的组合键
→ 关闭
```

例如把 **适应全部** 设成 `F`、**等轴测视图** 设成 `Ctrl+1`，以后单手就能切视角。

### 12.6 别和助手的预览搞混

助手的 3D 预览窗口用的是**另一套**约定，两边对照记：

| 操作 | 助手预览窗口 | CATIA |
|---|---|---|

## 十四、复杂提示词的识别（本轮大修 + 100 条基准评测）

### 14.1 起因：一张图纸式长句被建成了完全不对的东西

用户输入一条液压缸缸筒的图纸式描述（外径 Ø25 / 内孔 Ø20 / 壁厚 2.5 / 法兰 Ø33×4 / 过渡圆角 R0.8），
结果建出一个 **160×160×20** 的大圆盘。查下来是三个叠在一起的老问题：

| # | 问题 | 根因 | 修法 |
|---|---|---|---|
| 1 | `Ø`（U+00D8）没被规范化，只有 `Φ/φ/∅/ø` 被认 | 「外径Ø25」整段读不到数字，零件库模板以为自己没拿到尺寸，**静默套用典型值**（法兰 160/20/内孔60） | 直径符号全部归一到 `⌀`（含 `Ø/Ф/ф/ϕ`） |
| 2 | `壁厚2.5` 被当成高度 | 「厚」这个别名命中了「壁厚」里的"厚" | 提取时排除 `壁厚`，并新增"壁厚 + 外径/内径 → 推另一个" |
| 3 | 长句里参数分散在多段，模板只用第一段 | 「缸筒 总长180, 筒体外径Ø63 内孔Ø50」的第一段只有总长 | 新增"把紧跟其后的纯尺寸段并进零件"的合并逻辑 |

还顺手修掉一批**用户看不出报错、但模型是错的**问题：

| # | 问题 | 说明 |
|---|---|---|
| 4 | 解析器**无限递归崩溃**（RecursionError） | 零件库摘出的"附加要求"又匹配到同一个零件名，自己调自己且永不缩小 → 加三重保险（深度上限 / 子句必须变短 / 同段不重复） |
| 5 | `内孔` 被当成"切除动作" | 于是**整个零件库被跳过**，联轴器/缸筒/垫圈全部退回通用规则建错 |
| 6 | 参数别名读不到就**静默套典型值** | 联轴器"长72"被套成 120、垫圈"内孔20.5"被套成 10 → 现在别名读不到会用**通用维度词兜底**，并由参数自己的中文别名决定语义（"轴孔直径"是内孔，不是外径） |
| 7 | 孔类参数**凭空套典型值** | 用户没写内孔时给法兰挖了个 Ø60 的洞 → 改为"绝不套"，缺孔就不挖 |
| 8 | 同一个孔被切两遍 | 零件库自带的孔 + 描述里又写了一遍 → 自动合并 |
| 9 | 「均布8个Ø14」位置式硬填 | 早先只要数字个数对得上就按顺序硬填，`法兰 Ø210×22` 把内径填成 210 → 位置式现在要求"后面**只有裸数字**" |
| 10 | 通用解析器不认 `铝板/钢板/箱体/凸台` | 新增这些关键词（凸台 = 圆柱） |
| 11 | 顺序描述不堆叠 | 「缸筒 Ø25/Ø20 长40, 端面法兰 Ø33 厚4」原本法兰陷在筒里，总高还是 40 → 现在默认**堆在前一个零件的顶面**（说了"同心/总长"则不堆） |
| 12 | 斜齿轮建模超时（20~36 秒，甚至 27 万面后放弃） | 内核按**直齿近似**（齿数/齿顶圆/中心孔都仍正确，CATIA 导出本来也是这么近似的） |
| 13 | 连杆"厚度"被算成大头外径 | 大头/小头改成**轴线沿 Z 的环**，厚度取"杆厚" |
