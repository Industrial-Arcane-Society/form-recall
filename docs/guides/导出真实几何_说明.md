# 导出真实零件几何（把 STEP 找回来）

## 为什么要这一步
本插件要把"真实零件的外轮廓（型腔/加强筋/台阶）"复刻出来，就必须拿到**实测 B-Rep**。
唯一来源是 CATIA 从 518 个 CATPart 导出 STEP/STL。

## 为什么需要你手动跑一次
我用 COM 无人值守启动的 CATIA **不能导出**（`ExportData` 一律返回 E_FAIL，
STEP / STL 都一样，已实测）—— 导出需要 CATIA 正常启动的完整会话与许可。
所以请你：

1. 用桌面快捷方式/开始菜单**正常打开 CATIA V5**（有界面、有许可即可，不用手动打开零件）；
2. **双击** `启动脚本/导出真实几何_双击运行.vbs`（就在插件根目录）；
3. 弹出两个对话框时：
   * 输入目录 → 默认 `C:\Users\25643\Desktop\零件参数`（直接确定）
   * 输出目录 → 默认 `%TEMP%\catia_step_out`（直接确定）
4. 等它跑完（518 个零件，约 20~40 分钟；支持断点续跑，中断了再双击一次即可）；
5. 跑完告诉我，我执行：
   ```powershell
   python tools\build_real_brep.py                 # STEP/STL → kb/real_brep/*.npz
   python tools\render_ai_parts.py --all           # 用真实外轮廓重渲染
   python tools\compare_ai_vs_photos.py --all       # 重新算图像相似度
   ```
