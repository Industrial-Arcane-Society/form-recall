# 实验记录模板

复制本文件到 `docs/03-experiments/`，以 `YYYY-MM-DD-<短主题>.md` 命名。每次运行使用唯一 run ID；保留失败、取消和部分完成记录，不覆盖先前结果。

## A. 登记信息

- Study ID / run ID：
- 记录人 / 日期 / 时区：
- 研究类型：探索性 / 假设检验
- 状态：已预注册 / 运行中 / 完成 / 中止 / 失败
- 研究问题：
- 主要假设：
- 相反结果或可反驳条件：
- 主要终点与次要终点：
- 方案版本、登记时间及变更记录：

## B. 背景与范围

- 项目内部观察或外部研究背景：
- 来源和引用（页面/版本/页码/链接/访问日期）：
- 当前方案要填补的证据缺口：
- 结论适用范围：
- 本次明确不回答的问题：

区分项目内部问题与外部行业事实。没有来源的市场/行业主张不要写入结果解释。

## C. 样本与输入证据

- 数据集名称、版本、划分（开发 / 验证 / 冷启动测试）：
- 样本 ID 与数量；预注册纳入/排除规则：
- 用户文字：
- 原图路径、顺序、视角标签、遮挡/不可观察区域：
- 每个输入文件 SHA-256：
- 尺寸真值与标注来源；容差及单位：
- 未知尺寸/图像估值及依据（估值须标 `image_estimate`）：
- 允许使用的知识库/历史材料：
- 禁止泄漏的答案、模型、报告或会话：
- 图像使用许可、敏感信息与保留限制：

## D. 对照与实验条件

- 对照实现 / 精确 commit：
- 候选实现 / 精确 commit：
- 两个工作树是否干净；若否，diff 文件：
- 操纵变量（本次只改变什么）：
- 固定变量：提示词、工具 schema、知识库、输入、provider/model/route、reasoning、运行时、机器等：
- 执行顺序与随机化/平衡方法：
- 重复次数与选择依据：
- Provider 未暴露、因此不可观测的配置：
- 若多项同时变化，说明只能比较整套系统、不能作组件因果归因：
