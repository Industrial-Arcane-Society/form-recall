# AI 建模训练提示词 —— 使用说明

> 语料来源：CATIA 批处理导出的 **521 个真实零件 STEP**，逐个实测解析后，
> 按「型号 → 真实几何」对照表自动生成。**每一条提示词都经过自检：**
> 当前插件必须能把它解析回同一个真实型号（自检不合格 0 条）。
> 生成工具：`tools/make_training_prompts.py`（可复跑，切分结果稳定不变）。

## 二、文件清单

| 文件 | 内容 |
|---|---|
| `全部提示词.jsonl` | 1816 正例 + 12 负例，每行一个 JSON：`{id, prompt, category, model, envelope, envelope_str, trust, source, group, variant}`。**给程序训练/微调用这个。** |
| `训练集_提示词.txt` | 1453 条提示词，每行一条（喂给模型的部分） |
| `训练集_答案.txt` | 与训练集**逐行对齐**：`id ⇥ 类别 ⇥ 型号 ⇥ 实测外形` |
| `测试集_提示词.txt` | 375 条（**留出题**，训练时不要喂给模型） |
| `测试集_答案.txt` | 与测试集逐行对齐 |

**切分规则**：按 `id` 的稳定哈希 8:2 切分 —— 同一份数据每次跑出来都一样，
不会出现"这轮的测试题下轮变成训练题"。

## 三、三种用法

### 用法 A：直接在"AI 自动建模助手"里练（人工评测）

把 `训练集_提示词.txt` 里的句子一条条粘进助手的输入框，看它建模的结果：

1. 类别对不对（与 `训练集_答案.txt` 第 2 列一致）；
2. 参数对不对（第 3 列型号、第 4 列实测外形，容差 0.05 mm）；
3. 建出来的**三维模型**外形与实测外形一致。

答错的做法记录到 `kb/instent_corrections.json`（插件自带的"意图纠正"会记住你改过的值）。

### 用法 B：用 jsonl 做 LLM 微调 / 评测

`全部提示词.jsonl` 的字段自解释。训练目标有三条：

1. **识类**：`prompt → category`（这是什么零件）；
2. **识号**：`prompt → model`（哪个真实型号）；
3. **识形**：`prompt → envelope`（现实长什么样 —— 这是本插件这一轮迭代的核心，
   "先让 AI 明白是什么、现实长什么样，再建模"）。

负例的正确答案是**拒绝**（category=null），训练"没命中就不猜"。

### 用法 C：全自动闭环（推荐，零手工）

```bat
python tools\bench_real_geometry.py             :: 593 条自动评分（对实测几何）
python tools\selflearn_real_geometry.py --rounds 4   :: 自学习闭环
python tools\selflearn_real_geometry.py --rounds 4 --inject 3   :: 注入缺陷验证闭环
```

## 四、评分标准（与 `tools/bench_real_geometry.py` 同口径）

| 检查项 | 通过条件 |
|---|---|
| 类别 | 与答案第 2 列一致 |
| 型号识别 | 与答案第 3 列一致（忽略大小写与分隔符） |
| 能建几何 | 特征树非空，网格能建出来 |
| **外形（对实测）** | 建出来的**网格**尺寸集合 = 答案第 4 列的实测外形，容差 0.05 mm |

> ⚠ 这里比的是**建出来的网格**，不是插件自己声明的尺寸 —— 上一轮迭代实测发现
> 只比声明值会出现"声明对了、建出来是错的"假通过（吊环、接近开关被抓出来过）。

**负例**的通过条件是：插件回答"库里没有 / 未命中"，而不是硬编一个零件。

## 五、注意事项

1. **不要用测试集训练**：`测试集_提示词.txt` 是留出题，训练时只喂 `训练集_*`。
   混用会让"命中率 95%+"失去意义（背答案）。
2. **外形是实测值，不是型号名义值**：例如 `EGT001 SW80x118` 的实测外形是
   118×80×80（截面是整数 80.000，长度就等于型号码）；`KMS-M09-S03-20-05`
   的实测厚度是 **0.5**（型号尾码 ×0.1），不是 5。
3. **装配导出的外购件没有可用的零件外形**：UNIVER 气缸类 8 个型号的 STEP 里
   混入了装配骨架坐标，答案里这类条目的 `envelope` 为 `null`、`trust` 为
   `assembly_scope` —— 训练它们"外形未知时就明说未知"。
4. **语料可再生**：新增导出的 STEP 后，重跑
   `build_real_geometry.py → learn_real_library.py → make_training_prompts.py`
   即可扩库；切分哈希保证老条目不会挪窝。
