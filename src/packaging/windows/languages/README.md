# 安装器语言来源

`ChineseSimplified.isl` 来自 Inno Setup 官方源仓库收录的社区简体中文翻译，维护者为 Zhenghan Yang。文件保留上游署名、说明和全部翻译文本。英文使用编译器随附的 `Default.isl`。

安装器按 Windows 界面语言选择简体中文或英文，并显示语言选择框。无法匹配时采用列表首项简体中文。升级继续使用之前选择的语言。

两份上游文件固定于 Inno Setup `is-6_7_4` 对应提交 `c2913c993858a781fcb455bac8b8949c1c366cb8`，已随源码提供。构建直接读取仓库内文件。
