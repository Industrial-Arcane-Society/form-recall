# 真实特征提取报告

从 518 个 STEP 里提取**带位置**的圆柱特征（直径 / 轴向 / 位置 / 轴向范围）。

## 为什么做这个

用户反馈：除螺钉外，其它零件「只是一个大体形状，零件细节都没有」。
根因是之前建模只用了包围盒 + 直径指纹，**位置信息全丢了**，
孔只能按预算平均摆在长边上。本工具把位置补回来。
